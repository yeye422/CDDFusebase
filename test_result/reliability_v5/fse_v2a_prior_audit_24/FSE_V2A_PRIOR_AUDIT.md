# FSE-v2a 固定结构先验独立审计

## 1. 审计范围

本审计不经过Router，不使用融合指标，直接回答：

\[
R_0=\operatorname{FSE\text{-}v2a}(SAR)
\]

究竟检测到了什么，以及它是否具有作为结构证据的空间连续性和扰动稳定性。

数据为val200中的24个固定等间隔位置。完成以下检查：

1. Optical、SAR、连续 \(R_0\) 和 \(R_0\ge0.5\) 覆盖图的并排审查；
2. 阈值0.3、0.5、0.7下的连通域、碎片化和方向一致性统计；
3. 12张图上的轻微平移、强度、模糊和弱乘性扰动稳定性；
4. 从 \(R_0\ge0.5\) 区域固定随机抽取200个中心，生成可复查接触表。

本审计不使用光学边缘作为SAR结构真值。所有“结构性”判断只描述SAR内部形态、连续性、方向性和稳定性。

---

## 2. 空间统计

### 阈值 \(R_0\ge0.5\)

24张图的平均统计为：

| 统计量 | 结果 |
|---|---:|
| 高响应像素比例 | 1.73% |
| 每图连通域数量 | 186.2 |
| 平均连通域面积 | 5.71像素 |
| 连通域面积中位数 | 3.08像素 |
| 单像素连通域比例 | 19.25% |
| 面积不超过5像素的连通域比例 | **73.88%** |
| 面积不超过5像素的高响应像素占比 | **37.74%** |
| 伸长率不低于3的连通域比例 | 10.72% |
| 高响应区方向一致性 | 0.831 |
| 全有效区方向一致性 | 0.501 |
| 高响应区SAR梯度强度 | 1.240 |
| 全有效区SAR梯度强度 | 0.481 |

该结果同时说明两件事。

第一，\(R_0\)具有明确的结构偏好：高响应位置的方向一致性比全图高约66%，SAR梯度强度约为全图的2.58倍。它不是纯随机概率图。

第二，\(R_0\)高度碎片化：近74%的连通域不超过5像素，只有约11%的连通域具有较明显伸长形态。因此阈值0.5的输出更接近：

\[
\text{稀疏强线段、边缘片段、亮点和短响应集合}
\]

而不是：

\[
\text{完整连续的结构区域图}
\]

### 阈值变化

阈值从0.3提高到0.7时：

- 高响应像素比例从7.12%降至0.27%；
- 小连通域比例从62.98%升至80.50%；
- 单像素连通域比例从15.66%升至28.01%；
- 方向一致性从0.768升至0.884；
- 梯度强度从0.996升至1.492。

提高阈值会选出更强、更有方向性的响应，同时使空间碎片化更严重。单纯提高阈值不能得到更完整的结构图。

## 3. 随机高响应样本

从 \(R_0\ge0.5\) 区域固定随机抽取200个中心，并按中心所在连通域的形态分类：

| 形态类别 | 数量 | 比例 |
|---|---:|---:|
| 1–5像素碎片 | 70 | 35% |
| 6–20像素小组件 | 74 | 37% |
| 明显伸长组件 | 44 | 22% |
| 其他较大组件 | 12 | 6% |

即72%的随机高响应中心位于面积不超过20像素的组件中。

视觉审查表明高响应样本包括：

- 与道路、田块、建筑和区域边界对应的清晰长边；
- 真实边缘上的短断裂片段；
- 建筑或人工目标周围的强散射簇；
- 孤立亮点；
- 均匀speckle背景中的短小响应；
- 难以仅凭单幅单极化图判断物理意义的局部高响应。

因此：

\[
P(\text{organized structure}\mid R_0\ge0.5)
\]

并非接近1。当前高响应集合在视觉和形态上都不是语义纯净的结构类别。

但由于没有SAR结构真值和极化信息，本审计不对每个强散射点强行判定为“噪声”或“目标”。

---

## 4. 扰动稳定性

下表为阈值0.5时12张图的平均结果：

| 扰动 | 连续图相关系数 | 平均绝对变化 | 高响应IoU | Top-k重合率 |
|---|---:|---:|---:|---:|
| 1像素平移并反向对齐 | **0.9981** | **0.0008** | **0.9861** | **0.9916** |
| 轻微强度变化 | 0.9995 | 0.0026 | 0.9028 | 0.9827 |
| 3%弱乘性扰动 | 0.9968 | 0.0055 | 0.9196 | 0.9583 |
| Gaussian blur，\(\sigma=0.6\) | 0.9454 | 0.0235 | 0.5803 | 0.7774 |

结论：

1. FSE-v2a对轻微平移、强度和弱随机扰动具有较高稳定性；
2. 它不是一张会因轻微输入变化完全重排的随机噪声图；
3. 它对轻微模糊较敏感，尤其高阈值集合变化明显，说明其证据强烈依赖细尺度高频；
4. 扰动稳定只能证明检测器响应稳定，不能证明检测到的内容具有融合价值。

## 5. 原图审查

完整图覆盖结果显示：

- 长而明亮的SAR边缘通常能够获得连续高响应；
- 建筑规则边缘、道路边界和水陆边界是其优势区域；
- 均匀或高speckle区域仍存在大量稀疏红色孤立点；
- 同一完整物体的响应经常只保留若干局部片段；
- 弱边界、低对比结构和非线性区域存在漏检；
- 强点散射与连续线结构都会产生高值，单凭 \(R_0\) 无法区分其融合意义。

因此，当前图更适合解释为：

\[
\boxed{\text{stable strong line/high-gradient evidence}}
\]

而不适合解释为：

\[
\boxed{\text{universal structural reliability map}}
\]

---

## 6. 三种情况判断

### 情况A：高质量通用结构图

不成立。碎片化、孤立响应和结构类型覆盖不足都与“通用结构图”不符。

### 情况B：明显杂乱、基本无结构价值

也不成立。高响应区具有显著更高的方向一致性和梯度强度，并对多种轻微扰动保持稳定；长边和强结构经常被正确突出。

### 情况C：只对部分强线结构有效

与现有证据最一致。FSE-v2a对长线、强边缘和稳定高梯度响应有价值，但同时包含大量短片段、强点和speckle样小组件，对弱边界和非线性信息覆盖不足。

因此正式定位应从：

> 固定结构可靠性图

修正为：

> 固定强线/高梯度结构证据（fixed strong line-structure evidence）

## 7. 对SRR失败链条的影响

当前证据支持以下更完整的失败链条：

```text
具有局部价值但碎片化的强线证据 R0
                ↓
被解释为通用可靠性正标签
                ↓
低R0与低Ex被混合解释为负标签
                ↓
Router通过输入—标签捷径复制R0
                ↓
局部线段、强散射点与speckle样碎片被共同放大
弱结构、非线性信息和错位结构被共同抑制
                ↓
Anchor分类变好，但融合效用估计没有变好
```

V6失败既包含Anchor语义错误，也包含先验适用范围被过度扩大的问题。

---

## 8. 后续使用原则

FSE-v2a仍可保留，但必须满足以下限制：

1. 名称明确为“强线结构证据”，不再称为通用结构可靠性图；
2. 只能作为辅助连续通道，不直接生成可靠性正负标签；
3. 不允许单独决定SAR特征保留或删除；
4. 必须与不依赖线结构的区域、纹理或目标证据共同使用；
5. 是否带来净收益需要通过无FSE/有FSE配对实验验证；
6. 若新Router在不使用FSE时已经有效，FSE只能作为增量消融项加入。
