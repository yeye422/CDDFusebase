# PDCF 改进方案 V2：先验证结构保留，再验证分解价值

日期：2026-10-22。本文是针对当前 PDCF P2 失败的实验设计，不是已验证有效的方法；未修改模型或启动训练、批量评价。新损失、候选选择和新增控制尚需实现，现有 CMD 不能直接完成本方案，不提供含有未实现参数的伪命令。

**推荐路线：保留 C0 和现有单路 Adapter，用结构保留约束修复训练方向，建立包含 C0 的指标选模，再决定是否值得引入残余专用路径。**

不更换 PDCF 的正式基线，不把其他 B0/SPD 路线收益归入 PDCF。当前失败 checkpoint 保留归档；后续从同一 C0 和 P1 checkpoint、零初始化 Adapter 重新开始。

**实施前补充诊断：**先运行 `CDDFuse/run_pdcf_p2_signed_scale_diagnostic_val200.cmd`。该诊断不重新训练，扫描 `alpha=-0.10...+0.10` 并包含零修正恒等候选；它同时落盘配对 bootstrap 区间、原代理损失、代理损失变化与各 paper 指标变化的相关性，以及局部块输出/梯度偏移。若负方向稳定改善而正方向稳定退化，应优先复核任务目标或梯度方向，不直接进入保护损失训练；若正负方向都退化，则更支持当前 Adapter 的局部方向混杂或 C0 附近非线性问题。诊断结果生成前不得预判上述两种情况。

**一、先把可接受收益定义清楚**

目标仍为 QAB/F、FMI、VIF 中至少两项改善，同时限制 NAB/F 恶化和第三项退化。降低训练损失、输出更平滑、仅提高 MS-SSIM，均不足以继续。

建议将以下数值作为下一轮开发开始前冻结的工程门槛，而非统计定律或事后阈值：

- 至少两个主指标相对当次 C0 提高 0.5%；
- 第三个主指标相对下降不超过 0.5%；
- NAB/F 相对恶化不超过 1%；
- 完整 val1000 确认时，两个改善项的逐图配对 bootstrap 95% CI 下界均大于 0；另外两项还需报告非劣性边界；
- 最终至少三个训练 seed 同方向，报告各 seed 和跨 seed 汇总，不把图片 bootstrap 当作训练复现；
- 无明显全局模糊、光学复制、新增光晕或SAR重要结构消失。

这些门槛会筛掉“基本回到 C0”的模型。不要给输出变化设最低幅度损失或强制门控覆盖率，以免网络为了达标制造无用变化。

**二、第一轮不改网络，先做四组可归因的对照**

| 编号 | Adapter 输入 | 训练目标 | 回答的问题 |
|---|---|---|---|
| A0 | 无，C0 恒等输出 | 无 | 当次统一评价基线 |
| A1 | Raw Evidence | 原 frequency-minimax | 新统一协议下原目标的表现 |
| A2 | Raw Evidence | 原目标＋结构/输出预算 | 不依赖分解，约束是否有效 |
| A3 | Predictable/Residual | 原 frequency-minimax | 与 A1 比较输入分解作用 |
| A4 | Predictable/Residual | 原目标＋结构/输出预算 | 与 A2 比较约束下分解的独立价值 |

四个训练组使用完全相同的 Adapter、初始化规则、数据顺序、预算、优化器和评价；Encoder、Decoder、原 Fusion、P1 Predictor 全部冻结。保留原 Base/Detail 两路修正和 25% 特征幅度上限，避免首轮同时加入 Detail-only、双路径、Refactor 或 SPD。

A1/A3 是按新协议重新训练的对照，不直接拿历史结果充当因果控制。新协议改变了尺寸和优化设置，历史结果只能作为背景。

**三、改进损失：允许改进，同时给结构损失设置预算**

设 F₀ 为同一输入下冻结 C0 的输出，F 为候选输出。保留原任务损失 L_task，新增预算惩罚：

`L = L_task + λ_guard · L_guard`。

对尺度 σ∈{0,1,2}，定义有符号二维梯度 `gσ(X)=∇Gσ(X)`，其中 σ=0 表示不做高斯平滑：

`eσ = mean(|gσ(F)−gσ(F₀)|) / max(mean(|gσ(F₀)|), sσ_floor)`。

`r = sqrt(mean((F−F₀)²)+ε²)−ε`。

`L_guard = meanσ([eσ/τσ−1]₊²) + [r/τr−1]₊²`。

其中 `[x]₊=max(x,0)`，F₀ 与分母全部 stop-gradient。每张图独立计算后取平均，梯度只在有效区域及卷积有效边界内统计。`sσ_floor` 从固定训练校准样本的梯度统计获得并保存，另设数值 ε，避免平坦区域分母接近零。

首轮建议固定：`τσ=0.05`，`τr=8/255`，`λ_guard=1`。这些只是待验证的起点，不宣称最优。训练校准仅检查量纲、有限性及惩罚是否产生预期梯度，不按验证结果反复改阈值。

设计理由：

- 比较梯度向量而非只比较梯度幅值，使方向偏移、削弱和新增边缘都受到约束；
- 原尺度与平滑尺度同时保护，避免只保住大轮廓而丢失细节；
- 预算以内惩罚为零，允许局部改进，不把每个像素强行锁死在 C0；
- 平滑 RMS 保持零初始化处梯度有限；禁用项不接入计算图；
- 输出预算作用于实际生成图像，补充“特征修正很小但 Decoder 输出变化很大”的缺口。

这是软约束，不是数学上的硬保证，训练后必须记录实际违规比例。它还会保留 C0 的部分斑点和错误结构，因此不能当作理想融合真值；其用途是检验当前损失是否存在兼顾结构保留的改进空间。

如果 A2/A4 只回到 C0、没有达到最小收益，判为没有进展。若继续降低 L_task 总要破坏预算，则停止沿用该目标；不能不停加大 λ 直到输出不变，再宣称问题解决。若只保住结构而不能改善，不自动进入更复杂网络。

**四、必须修正 checkpoint 选择**

每个 run 都保存 epoch 0 的恒等候选，并验证其输出与 C0 一致。训练损失只用于诊断，不能单独决定最终 best。

每个 epoch 在同一 val200、256×256、相同 clamp/uint8 和 paper metric profile 下计算完整14指标、逐图差值。先过滤第三项退化与 NAB/F 超预算的候选，再检验至少两项达到 0.5% 最小收益。

对于通过门槛的候选，使用预先固定分数：

`Score = mean(ΔQAB/F / QAB/F_C0, ΔFMI / FMI_C0, ΔVIF / VIF_C0)`。

同分选输出偏移更小者，再同分选较早 epoch。未通过门槛时，结果记录为 `no_eligible_candidate` 并返回 C0；可以另存最低训练损失 checkpoint 用于诊断，但不能称为有效改进。

val200 只做开发筛选。每组最多保留一个候选进入 val1000，并使用同一冻结规则进行确认/比较，不在看到 val1000 后追加阈值、尺度和 loss weight 搜索。验证集选择后的 CI 不能当作未经选择的最终泛化证明；最终结果仍需冻结方案后在 test1000 确认。

**五、统一训练预算与尺度，消除可避免的混杂**

- 沿用原 train/val/test manifest，不重划分数据；
- 从原 train split 用固定种子不放回抽取 pilot1000，保存独立子集清单及 SHA；不再截取按编号排序的前1000张；
- val200 暂用已使用的前200张，明确它已是开发集；不把它重新命名为未见验证集；
- pilot 训练和选模均用 256×256；推荐 micro-batch=2、梯度累积4次实现有效 batch=8，四组一致；
- AdamW，lr=1e-5，weight_decay=1e-4，clip_grad=1.0，5 epoch，seed=42；这些是本轮统一起点，不与历史不同配置直接作损失因果比较；
- 全部组使用相同随机增强和样本顺序，保存每 epoch checkpoint；不使用 test 选模型；
- 特征尺度仍沿用现有实现，记录其分布；若未来改为训练集固定 RMS，应另开单因素实验，首轮不一并改变。

正式阶段再扩至 train8000 和至少3个 seed。若显存不足，优先保持图像尺寸并降低 micro-batch、增加累积次数；必须按实际累积样本数归一化末批梯度。

**六、只有四组实验出现正收益，才补强 P1 的价值论证**

现有 P1 checkpoint 保存了 `PDCFLinearBaseline`，可用来建立线性 Predictor 控制，无需立即重训预测器。

必要检查包括：

1. 均值基线使用目标模态自身的训练均值，不能只用两模态合并均值。
2. 用正确配对、输入轻微平移和跨样本错配比较预测误差；残余交换不能代替 Predictor 输入错配实验。
3. 对比非线性预测器、线性预测器与 Raw Evidence，Adapter 容量和训练预算相同；分别记录训练参数、冻结 Predictor 参数、推理开销。
4. 对训练好的 Adapter 做 Optical/SAR 残余单独置零、空间打乱与等能量替换，并检验相对 C0 的增益是否消失。把此类干预视为机制诊断，注意其会产生分布外输入。
5. 用从头训练的残余移除/线性控制验证必要性，避免仅靠分布外干预作因果结论。

若 A4 不优于 A2，保留更简单的受约束融合方案，停止把可预测分解作为主要贡献。若线性预测器达到同等效果，采用线性版本并如实描述；不为保留“非线性分解”叙述继续堆叠网络。

**七、第二轮架构候选：条件化残余修正，只在前述门槛通过后实施**

这一轮要解决四组特征过早混合的问题。让 Predictable 提供上下文，让两个模态 Residual 分别产生候选修正：

`zC = φC([C_O,C_S])`

`zO = φO(R_O ; zC)`，`zS = φS(R_S ; zC)`

`ΔD = Q([zO,zS,zC])`，`B_F=B_F_C0`，`D_F=D_F_C0+ΔD`。

第一版只修改 Detail，目的是减少同时改变 Base 外观造成的混杂；并非假设所有互补信息都只在 Detail。必须先补一个参数/预算匹配的单路 Detail-only 对照，再比较分路径结构，不能把两个变化合并归因。若 Detail-only 本身损害收益，保留 Base/Detail 两输出接口，不强行采用 Detail-only。

条件模块可使用有界 FiLM：`z=(1+0.1·tanh(a))⊙φ(R)+0.1·tanh(b)`，a、b由zC产生。这只提供有界调制，不代表可靠性概率。最终输出层零初始化，其余层保持可训练的非零初始化；不再叠加一个零初始化全局乘法门，避免两个零因子导致梯度阻断。

首版不加稀疏门控、不规定最低SAR贡献、不用预测误差直接生成可靠性标签。Predictor继续冻结，使用相同结构预算和指标选模。分路径结构只能提高归纳约束，不能从结构上保证残余具有纯互补语义。

**八、阶段决策**

| 观测结果 | 决策 |
|---|---|
| A1/A3 已通过，而 A2/A4 无额外收益 | 优先保留统一协议修复，不强行引入保护损失 |
| A2通过，A4没有独立优势 | 保留受约束 Raw Evidence，结束 PDCF 主贡献叙述 |
| A4只恢复C0，未达到最小改善 | 判为无收益，停止增加复杂度 |
| A4优于C0与A2，且线性控制更差 | 进入分解机制审计及第二轮架构验证 |
| 四组全部失败 | 停止当前 Adapter＋任务目标组合，转向明确可定位错误的修正任务 |
| val200通过但val1000或多seed不稳定 | 不进入正式test，不以挑图或换阈值挽救 |

若四组全部失败，下一步应重新定义可被监督的修正任务，例如只处理具备源支持证据的新增伪边缘；这应作为独立方案，并设置自己的基线和指标目标，不再把原 PDCF 结构持续扩展。

**九、实现与交付顺序**

1. 训练器增加结构/输出预算、梯度累积、子集清单、epoch0与每epoch checkpoint。
2. 复用现有评价器增加候选筛选、配对bootstrap、均值/标准差/胜率、预算违规统计；统计实际写入JSON，不能仅写注册表备注。
3. 加必要单元检查：恒等输出、零点有限梯度、预算内惩罚为零、可控边缘减弱/偏转能触发惩罚、候选全部失败时返回C0、不同图像尺寸的协议校验。
4. 生成四组训练CMD及独立评价CMD；由用户执行训练与批量评价。正式run使用新唯一目录，保存代码版本/差异、checkpoint和manifest SHA。
5. 新结果生成后登记 `EXPERIMENT_REGISTRY.json`，执行项目规定的索引检查；训练、开发、正式验证和不同比较组不得混排。

当前版本只完成方案。建议首个开发工作包限定在第一至第五项实验设计对应的最小四组对照，暂不实现第二轮架构，以减少没有证据支持的开发投入。
