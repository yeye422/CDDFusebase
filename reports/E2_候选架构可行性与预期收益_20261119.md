# E2 候选架构可行性与预期收益

日期：2026-11-19。分析对象为上一轮材料中的 GDN2/DAME、可逆耦合和 Mamba-3/MIMO，其他候选作投入比较。本轮仅读取代码、已有结果和原始文献，计算示例模块的静态参数、卷积乘加及状态存储量，没有训练、模型推理、显存实测或批量测试。以下“预期”是研究判断，不是新实验结论。

**结论：三条路线在数学上均可实现，但可实施性和成图收益的把握不同。INN 最容易在现有环境做成受控原型，GDN2 最容易围绕独立擦写提出明确的机制消融，Mamba-3/MIMO 的当前投入回报最不明确。没有证据支持任何一条能带来预定比例的画质提升。**

优先目标应是改善困难光学结构的呈现，同时保住 SAR 独有内容和 E2 的伪影折中。不能把“光学特征更强”“记忆更丰富”或“源特征更可恢复”直接计为融合成功。

**收益受到四个环节共同限制。**

当前从头训练、光学 Base 保留版 E2 pilot 的冻结诊断支持如下判断：

1. 源端并非没有可呈现的信息：光学候选结构的单源重建传递约 0.961，融合中约 0.333；SAR 对应为 0.954、0.931。
2. 两源投影的整体输入响应不直接解释最终失衡：逐图光学/SAR 增益比均值从投影层 1.210，变为 fused Detail 的 0.906、最终图像的 0.572。
3. Decoder 能传播某些高频探针，但对两源方向响应不同；不能把它视为完全中性的通道，也不能认定它是唯一故障点。
4. 原最大梯度监督在全有效区约 82.45% 由 SAR 提供，但在光学候选区为 43.74%。存在全局监督偏向，不能据此认定每条光学边都受强负冲突。

来源：[源路由原始摘要](../test_result/e2_detail_route_localization_v1/val16_seed42/summary.json)、[Decoder 原始摘要](../test_result/e2_fcsr_decoder_diagnosis_v1/val16_seed42/summary.json)。这些是梯度候选与冻结响应，不是人工结构真值，也不是新模块的性能上限。

由此得到的核心限制是：**新融合模块可以改变特征组织和进入 Decoder 的方向，联合训练也可能改变 Decoder 的适应；但它不会自动改变什么内容受到训练目标奖励。** 只加强信息保存或传播，仍可能得到偏 SAR 的解。因此第一轮保持原损失适合检验架构是否有独立价值，却不应预期架构自然完成结构真假判别。

| 路线 | 数学及接口可行性 | 当前环境落地成本 | 最合理的预期收益 | 当前证据最弱处 |
|---|---|---|---|---|
| 可逆加性耦合 | 高，可保留原 Base/Decoder 及最终 Detail 通道数 | 较低，普通 PyTorch 即可 | 通过双源交互重排表示，使既定压缩头更容易选择内容 | 可逆性是否优于同宽普通交互，而非只增加参数 |
| GDN2 残差上下文 | 高，需要定义子带、状态、扫描和读出接口 | 中高，高效训练后端尚未就绪 | 对某些远距离重复结构提供选择性上下文，研究独立擦写的额外作用 | 当前问题是否确实需要记忆编辑，以及正确条件是否有独立价值 |
| Mamba-3/MIMO | 可以实现，但子带到 MIMO 秩的映射需另行设计 | 中高，需要完整算子及额外消融 | 跨位置、跨投影分量的状态表达增强 | 表达能力增加与当前两源取舍问题之间没有直接证据 |

表中等级是实现难度和证据强弱的定性判断，不是成功概率排名。

**可逆耦合：适合低成本筛查，预期主要来自表示重排。**

建议只考虑最小加性耦合，例如 `Yo=Do+f(Ds)`、`Ys=Ds+g(Yo)`，先避免仿射指数缩放、扩散超分或额外小波分解。只要保留两路完整表示、函数计算可重现且不在中间截断量化，加性结构容易实现逆变换；但 `Yo/Ys` 已包含跨源内容，不能继续把它们解释为纯光学、纯 SAR 表示。

它的合理价值不是创造新信息：原始 `concat(Do,Ds)` 已完整包含两源，任何可逆变换都不会比它包含更多信息。可能的价值是把有利于融合选择的内容排列到更容易读出的坐标，使后面的受限压缩头在给定训练预算内更容易优化。这是归纳偏置和可读出性假设，不能由“可逆”两个字推出。

本地 RICF 的 train128/val64 结果中，PCA64 对两源的恢复 NMSE 分别为 0.015347、0.017100，E2 为 0.124287、0.167563，PCA 在两源各 64/64 图上胜出；随机投影也优于 E2。这支持比较不同压缩表示，但不特异地支持 INN，也没有证明多恢复的是有效结构。[RICF 原始结果](../test_result/e2_ricf_bottleneck_expanded_v1/train128_val64_seed42/summary.json)

更现实的预期是局部纹理/边界的呈现发生改变，或压缩后源信息更容易恢复；不能预期仅靠 coupling 就系统性降低 NAB/F。它也可能保留更多不利高频，增加输出过冲。若后续普通 `128→64` 选择仍丢弃光学内容，INN 的完整双路可逆并不能救回最终输出。

从具体成本看，当前 `MultiScaleDetailFusion(64,32,16)` 按代码静态计数为 **61,616 参数**。假定每个 `f/g` 采用 `1×1:64→32`、`3×3 depthwise:32`、`1×1:32→64`，均含 bias，则两函数合计 **9,024 参数**。将这对 coupling 作为原头之前的附加交互，约增加该 Detail 头参数的 **14.6%**，不是整个模型增加 14.6%。

对单张 256×256 特征，仅按卷积权重乘加计算，当前 Detail 头约 4.006 GMAC，上述附加块约 0.575 GMAC，增加约 14.3%。该估算不含激活、访存和函数调用，未测速度，不能换算成训练耗时或吞吐比例。普通自动求导也不会因为层可逆就自动节省训练显存；显存收益需要另行实现重计算/逆重建。

这个成本具有可控性，但仍须与同宽、近似参数量的普通残差双分支比较。若在已有每源 `64→32` 投影后插入 coupling，只能保护投影后内容；若前置保留完整 128 通道，对照必须拥有相同的最终选择输入宽度。首轮不另加源重建损失，避免算子收益与监督收益混在一起。

已有 CDDFuse 原模型和近期频率引导 INN 都构成近邻，因此它的论文收益预期低于单纯工程改动预期。只有可逆约束本身在同容量、同选择头下改善最终有效结构，才值得继续发展。[CDDFuse 原文](https://openaccess.thecvf.com/content/CVPR2023/html/Zhao_CDDFuse_Correlation-Driven_Dual-Branch_Feature_Decomposition_for_Multi-Modality_Image_Fusion_CVPR_2023_paper.html)

**GDN2：机制辨识度更高，当前主要障碍是有效训练和任务适配。**

GDN2 的独立擦写与逐通道衰减是真实算子差异，适合检验“已有记忆应当改多少、新内容应当写多少是否需要分别决定”。但其语言实验不能证明 SAR 可靠性，更不能证明 E2 已存在记忆覆盖病因。[GDN2 原文](https://arxiv.org/html/2605.22791v2)

在 E2 中，较稳妥的第一版是保留原局部成图路径，用源别状态提供受限的上下文残差。最可能首先受益的是已有源证据、但局部聚合未充分利用的延展结构；若细线主要由当前位置的有符号子带决定，全局记忆增益可能很小。道路/田界是否属于前一种情形，需要结果确认，不能先给出类别保证。

该模块不能凭门值区分散斑和真结构；更长传播也可能把高响应带到不相关区域。Base 跨源条件可能帮助选择，也可能沿用现有偏向。源别状态只保证没有直接跨源 value 写入，LWPD 门控、跨源条件与最终读取依然有信息交换，不构成整网来源隔离。

当前环境查询仍为 PyTorch 2.4.1，未安装 Triton/FLA；前轮查询的 Python 为 3.8.10。官方依赖使用 PyTorch 2.9.0，不能假定现环境直接运行高效核。[官方依赖](https://github.com/NVlabs/GatedDeltaNet-2/blob/main/requirements.txt) 短序列纯 PyTorch 原型可以验证更新、退化关系及梯度，但完整训练应等待有效后端，不将逐步 Python 循环当成效率结论。

以下仅为状态存储的算术示例：两源、四方向、batch=2、每源每方向 2 个 head、`dk=dv=16`、FP32。假设每个位置都显式存一份矩阵状态：

| 子带网格 | 全部位置状态张量的原始存储 | 按行列流式执行、同时保留所有源/方向当前行状态 |
|---|---:|---:|
| 64×64 | 128 MiB | 2 MiB |
| 128×128 | 512 MiB | 4 MiB |

公式为 `2源×4方向×B×P²×heads×dk×dv×4 bytes`。流式状态少一个序列长度因子。串行调度各方向还可降低当前状态存储，但训练梯度不是仅保存当前状态就自然可得；朴素 autograd 的门、投影、中间量和反向存储会另外增加，实际峰值也受调度与重计算影响。这些不是实测显存，也不表示 chunkwise 核具有同样存储量。16 维 head 是估算配置，尚未验证核支持和利用率。

把网格从 128 降到 64 会降低位置相关成本，但不是免费收益：要保留细尺度成图旁路，或明确保留所有分量的重排，否则可能为省显存而删掉目标细线。所有控制组应使用相同输入网格和旁路。

GDN2 的首轮性能预期应是**局部结构和全图折中的小规模验证信号**，而非全指标大幅上升。研究收益则较明确：最新 v2 的共享向量门控制允许在近似相同外框中识别“独立擦写”是否必要。若独立门不优于 tied 版本，就不主张独立擦写是该任务的有效第二机制。Dual-KDA 用来区分通道衰减与门控粒度，Joint-GDN2 用来检验状态分账，二者也不能由 Mamba-2 替代。

**Mamba-3/MIMO：能做，但当前更像表达能力对照。**

MIMO 在状态读写中增加秩维度，能够增强相互作用；它不直接规定哪个模态应保留，也不会自动按 LH/HL/HH 的语义分配秩。当前 E2 的 LWPD 门已联合读取各子带，因此新增收益只能来自更具体的状态交互，而非首次引入跨子带关系。[Mamba-3 §3.3](https://arxiv.org/html/2603.15569v1#S3.SS3)

它可能改善某些长程关联或方向组合的表示，但缺少证据证明这正是当前损失所在。更强状态会增加实现、调参和消融成本，也可能传播更多无用响应。语言逐 token 解码的优势不直接适用于高分辨率双向训练。

要验证 MIMO，至少需要同外框 Mamba-3 SISO/MIMO；只与 Mamba-2 比较会混入离散化和复数状态差异。若方向联合是主张，还要与联合输入的普通通道混合/SISO 比较。当前不建议为了它先扩大整套模型或改变 Base/Decoder。

**对七类候选的预期收益应分别看。**

| 候选 | 对当前 E2 的可能收益 | 当前投入判断 |
|---|---|---|
| GDN2 | 选择性长程上下文与可分离的记忆编辑变量 | 可保留为研究主候选，先过后端和有效输入准入 |
| INN | 改善压缩前的表示组织与可读出性 | 适合低成本配对筛查，暂不视为质量成功率最高 |
| Mamba-3/MIMO | 更丰富的状态表达和方向交互 | 后续对照；暂无优先独立实现的收益依据 |
| 新 MoE | 条件自适应的专家选择 | 先复用 S2 已有证据，不默认再开相近路线 |
| Rectified Flow | 对指定高频端点的迭代逼近 | 端点是否有用未解决前，轨迹收益没有依据 |
| FNO/神经算子 | 全局频域交互与可能的计算替代 | 当前缺少任务适配和成图增益依据 |
| Vision KAN | 更灵活的非线性/token mixing | 可以作算子参照，尚不构成源传递机制主线 |

这里没有给出“QAB/F 提升几个百分点”或成功概率，因为当前不存在这些新候选的匹配训练结果。已有语言、医学、检测论文成绩，以及 RICF 的源恢复误差，都不能提供这种数值预测。更合理的预期是先确认少数困难结构有可辨认改善，并检查其他来源是否付出代价；全图分数可能只有小幅变化，也可能相互冲突。

**以最小增量投入检验，而不同时安排三条完整训练线。**

- 若目标是尽快判断工程增益：只开“最小 INN coupling + 同宽普通交互”的一对新小试，共用最终选择头；复用已有适用 E2 对照。仅 INN 胜过 E2 还不能归因于可逆性。
- 若目标是形成清楚的第二机制：先完成 GDN2 小尺寸数值和有效输入检查，确认高效后端可用，再只训练一个新增候选。出现有效结构信号后，依次补普通卷积、tied 门及 KDA；需要主张状态隔离时再加 joint 状态。
- Mamba-3/MIMO 不与上述同时推进；候选确定后再作为有明确问题的扩展比较。

这两个顺序的目标不同，不代表 INN 和 GDN2 必须同时执行。结合当前已有长期探索与 Windows 环境，**工程筛查可先选最小 INN 配对；若论文必须突出可检验的新状态机制，则 GDN2 的研究价值更高，但应接受更高的实现成本和不确定性。** 不把前者描述成更可能全面超过 E2。

小试统一采用适用的 train1024/val64、4 轮源重建 + 12 轮融合、seed42、原损失和相同 Base/Decoder 结构，整套从头初始化。相同预算是筛查条件，不意味着不同算子均已充分优化；若再调训练预算，另列成本与可比限制。旧 S2 微调、历史 R3 初始化 E2 与当前从头训练 pilot 分开解释，不默认重训现有基线。

通过首先要求困难光学结构有真实成图改善、SAR 独有边/孤立目标没有系统丢失，再联合检查 QAB/F、FMI、VIF、NAB/F 及其余完整指标。NAB/F 不劣于匹配 E2 是筛查目标；若要接受非劣容差，应在看结果前定义，不能用“差异不显著”代替等效证据。候选边不是结构真值，独立评价样本也不能用于训练新条件或反复挑阈值。

若只改善完整双路的逆重建、线性探针、状态响应或门分布，而最终图像没有收益，不升级。若普通卷积解释 INN 的全部改善，或 tied 门解释 GDN2 的全部改善，应撤回对应机制归因。NAB/F 的改善若主要来自删掉 SAR 信息，也不通过。

后续统一使用 `reference_v2_candidate_with_paper_fmi`，逐指标报告共同有限样本数、逐图值及配对不确定性；有信号后再补训练种子与固定配置的大规模确认。新结果采用唯一目录并登记注册表。本轮仅增加分析文档，静态估算不是模型测试结果，不修改实验注册表，也没有新训练入口或可执行的新训练命令。
