# 新兴架构二轮核验：可逆表示、增量记忆与 E2 适配

日期：2026-11-18。本轮继续核验用户粘贴材料，并结合当前代码及已保存的 RICF、S2、E2 结果判断接入价值。沿用本轮范围：不引入 MaRS、预训练基础模型、人工结构训练标签或 SAR 物理域概率模型。没有执行训练、模型推理或批量测试。

**结论：主要论文真实存在，但材料把不同任务上的成果混成了同一种融合证据，并把“更容易实现可逆耦合”推到了“更可能改善 E2”。目前不支持将可逆网络直接升级为首选。GDN2 保留为递归主候选；INN 适合作为与普通双分支配对的工程候选；Mamba-3/MIMO 放在后续骨干消融。其余方向暂不新增实现。**

这不是七种架构的性能排名。判断的依据是当前失败现象、可检验差异、已有实验及工程成本，而不是原论文的语言建模、检测、重建或医学融合分数。

**可逆来源融合的公式成立，但还没有构成优先接入理由。**

材料的加性耦合在保留完整双路状态、使用相同确定性函数且中途不量化截断的条件下，确实可以逆向恢复输入。这里需要区分三个命题：

1. coupling 层数值上可逆；
2. 中间表示更容易保留对融合有效的内容；
3. 最终融合图的结构、互补信息与伪影折中改善。

第 1 项来自构造，第 2、3 项必须另有证据。若随后仍用普通 `128→64` 投影与原 Decoder，前面的 `128→128` 可逆变换不会保证最终无损。它没有自动扩大最终表示容量，也没有自动解决选择标准；在一般连续映射条件下，不能声称任意双源特征都可由一半维度的融合特征精确恢复。真实数据可能有大量冗余，所以也不能仅凭维数认定压缩已经丢掉任务所需信息。

纯 `T^{-1}(T(x))` 重建误差可以检查逆实现和数值稳定性；对精确构造的可逆层，它本来就趋近零，不能单独作为学习有效融合的监督或成功指标。从压缩后的 `Df` 重建两源则是另一种监督改造，需要与算子分开消融。

当前 `MultiScaleDetailFusion` 并不是先把两源粗暴相加再处理。它分别将每源 64 通道投影到 32 通道，保留两路投影，并将它们与联合多尺度分支、Base 条件一起送入最终聚合。因此：

- 若 coupling 放在每源 32 通道投影之后，它只能保护已经投影的内容，不能声称避免此前全部源信息损失。
- 若放在投影之前保留两源完整 128 通道，普通双分支对照也必须保留相同宽度、相同后续选择头与近似预算。
- `受约束融合` 目前没有具体定义。若最后仍是普通拼接卷积，尚不能把它称为新的信息保护机制；若加入新的结构目标或门控规则，它们才是需要明确并独立检验的内容。

此外，原始 **CDDFuse（CVPR 2023）已经使用 INN detail 分支和融合层**，`net.py::DetailNode` 中也保留了加性/仿射 coupling 形式。当前 LWPD E2 的 `encode_pair` 使用共享编码特征后直接交给 LWPD，绕过旧 Base/Detail 分解头；所以不能说“当前 E2 已经运行该旧 INN”，但更不能把“给 CDDFuse 引入可逆网络”作为新的架构贡献。[CDDFuse 原文](https://openaccess.thecvf.com/content/CVPR2023/html/Zhao_CDDFuse_Correlation-Driven_Dual-Branch_Feature_Decomposition_for_Multi-Modality_Image_Fusion_CVPR_2023_paper.html)

**已有 RICF 结果比材料引用的论据更直接，但仍不足以证明 INN。**

本地 `test_result/e2_ricf_bottleneck_expanded_v1/train128_val64_seed42/summary.json` 已存在真实扩展结果，状态为 `frozen_e2_streamed_probes_no_ricf_training`；不能沿用旧协议文档中的“尚未运行”。它使用同一冻结光学 Base E2，以 train128 拟合探针、val64 评价，在每种表示旁保留相同 Base 条件。下表仅比较本诊断中的源 Detail 线性恢复 NMSE，越低越好，不是融合画质分数。

| 来源 | E2 fused Detail | PCA64 | 随机投影64 | PCA 优于 E2 的场景 |
|---|---:|---:|---:|---:|
| Optical | 0.124287 | 0.015347 | 0.039592 | 64/64 |
| SAR | 0.167563 | 0.017100 | 0.054007 | 64/64 |

PCA64 的训练方差解释率约 98.21%。结果说明同宽表示之间存在明显的**线性可恢复性差异**，不是只由少数异常图推动。随机投影也更容易恢复两源，因此它没有特异地指向可逆耦合。PCA 本就面向源方差保留，E2 则面向融合成图；恢复得更多也可能包括 SAR 散斑、重复内容或对最终任务无用的信号。

因此，可以继续研究融合压缩和来源保留，但不能把这份结果改写成“E2 必须使用 INN”。也没有理由再默认运行相同 RICF 扩样诊断。来源：[已保存原始摘要](../test_result/e2_ricf_bottleneck_expanded_v1/train128_val64_seed42/summary.json)。

**DAME 比上一版明确了条件来源，但没有解除归因问题。**

让 `k/v` 来自本源、`b/w/Λ` 由本源和跨源 Base 共同生成，是可以实现的候选。它确实没有直接把另一源 value 加进当前记忆；但跨源信息仍可通过编辑门进入状态，再通过读取和最终 Decoder 影响输出。因而“无直接跨源 value 写入”和“状态所含信息严格单源”必须区分。LWPD 自身还已有跨源方向门，更不能主张整条路径来源独立。

材料目前对两种模态使用相同形式的更新，没有规定光学/SAR 的不同职责；“非对称”究竟指擦写职责、独立参数，还是模态间约束，需要明确。不能靠 DAME 这个拟议名称建立新机制，门控强度也不是结构可信度。

若后续实现，优先保留前轮建议中的三类直接控制：同接口普通卷积、Dual-KDA、GDN2 共享向量门。需要主张状态分账时再加 Joint-GDN2；需要主张跨源条件有效时，应增加本源条件及空间错位/打乱条件，并对齐有效作用强度。不能只用 Mamba-2 作为“独立擦写”的消融。[前轮详细核验](Mamba类架构核验与E2接入建议_20261118.md)

64×64 也不是自动合理的尺度。一级 Haar 在 256×256 特征上产生 128×128 子带；再降到 64×64 要说明信息如何处理。对子带系数做池化不会必然复现重建 Detail 的对齐零均值抵消，但仍可能丢失细线。可以保留原分辨率成图支、让低分辨率记忆仅作条件，或用保留全部分量的重排；若重排增加通道，预算也必须计入。纯 PyTorch 数值验证应从短序列开始，不把 64×64 多向矩阵状态训练称为低成本检查。

**子带拼接与 Mamba-3 MIMO 需要分开。**

`[LH,HL,HH]` 拼成输入只规定了特征组织，普通卷积、Mamba-2、Mamba-3 SISO 都能接受它。Mamba-3 MIMO 则在状态的写入/读取投影中引入秩维度 `R`。将某些秩分量约束为不同方向或模态，是另一个待验证的设计，不是直接使用作者模块就自然成立。[原文 §3.3](https://arxiv.org/html/2603.15569v1#S3.SS3)

E2 也并非完全独立判断每个子带：`lwpd.py::_context` 已把 LL/LH/HL/HH 拼接给门控网络，重建 Detail 后又进入多通道卷积。因此，新增模块必须证明额外的联合状态有用，不能先断言原模型不存在跨子带关系。

将 Mamba-3 MIMO 与 Mamba-2 相比，会同时改变离散化、复数状态和 MIMO；要归因于 MIMO，至少需要同一 Mamba-3 外框的 SISO/MIMO 对照。检验方向联合，还需普通通道混合或联合输入 SISO 控制。论文针对语言逐 token 解码的硬件收益，不能直接等同于图像双向扫描的训练吞吐。

**其余方向暂缓的理由需要更具体。**

- MoE：本地 S2 四组训练/验证产物及固定四图路由干预已经存在，不只是“有实验设计”。已有检查没有建立区域路由的独立成图必要性；不能因 DAMoE/WMoE-Net 新发表就默认再开一套。旧 S2 的冻结/微调协议也不能直接当作所有从头训练候选的同预算对照。来源：[S2 路由原始结果](../test_result/s2_route_intervention_v1/fixed4/diagnosis.json)、[历史结果复核](历史实验结果总结_20261118.md)。
- Rectified Flow：没有融合真值不等于无法训练；SDC-Fusion 已展示由源图规则构造端点的方式。迁移的关键是这个端点是否合适。它采用高频局部能量权重，直接移到 SAR 可能再次奖励强响应，不能把能量自动解释为有效结构。应先证明端点本身的价值，再将 RF 与同端点、同容量的直接残差及相近调用成本的迭代修正比较。只胜过无补偿 E2，无法证明流轨迹必要。
- FNO/神经算子：傅里叶混合不必然只能建模平滑内容；截断频模、边界处理和细节支路决定实际表现。NODiff 的完整任务与学习框架不同，未给出当前 E2 缺少何种算子能力的证据，因此暂缓，不能简化为“FNO 天生不保细节”。
- Vision KAN：其 token mixer 不只是改激活，但暂无证据把它与当前两源传递失衡联系起来。保持为普通非线性/上下文候选即可，不能据此断言它一定不如卷积。
- 配准/可变形交互：需要自然错位确实影响目标结构的证据；不同任务论文不能替代本地定位。当前材料不足以将它升级为第二机制主线。

**材料引用的 test1000 数字必须标记为旧口径。**

`QAB/F≈0.7279、FMI≈0.7011、VIF≈0.3982、NAB/F≈0.0660` 属于历史 `paper` 评价口径。现行 `reference_v2_candidate_with_paper_fmi` 的已有历史 E2 复评中，对应 QAB/F 为 0.812894、NAB/F 为 0.020025，FMI 为 0.701122、VIF 为 0.398218。这里是不同评价口径下的记录说明，不是模型性能提升表。[现行已保存复评表](../test_result/qxs_reference_v2_legacy_fmi_test1000_v1/comparison_14_metrics.csv)

不能把旧 NAB/F=0.0660 设成新协议下的准入门槛，也不能将历史 R3 初始化 E2 的 test1000 直接当成 train1024/val64 光学 Base pilot 的匹配对照。复评数字仅用于澄清口径，不用于当前结构选择、阈值调整或候选调参。

**接下来的投入建议。**

| 层级 | 建议 | 进入下一步需要什么 |
|---|---|---|
| 研究主问题 | 固定 LWPD 后改善两源有效结构的融合传递 | 最终图像收益，不能仅靠可恢复性或门值 |
| 递归候选 | 保留 GDN2；跨源条件作为独立变量 | 有效有符号输入、后端/数值可用，随后通过卷积、KDA、tied 门控制 |
| 工程候选 | 最小 INN coupling 与同宽普通双分支配对 | 相同最终选择头下，证明可逆约束有超出容量及普通交互的结构收益 |
| 后续骨干 | Mamba-3 SISO/MIMO | 先有稳定成图信号，再检验秩与联合输入的贡献 |
| 暂缓 | 新 MoE、RF、NODiff 式扩散、KAN 大改造 | 先给出当前缺口和匹配控制，不因新论文同时扩线 |

如果只看实现难度，普通 PyTorch coupling 可以比 Triton GDN2 更早完成原型；这不等于它的融合成功概率已经更高。若希望低成本筛查 INN，第一轮就要把同宽普通双分支作为配对控制，否则无法回答当前争议。若主攻递归，则先完成 GDN2 的数值和有效输入准入，再安排一个新增 pilot；不把所有候选同时训练。

后续新模型默认整套从头初始化，保持匹配 pilot 的 Base/Decoder、原损失、train1024/val64 与预算，复用已有适用 E2 对照。判定同时看光学困难边、SAR 独有边和孤立目标、共同边及误连负例，联合报告完整 14 项指标，固定配置后再扩大验证。结构训练不使用人工标签；若使用既有人工核查样本，仅作独立评价，不能用于挑条件或阈值。

统一现行评价口径，逐项使用共同有限场景并报告样本数；新结果写唯一目录、登记注册表，只在相同 `comparable_group` 内合表。没有新增实验结果时不改注册表或重建生成表。本轮只有核验报告，没有新训练入口，因此不提供尚不存在的脚本命令。

**可以保留材料的“信息保护应先于盲目增强”这一动机；需要撤回“因此可逆网络最可能成功”的推断。真正待解决的是最终选择如何利用有效的双源内容，可逆性与更强递归都只是可检验的工具。**
