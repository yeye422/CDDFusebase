# E2-BGC1：有界的 SAR 梯度目标修正方案

日期：2026-11-04。设计提案，尚未实现或训练，不代表已验证收益。

## 决策与目标

推荐先实施一个独立、保守的损失消融：Bounded Gradient Correction，简称E2-BGC1。保持E2网络、强度项、重建项、梯度L1形式、外部权重和训练协议，仅修改SAR主导位置的梯度目标。

研究假设：原最大梯度监督可能奖励SAR中局部方向不一致的高频起伏；对这部分梯度目标轻度衰减，有机会改善NAB/F，同时避免G1的大幅SAR信息损失。方向不一致不是噪声标签，本方案只把它用作有限修正的证据。

这是依据现有失败结果提出的工程候选，不是已发表方法的直接复现；不宣称具备论文级创新性，不承诺MI/VIF等全部改善。

## 1. 保留原目标主体

定义A_X = |Sobel_x(X)| + |Sobel_y(X)|。使用原E2未归一化Sobel核及原padding。

有效SAR像素处原目标：T0 = max(A_O, A_S)。无效SAR处T0=A_O。

总损失仍为：

L = L_I + 10 * mean(|A_F - T_BGC|) + 0.1 * L_R。

L_I、L_R逐项保持当前E2实现。不加融合SSIM、不换Huber、不改变梯度方向表示、不添加可训练模块。

## 2. 只估计SAR自身的局部方向一致性

从SAR独立有符号Sobel梯度gx、gy计算结构张量：

Jxx = K * gx^2；Jyy = K * gy^2；Jxy = K * (gx*gy)。

K固定为5×5、sigma=1.0、和为1的高斯核。它只平滑张量分量，不替换网络输入或梯度幅值目标。

C = clamp(sqrt((Jxx-Jyy)^2 + 4*Jxy^2) / (Jxx+Jyy+epsilon), 0, 1)。

epsilon=1e-6，FP32计算，C全程StopGrad。C高表示局部梯度主要沿一致方向；C低表示局部方向较分散。真实交叉路口、角点、点目标、复杂纹理也可能C低；定向散斑也可能C高。因此C仅为方向一致性证据，不叫“真实结构置信度”。

不乘光学PA，不要求跨模态共识，不使用新的相位阈值或语义模型。SAR独有长线与边界也可以有较高C。

有效支持V7要求整个7×7邻域SAR有效（3×3 Sobel与5×5张量窗口的联合支持）。图像外部按无效处理，外侧3像素禁用新修正。计算C前将无效SAR值置零，防止NaN；仅在V7=1处使用修正，避免该填充值进入被修正像素的张量证据。原梯度主路径保留原逻辑，不借本轮改动修复其边界策略。

## 3. 只削减SAR超过光学的部分，幅度有界

D = relu(A_S - A_O)。

R = V7 * (1-C)。

T_BGC = T0 - eta * R * D，首轮eta固定0.10。

无效SAR像素直接T_BGC=A_O。SAR目标计算与C均从输入构造并detach，不能由网络操纵。

解释：

- 光学梯度占优：D=0，与E2完全相同。
- SAR占优且方向一致：C接近1，接近原E2目标。
- SAR占优且方向分散：最多衰减SAR超额梯度的10%。
- SAR独有结构、光学没有响应：仍保留至少90%的原SAR梯度目标，绝不整体回退为光学。
- 无效邻域及边界：禁用修正，沿用原E2目标。

## 4. 可证明的性质与不能保证的结果

对有效像素：

A_O <= T_BGC <= T0；0.9*T0 <= T_BGC。

eta=0时，必须逐值恢复原E2损失与输出梯度（使用同一前向图和原Sobel路径，不只做近似数值比较）。

由绝对值损失的Lipschitz性质：

|L_G_BGC - L_G_E2| <= eta * mean(R*D)。

这是目标与损失值变化界，不是模型参数、融合图、QAB/F或NAB/F的变化界；非凸训练仍可能放大小改动。至少90%指目标幅值，不代表保留了90%的真实SAR信息。

## 5. 与前两轮的差异

E2-S新增原始SAR局部统计量监督，可能额外奖励散斑；BGC1不增加这类监督。E2-G1替换成大范围光学fallback且限制SAR增量，BGC1保留双源梯度保留机制，只小幅下调部分SAR超额目标。

此前“原E2+弱PA方向项”更适合定位PA方向证据的独立增益；BGC1直接针对当前幅值目标中的噪声压力。两者不同时实施，以免无法归因。

## 6. 预期收益与主要风险

预期首先是小幅降低NAB/F、减少碎片状高频，同时尽量维持QAB/F、FMI及SAR独有线状结构。MI/VIF方向未知，不预报改善百分比。

主要风险：

1. QAB/F也会奖励部分被削减的SAR梯度，可能随NAB/F一起下降；这意味着仍未通过既定目标。
2. 交叉结构、点目标和真实随机纹理可能被误衰减，虽然目标改动最多10%，仍需固定样例检查。
3. 结构张量不能识别所有散斑，可能收益接近零。
4. 强度项仍匹配max(O,S)，原SAR亮点也可能经该路径进入输出；因此本轮只能检验梯度监督修正，不能解决全部伪影。
5. SAR已是8位处理图，C不是基于原始复数SAR数据的统计估计。

## 7. 实施前工程检查

必要单元检查：eta=0完全回归；上述目标上下界；光学占优不变；全无效SAR光学回退；无效NaN不进入新证据；C与目标无反传；E2完整前反传有限。

固定少量样本（不做全数据搜索）检查：

- 真实SAR独有亮线、角点/点目标、平坦散斑、跨模态共同边界；
- C分布、R分布、修正像素占比、目标下调均值和分位数；
- 原E2/B、G1、复制光学、复制SAR输出在新旧损失下的分项代价；
- 新旧梯度损失对融合输出的梯度方向、范数，避免只看损失数值。

这些诊断只检验机制，不能据其挑选验证集最优eta。首版只测试eta=0.10，不默认执行阈值/核大小/权重网格。

训练日志额外保存AMP scale、跳步计数，以及新旧梯度损失（旧项只诊断、不加入优化）、mean(C)、mean(R)、mean(T0-T_BGC)。区分梯度范数统计溢出与真实非有限梯度。

## 8. 唯一首轮实验与验收

沿用现有E2-B：lwpd_e2、R3初始化、seed42、8000/1000/1000固定切分、batch2、累积4步、16轮（2+4+10），优化器、AMP和学习率策略不变。只新增BGC1，不重训B，不从已训练B继续微调，以免改变训练预算和初始化。

最终固定epoch_016.pth，不根据验证指标事后挑checkpoint。建议独立目录models/e2_bgc1_v1/bgc1_seed42与test_result/e2_bgc1_v1/val1000/bgc1_seed42，实施时建立包含参数和源码哈希的协议锁。

直接对照使用已有匹配B。原E2保留为历史性能底线，不能混用历史均值和匹配B均值来计算改善率。正式验证沿用原paper协议，保存全部图像和14项逐图指标；完成后登记EXPERIMENT_REGISTRY.json，并检查生成索引。只有相同比较组才汇总定量表。

沿用既定成功标准：NAB/F<=0.067842，QAB/F不低于匹配B，MI/VIF相对匹配B改善；并检查FMI/SCD及固定SAR目标样例，防止单模态退化。同时要求NAB/F相对匹配B确有下降，体现本方案抑制伪影的预期价值。对NAB/F、QAB/F做配对Bootstrap，区间不替代训练种子方差。

如果仅NAB/F改善而QAB/F下降，记录为取舍，不能宣布成功或事后放宽门槛。如果收益过小，先查修正实际作用，不自动扩大eta或追加训练。
