# C 区域均衡通道关系单场景机制诊断

2026-11-13。使用 `models/e2_scratch_base_anchor_v1/seed42/epoch_016.pth`，在 QXS-SAROPT 的既有验证场景 4 上做冻结权重干预。该场景是原审查已展示的近 SAR 个案。实际运行采用 CUDA FP32，并关闭 TF32。诊断脚本重建的原全局算子与当前模型正常前向逐元素一致。与历史归档 PNG 相比，重新推理的灰度最大绝对差为 1，平均为 0.0266。以下对照均以本次重建的全局输出为基线。

## 干预与对照

- 目标区为中心 `[112, 144) × [112, 144)`。仅改动投影后 SAR Q/K 的顶部和底部各 64 行。Encoder 与 LWPD 只产生一份供各干预复用的特征，原位置 V、目标区 Q/K、光学投影、Detail 源特征和各层权重固定。Base 变化仍可经 Detail 融合及 Decoder 传播。
- 幅值干预按远端每个 32×32 统计块、每个 SAR 通道对 Q/K 各施加 `4x + 2 × RMS(x)`。错配干预在同一批块内把有效 SAR Q/K 像素共同循环移位半个有效样本序列，保持块内 SAR 的边际分布。
- 对照依次为原全局、普通局部余弦、去均值局部、完整 C。三种局部对照使用同样的 32×32 窗、16 像素步长、固定三角权重重叠合成，沿用原温度。完整 C 另外混入 50% 的非重叠窗口先验，按有效面积聚合有效通道对。SAR 有效像素按项目训练数据的 `SAR > 0` 规则定义，本场景有效率为 100%。
- 随机张量验证了去均值关系对正仿射变换的不变性，也检查了全无效和常量通道的回退输入。Scene 4 的两个方向共有各 225 个重叠窗口，局部去均值关系与均衡先验的窗口 RMS 平均约为 0.14 和 0.15。

完整 C 的全图光学相似性增加 0.00608，SAR 相似性下降 0.01079，平均 SSIM 和 MS-SSIM 同时下降，SCD 下降约 23.4%，VIF 下降约 13.8%。目标区的光学 SSIM 从 0.04855 到 0.05319，SAR SSIM 从 0.99879 到 0.98935。在保存的 8 位输出上，目标区的水平与垂直一阶差分拼接后，与光学的相关系数从 0.02165 到 0.02378，与 SAR 的相关系数从 0.99844 到 0.99653。用原全局输出对完整 C 的目标区输出拟合单一亮度增益和偏置，拟合前后差值 RMSE 从 10.48 降至 2.74 灰度级。该样本上输出变化很大一部分可用亮度和对比度解释，光学梯度一致性的增量很小。

这次验证确认了现有全局交互存在远端统计耦合，也复现了 C 的幅值稳定性及先验对远端关系变化的敏感性。Scene 4 的冻结替换没有达到结构与信息联合收益门槛，当前证据不足以启动完整 C 训练。强扰动用于定位因果路径，无法估计自然场景中远端混合造成的误差大小。冻结替换沿用对原全局关系训练过的投影、温度和输出层，其指标不能当作重训候选的性能估计。
