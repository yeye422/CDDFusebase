# LWPD E2作为第一机制：第二创新机制方向分析

日期：2026-11-18。第一机制按用户要求确定为LWPD E2。本轮复核已有结果、代码和原始论文，未训练新模型，未执行数据集推理或批量测试。

**建议把第二机制的研究方向收敛为“面向源结构保留的Detail融合传递”，优先验证结构关系能否帮助已有两源内容进入最终融合图。** 第一机制负责分解和方向调制，第二机制研究融合中的结构取舍。当前可以锁定研究问题与优先插入位置，尚不足以宣布某个具体算子已构成有效创新。

## 1. 第一、第二机制的边界

第一机制LWPD E2保留固定Haar分解、方向上下文门控及其已有LL调制，不加入E3的SAR恢复或E4的相位对称扩展。第二机制首先放在LWPD之后、两源Detail聚合的位置，第一版保留Base融合方式、Decoder结构和原训练损失，便于识别新增机制的作用。

还要区分两个完整模型：

- 历史 `lwpd_e2` 使用R3初始化，已有test1000。
- 当前多数冻结定位使用 `e2_scratch_original_loss_pilot_v1`，属于光学Base保留版、train1024/val64的小试模型。

用户确定的是第一机制。光学Base保留路径、训练初始化及数据预算不能悄悄并入“LWPD E2的贡献”。下文的定位数值主要适用于对应pilot权重；若论文主模型选历史E2的Base结构，应复用相应权重核对关键现象后再迁移结论，不因此默认安排基线重训。

## 2. 历史定位已经支持什么

### 2.1 首要问题是源信息进入输出后的不对称

同一冻结pilot的val16中，光学候选边缘的单源重建传递系数为0.961，融合图为0.333；SAR对应为0.954与0.931。光学融合传递中位数仅0.100。

这表明源端存在能在单源路径呈现的光学候选信息，融合路径没有同等保留。**单源重建同时使用Base与Detail，因此它不能单独证明这些信息全在Detail里，更不能证明只改Detail就一定解决。**

来源：[FCSR原始summary](../test_result/e2_fcsr_decoder_diagnosis_v1/val16_seed42/summary.json)、[源路由原始summary](../test_result/e2_detail_route_localization_v1/val16_seed42/summary.json)。候选由源图梯度规则产生，不是人工确认的结构真值。

### 2.2 衰减涉及聚合与解码方向响应

等输入RMS扰动下，逐图计算再平均的光学/SAR增益比，从源投影1.210、多尺度分支1.137，变为fused Detail 0.906、最终图像0.572。

因此，光学最早投影并非整体更弱；两源特征进入后续组合与共享Decoder时，响应方向发生了不同处理。Decoder对Detail fine探针的图像增益约6.82，也不支持“Decoder普遍传不过高频”的解释。

**可以优先排查聚合，不能把某个1×1层或Decoder定为已证实的唯一故障点。** Early/Late等效干预结果接近，也不足以把所有问题归给某一条多尺度支路。

来源：[源路由summary](../test_result/e2_detail_route_localization_v1/val16_seed42/summary.json)、[Decoder summary](../test_result/e2_fcsr_decoder_diagnosis_v1/val16_seed42/summary.json)、[等最终影响summary](../test_result/e2_equal_final_effect_v1/val16_strength004_seed42/summary.json)。

### 2.3 “增强光学、减小SAR”还不是机制答案

匹配最终图像MAE后，直接正向增加光学投影方向，early/late的QAB/F、NAB/F和VIF均值均朝不利方向变化，光学候选传递也略降。沿某个光学特征方向放大，不等于增强光学边缘。

SAR负向干预有小幅指标收益，但仍使SAR候选传递下降；另一种Detail-RMS匹配下FMI均值也会下降。DRF固定分离、方向收缩及人工背景移除又没有稳定超过等幅简单控制。

**研究目标应是改善有效结构的传递方式，不能将源幅值比例直接当作结构保留率。** [等效干预](../test_result/e2_equal_final_effect_v1/val16_strength004_seed42/summary.json)、[DRF](DRF_冻结E2等幅分离诊断_20261117.md)

### 2.4 监督偏向存在，但换损失尚未解决问题

val16全有效区的原最大梯度目标约82.45%由SAR提供；光学候选区该比例为43.74%，原总损失与光学边缘代理梯度的平均余弦约0.021。因此全局SAR监督较强，不能推广为每条光学边界都存在强负冲突。

另一个8图参数梯度诊断确有稳定负余弦；但GCO单侧投影、OKD和G1没有建立最终结构收益。强行拉向光学又可能压掉SAR独有内容。

新机制必须给两源独有信息保留机会，并与原监督共同适应；“等权”“梯度正交”或“光学教师”本身都不是质量保证。[梯度诊断](../test_result/e2_subspace_gradient_diagnosis_v1/val16_seed42/summary.json)、[GCO](../test_result/e2_gco_virtual_update_v1/train8_val8_seed42/summary.json)、[OKD](OKD_冻结E2梯度对照_20261117.md)

## 3. 对局部对应正结果的进一步收紧

已有局部交换候选在val64改善QAB/F、NAB/F、FMI、VIF和平均SSIM，但SCD、MS-SSIM下降。复核现有diagnostics.csv得到：

- 平均 `match_mass` 为0.112738；平均 `offcenter_mass` 为0.100181。
- 逐图外移质量占比的均值为88.8618%，接近3×3均匀邻域的8/9。
- 两源完全零交换位置的平均占比分别仅约0.176%和0.132%。
- 全64图的光学SSIM平均只增加0.000116，SAR增加0.005509。
- 按基线 `SSIM_S>0.95` 固定的36张图中，光学SSIM平均下降0.000669，SAR增加0.003861。

以上仅汇总已有CSV，没有重新推理。来源：[候选诊断](../test_result/e2_scratch_local_correspondence_pilot_v1/val64/seed42/candidate/diagnostics.csv)、[E2诊断](../test_result/e2_scratch_local_correspondence_pilot_v1/val64/seed42/e2/diagnostics.csv)、[配对指标](../test_result/e2_scratch_local_correspondence_pilot_v1/val64/seed42/paired_comparison.csv)。

平均质量接近均匀参考，**不能证明每个位置都均匀**；完全零交换比例也不是软拒配概率。它们说明现有汇总尚不足以证明网络利用了正确几何对应。收益可能来自邻域上下文、平滑、分支容量或重新训练。

因此，局部交换可保留为工程控制，暂不把“拒配与有效对应”定为第二机制核心，更不优先通过继续调温度或搜索窗口追求指标。

## 4. 推荐主方向：由结构关系支持两源内容的融合传递

### 4.1 研究假设

在E2已经给出两源表示的前提下，**源内空间关系能否帮助融合器保留有结构支撑的内容，并使这些内容在最终图像上可辨认？**

这个方向包括三个应分别验证的要点：

1. 光学、SAR分别形成源内关系证据；单源结构不需要另一源高相似才有资格保留。
2. 两路原位Detail继续提供成图内容；关系用于组织内容，避免直接搬运远处纹理或由低分辨率先验生成细线。
3. 成功以输出中的结构传递、误响应和14项融合指标联合判断；关系热图、门值或PCA恢复率只作诊断。

其中第1、2点是候选设计，第3点是必须满足的证据要求。**目前尚未证明“缺少结构关系”就是根因；它是比再增加频率增强更值得检验的下一假设。**

### 4.2 第一版接口与插入位置

```text
Optical / SAR
    → 原共享Encoder
    → 原LWPD E2
    → Bo, Do, Bs, Ds
         ├─ 原Base融合 → Bf
         └─ 两源原位Detail投影
                  + 各自结构关系条件
                  → 源别独立的条件变换
                  → 原多尺度聚合接口 → Df
    → 原Decoder → Fused
```

优先接口放在 `MultiScaleDetailFusion` 两源投影之后、共同聚合之前。先保持Base和Decoder的结构，避免一次改动多个环节。

候选可抽象为：

`z'_m = z_m + Δ_m(z_o, z_s, Bf, R_o, R_s), m∈{o,s}`

`Df = Aggregate(z'_o, z'_s, Bf)`

这里Δ是待验证的源别条件变换，不是已确定的算法。首个机制探针可用受限的残差调制；两源系数独立，不强制和为1，也不令“跨源不匹配”自动关闭某一源。零初始化只保证与**同次初始化的原接口**相容，不默认加载已有E2训练权重。

简单残差、独立门或额外卷积已很常见，单独不能构成第二创新点。只有正确关系优于同容量普通上下文、打乱关系以及简单幅度控制，并且改善最终结构，才有进一步发展为完整模块的依据。

### 4.3 结构关系首先从哪里来

先检验低成本源内关系：共享编码特征的局部/区域自相似，或源图内经过适当归一化的结构关系。关系描述与成图value分开。

需要避免两个历史问题：

- 直接对重建后的Haar Detail做对齐2×2平均池化会抵消信号。条件可从共享特征或幅值/能量统计构造；原有符号Detail内容不通过该平均池化路径。
- 相似性、连续性或稳定性都不是结构真值。必须保留断开负例、孤立目标和两源独有边界，避免把相似区域误连或把罕见目标删掉。

首轮研究的重点是“关系是否提供超出普通上下文的选择依据”，不叠加低秩分解、图连接、SSM和教师损失。

## 5. MaRS的合适位置：条件来源备选

现有v3检查的是MaRS阶段0/1、灰度复制输入、PCA32及线性读出。它证明浅层特征有像素梯度读出增量，但没有通过困难线段与负例筛查，不能视为可直接接入的结构教师。

本地进一步审查发现阶段2/3权重实际存在，网格在512输入下为32×32和16×16，能提供较粗的空间上下文；v3没有评价这部分。**浅层失败不能否定深层关系，深层存在也不能证明有用。** [本地MaRS机制审查](MaRS_机制审查与接入研究_20261118.md)

若低成本关系方向值得继续，或需要检验强先验的额外价值，可独立验证：

`冻结MaRS深层 → 区域关系条件 → 组织E2原生Detail → 原Decoder`

条件对照至少包括E2自身关系、低成本结构条件、普通预训练SwinV2、空间打乱MaRS关系。保持输入信息相同；使用RGB时单独控制颜色信息。随机SwinV2残差初始化存在有效秩退化的问题，不能仅凭击败随机网络就归因于MaRS跨模态预训练。

当前没有本地MaRS SAR权重及原MMA权重。RGB分支不能独自判断SAR结构真假，新建attention也不能称为恢复已预训练MMA。关系蒸馏应等待在线条件首先证明融合收益。

MaRS原论文面向多模态预训练及下游任务，不能直接用其下游成绩推算本项目像素融合增益。[作者仓库](https://github.com/WanderRainy/MaRS)、[论文入口](https://ojs.aaai.org/index.php/AAAI/article/view/38153)

## 6. 其他方向的当前优先级

此表为研究判断，不是跨比较组的性能排名。

| 方向 | 当前证据 | 判断 |
|---|---|---|
| 源内关系支持的源结构传递 | 源端到融合图的不对称已定位；关系的额外作用未证实 | 主研究方向，先验证一个小接口 |
| MaRS深层关系条件 | 深层可用；现有浅层筛查不足以推进 | 条件来源备选，先做针对性准入 |
| 局部匹配/拒配交换 | 有全图指标收益；对应特异性、光学补充未成立 | 工程控制与机制消融 |
| PCA/可逆耦合/RICF | 线性可恢复性更好；有效结构与噪声未分清 | 不直接升级为成图主模块 |
| 四起点/采样稳定性 | 两批验证支持稳定性，原位画质仍有代价 | 适合E2稳健性扩展，独立第二点较弱 |
| LL状态、位置码、方向Mamba | 内部响应或工程可行，未建立融合收益 | 不作为当前首选 |
| STG/跨源拓扑补全 | 现有缺失正例没有显示必须双源接续，误连代价明显 | 暂缓当前路线 |
| 强光学约束、全局SAR削弱 | 已多次出现退化或结构代价 | 保留为必要简单控制 |
| 单纯再加结构/过冲损失 | 多个完整训练未取得联合改善 | 不先堆叠损失，作为监督因素单独定位 |

RBCF的Base区域均衡也不再首推：单图冻结干预证明统计耦合存在，却未得到结构—信息联合改善。[C诊断](C区域均衡通道关系_单场景机制诊断_20261113.md)

## 7. 新颖性必须落到可检验的差异

本轮核对的邻近原始工作表明，以下宽泛说法都已有直接近邻：

- WEMFusion已有小波先验、方向增强及差异驱动Mamba；第二机制若继续称“方向/频率增强”，与E2本身及已有工作重合较多。[WEMFusion原文](https://www.mdpi.com/2072-4292/18/4/612)
- UniFusion已有冻结DINOv3、Adapter及源重建对齐；“大模型+保留源信息+重建损失”不能单独视为新机制。[UniFusion原文§3](https://arxiv.org/html/2603.14214v1)
- ISFuse已有遮蔽/模态丢弃干预和不变性门控；“干预指导可靠性”同样需要明确不同的算子与目标。[ISFuse原文§3](https://arxiv.org/html/2603.23272v1)

本方向可能形成的具体贡献是：**用保留源别的结构关系条件组织E2内容，并建立关系干预、源结构传递、最终融合收益之间的一致证据。** 仅有这个研究表述还不能认证新颖性；候选算子确定后仍须与最接近的方法逐项比较。

“解码响应校准”目前更适合作为设计与评估原则：比较同最终影响强度下的真实/打乱条件、两源结构响应及误响应。若进一步把这些响应写进训练目标，应另开算子×监督的消融，不能把监督收益全部计入结构模块。

## 8. 最小验证顺序与停止条件

### 第一步：用现有权重和输出确定目标现象

复用已有单源重建、源路由和等效干预结果。结构读出沿用固定评估集，分别检查光学候选、SAR候选、共同边、孤立亮目标与不应连接位置。必要时只补关键模型版本上的缺失核查；不重跑已完整的历史诊断。

人工missing样本少，原梯度候选又不是结构真值，应将二者分开报告。已有人工验证线段不用于训练新条件网络或挑阈值。

### 第二步：只训练一个新增小试候选

若进入实现，沿用适用的train1024/val64、4轮源图重建+12轮融合、seed42，从头初始化融合模型，保持原损失与适用的Base/Decoder结构，复用已有匹配E2对照。先回答是否有真实自然图收益；不默认运行一套教师、图、SSM和多损失组合。

必须同时报告：

- 光学候选/已核查困难边的传递是否改善；
- SAR独有边与孤立目标是否被保留；
- NAB/F是否受控，QAB/F、FMI、VIF的收益是否与结构读出一致；
- SCD、MS-SSIM以及误连、极性反转是否出现代价；
- 每项指标共同有限样本数、逐图值和配对不确定性。

容许退化幅度应在看新结果前约定，不能靠事后只选有利指标判定通过。val64已多次用于开发，不称为全项目未见验证集。

### 第三步：有收益再做机制归因

依次补相同接口、近似参数量和匹配训练预算的控制：

1. 普通局部上下文条件；
2. 保留关系取值分布、破坏位置对应的条件；
3. 同输出变化强度的简单源增益/衰减控制。

若真实关系未超过前两项，不主张关系机制成立；若同幅度简单控制即可解释收益，不主张学会了结构选择。若只提高关系读出、未改善实际输出，不追加更大的先验来掩盖缺少成图收益的问题。

### 第四步：确认与两创新点的可分离性

最终需要“原融合架构、仅E2、仅第二机制、E2+第二机制”的消融证据。尽量使用通用 `Do/Ds/Bf` 接口，使第二机制能在无E2版本运行；不能让它只能读取E2专属中间量，却又声称完全独立贡献。现有结果满足条件就复用，缺失项另列成本，不默认重训全部基线。

之后再考虑full val1000、种子稳定性及固定配置的test1000。继续采用 `reference_v2_candidate_with_paper_fmi`，新路径使用唯一目录，按规则登记同组对照与元数据。

本轮尚未实现这个新候选，因此没有可直接运行的新训练入口；本次只完成方向分析，没有启动任何训练或批量评测。

## 9. 建议的论文机制表述

第一机制：**LWPD E2——方向上下文调制的特征分解。**

第二机制的研究表述：**结构关系支持的双源信息传递——在保留两源独有内容的前提下，改善已有结构从融合特征到最终图像的呈现。**

现有证据支持这个研究问题及验证优先级。具体条件来源、融合算子和训练约束仍应由受控结果决定；MaRS、Mamba、可逆性或某种注意力名称都不预先等同于第二创新机制。
