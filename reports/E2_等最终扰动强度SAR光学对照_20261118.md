# E2 等最终扰动强度的 SAR / Optical 冻结因果对照

日期：2026-11-18。已实现脚本与单元测试，真实 QXS-SAROPT 数据尚未运行。目标不是搜索最好融合指标，而是排除旧实验“同注入 RMS、不同最终影响强度”的混杂。

## 旧实验提示

此前归档 val16、同源投影 4% 正负干预中，最终 fused Detail delta RMS 的 Optical 均值约 0.000172、SAR 约 0.000335；非量化输出图的 MAE 约 0.080 与 0.414（灰度级）。同图十二组条件的最终 Detail RMS 最大/最小比值中位数约 2.3，图像 MAE 最大/最小比值中位数约 9.3（来自旧全逐场景 CSV）。不能直接说 SAR 减弱有特殊优势；幅度混杂明显。

## 新实验方法

复用原 E2 pilot epoch_016、同一锁定 val64，默认均匀选16张，允许 val64。全部模型和权重冻结，不训练新模块、不访问 test1000。

两种**独立校准**：

1. detail_rms：控制融合器最终 64 通道 fused Detail 相对原输出的 RMS 改变量完全相同；
2. image_mae：控制未量化最终融合灰度图的绝对 MAE（乘255）完全相同。

单个场景、单个校准口径，先在**全部12种候选（Early/Late × Optical/SAR/错位光学 × 正负）**上测原始投影节点 4% 注入的输出效应；从这12个响应中取最小值的90%，作为整个场景该口径的唯一共同目标。此目标在读取 QAB/F、NAB/F、FMI、VIF 等评价指标之前产生，只由效应大小决定，**不通过质量指标寻找有利的强度**。

对每个候选把原输入注入 RMS 降低，迭代求解该共享目标。**输入不允许超过旧实验4%幅度**。每组绝对匹配误差除以目标不得超过2%，否则整次实验报错，严禁自动把不匹配项纳入对比。

### 控制节点与条件

- Early：在 Optical/SAR 32通道 GELU 后投影注入，重算三条 dilated 分支与最终 Detail。
- Late：只在最终 concat 后的直连 Optical/SAR 槽位注入；三尺度分支冻结于原前向输出。
- Optical：原 Optical 投影方向。
- SAR：原 SAR 投影方向。
- Shuffled：原 Optical 投影经过通道重排与循环空间位移。
- 每个方向都测 + 和 −，不选事后最好符号。

每个场景、每种匹配口径下，Early/Late、两种符号和三种来源的**最终效应强度使用同一目标**，因此允许对照层位置与来源方向。不过两种校准口径分别构成独立实验，不能把 detail_rms 匹配等同于 image_mae 匹配。

### 读出与判断

使用统一 reference_v2_candidate_with_paper_fmi + clamp round uint8，输出完整14项逐图指标，以及原 Optical/SAR 候选梯度的有符号传递系数、量化前图像 MAE、量化后改变像素比例、实际 fused Detail RMS 和校准输入 RMS。单源边缘候选定义继承既有 FCSR 冻结诊断，不是人工结构真值；SAR 候选可能是散斑。

同图、同节点、同符号对照：

- Optical−SAR
- Optical−shuffled Optical
- SAR−shuffled Optical

对每项指标取两边都有限值的共同图像；报告配对差均值、中位数、改善图数及 n，不跨比较组混用旧 paper 口径。低 NAB/F 为好，QAB/F、FMI、VIF、SCD、SSIM 等高为好。

### 如何决定后续路线

- 若两种校准口径下 SAR 负向仍在多数图上优于光学与错位方向，改善 NAB/F/QAB/F/VIF 且不显著牺牲 FMI 与源结构传递，支持进一步研究 SAR 方向的选择性约束。
- 若等效后差异消失，旧实验收益更可能由大幅度图像影响解释，停止全局 SAR 衰减方向。
- 若只改善 NAB/F 但 SAR 候选响应下降、FMI 下降，不认定融合质量提高，也不直接训练。
- Early 与 Late 受相同输出效应校准后仍有差异，才可进一步定位多尺度分支的方向依赖。
- 即使筛选通过，也仅有冻结局部推演证据。真正的第二创新点须通过等参数量、匹配 train1024/val64 的重新训练与外部验证。

## Windows CMD

    cd /d "D:\#imageInfusion\CDDFuse"
    git pull --ff-only origin main
    .venv\Scripts\python.exe -m unittest -v test_e2_equal_final_effect
    .venv\Scripts\python.exe diagnose_e2_equal_final_effect.py

若需要全部64张验证图：

    .venv\Scripts\python.exe diagnose_e2_equal_final_effect.py --val-scenes 64 --save-images 8 --output-dir test_result\e2_equal_final_effect_v1\val64_strength004_seed42

默认 strength=0.04，target-fraction=0.90，匹配误差阈值2%。修改参数需要独立输出目录，不允许覆盖旧档案。输出会登记到 EXPERIMENT_REGISTRY.json 并运行 maintain_experiment_index.py --check --render。

## 输出

test_result/e2_equal_final_effect_v1/val16_strength004_seed42/

- nominal_effects.csv：原12组4%输入引发的真实 final Detail RMS、图像 MAE，以及两个共享目标。
- matched_all_metrics.csv：baseline 和12组×2种校准的完整14项、候选结构传递及校准日志。
- matched_contrasts.csv：同场景同位置同符号同口径的三种对照差值。
- summary.json：所有配对统计、有效样本数、最大校准误差和元信息。
- run_metadata.json：可归档的原始模型/manifest 哈希、设置。
- images/：默认前4张场景的干预后灰度图。

**本版本仅实现执行入口，没有真实 QXS 结果；所有收益判断须由本地运行后给出。**
