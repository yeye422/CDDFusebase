# RCT结构预测增量到实际成图：验证协议

日期：2026-11-18。状态：**用户已完成真实数据预测头拟合、val64预测与16图冻结成图；当前版本未通过联合筛查。** 结果见[分析报告](RCT_预测增量与成图结果分析_20261118.md)，以下保留原预定验证协议。第一机制沿用LWPD E2，复用归档光学Base版原损失pilot，不新增完整融合网络训练、不加载外部基础模型、不访问test。

本次问题分为两层：正确另一源是否提供本源上下文之外的结构预测增量；这种条件在相同成图扰动强度下，是否比简单条件更有利于最终源结构保留。

## 1. 本轮实际验证什么

- 预测器是固定HOG目标的**线性Ridge探针**；闭式拟合只使用训练图，E2不参与预测头拟合。
- 成图使用**冻结E2上的固定源Detail插值**，没有训练新的RCT条件变换网络。
- 固定插值可能进入原融合器未训练过的特征分布；失败也可能来自插值算子，不能据此认定关系无信息。
- 正结果最多说明该线性条件与固定成图接口具有局部可行性；失败不能排除非线性预测器或其他RCT算子。
- 实际成图、完整14项指标、梯度候选和既有人工线段一起读出，不把预测loss下降直接写成融合成功。

当前E2权重：`models/e2_scratch_original_loss_pilot_v1/seed42/epoch_016.pth`。启动时校验其归档SHA和manifest；光学Base pilot与历史R3初始化E2的完整模型不同。

## 2. 固定划分与预测目标

复用锁定的train1024/val64 manifest。默认从train1024均匀选128图，每4张中的第4张用于训练域校准：**96图拟合、32图校准**。两部分ID不重叠，均不进入val。

预测在全部val64评估。其中固定STG人工8图与后续轮廓复核8图共16图单列，其余48图是预测增量的主要检查集。这48图仅与人工16图区分，不是地理独立、全项目未见数据。

源图经固定5×5平滑、Sobel、9方向软直方图与局部归一化，再按4×4网格汇集。每格目标的原图支持宽度为12像素。输入本源上下文取8个相隔3格的位置，原图中心相隔12像素，支持域不与目标格重叠。整个预测路径不读取E2的全局混合特征，避免“完整图先编码，再遮特征”的目标泄漏。

SAR零值支持会经过完整描述子支持域传播。所有预测头在同一场景使用完全相同的有效位置和抽样索引。

## 3. 预测层对照

| 名称 | 输入 |
|---|---|
| constant | 仅训练集目标均值 |
| self | 本源8邻域上下文，额外槽为零 |
| self_wide | 相同上下文＋更远本源上下文 |
| cross | 相同上下文＋正确另一源的当前位置结构描述 |
| rolled | 相同上下文＋同图另一源的固定空间滚动描述 |
| swapped | 相同上下文＋固定错场景的另一源描述 |

后5种头的输入列数相同。rolled/swapped在拟合阶段也使用对应干预，并非只在评估时制造分布外输入。错场景映射是各自fit/calibration/val折内部的确定性无自配对置换，不混入测试图。

**额外输入先在训练集上对共同本源上下文作无标签线性残差化。** 这样重复已有上下文不能只通过减轻Ridge收缩产生虚假的跨源增量。保存有效秩和额外残差秩；相同列数不被解释为完全相同的有效容量。

每源分别使用训练统计标准化目标和输入，验证时不重新拟合。记录本源目标归一化MSE以及：

`Δ_context=e_self−e_cross`，以及对错位/错场景预测的配对增益。

主检查集至少16场景；预先固定的探索筛查要求：cross相对self、self_wide、rolled、swapped均有至少1%平均相对改善、正中位改善、场景bootstrap95%区间下界为正、至少60%场景改善。它不是外部验证或多重检验认证。

## 4. 从预测增量产生条件

原生条件为本源平滑梯度幅值，按32张训练校准图的95%分位标定。预测增量也只用训练校准图的正增量95%分位标定，不根据val选择阈值。

`R_predictive = R_native × clip((e_self−e_cross)/train_gain_scale,0,1)`。

该量表示受限预测器的增量条件，不命名为对应概率、真实噪声概率或独有性标签。高误差、负增量时只是不增加该方向修正，原E2路径仍存在，不能由此声称输出一定安全回退。

成图对照共6种条件：predictive、由训练匹配rolled/swapped头产生的条件、保持有效网格值分布的shuffled条件、native、uniform。shuffled按有效位置循环移位，保留网格值分布，但不保证空间平滑性完全一致；其他对照用于避免仅凭这一项归因。

## 5. 冻结成图与等效强度

默认实际成图选择已有人工标注的16图。先用原E2产生源Detail、fused Base和fused Detail，然后对两源分别测：

`D_f' = D_f ± α R_m (D_m−D_f)`。

fused Base、Encoder、LWPD、融合头、Decoder及其全部参数保持冻结。正向插值为预先确定的主方向；负向结果全部保存，仅作方向对照，不在看结果后改选有利符号。

每图共有24种干预（2源×6条件×2符号）及原E2。先测α=0.04时各干预引发的浮点融合图MAE，以其中最小值的90%作为该图全部24项共享目标。随后只向下调α，按最终图像MAE匹配，误差不超过2%。校准只读取效果强度，不读取QAB/F等质量或边缘指标。

若有条件完全没有输出效应，则该图不能建立完整等效对照，明确记录为效应不足，不把恒等或缺少激发解释成成功。新目录保存已完成产物；中途失败不覆盖旧文件。

每项另记录实际fused Detail变化RMS、量化后改变像素比例及条件作用区之外的图像变化份额，避免将输入幅度、输出幅度或空间外溢混为一谈。

## 6. 实际结构读出

1. **源梯度候选**：沿用FCSR的本源高梯度/另一源低梯度定义，记录光学/SAR有符号传递系数。这些是无标注代理，SAR候选可能包含散斑。
2. **人工线段**：复用两个固定8图的源图标注与E2可见性。根据源图在±6像素走廊内确定位置及极性，融合图读取相同位置。源响应至少2灰度级/像素才纳入源别读出。
3. **缺失正例**：记录有符号响应、达到源响应50%的连续性、最长连续段及反极性。
4. **disconnected负例**：固定走廊内读连续路径代理，检查不应连接的地方是否更容易形成长响应，至少12条线/3场景才具备自动安全筛查样本。
5. **14项全图指标**：使用`reference_v2_candidate_with_paper_fmi`及clamp+round uint8。每指标取所有方法共同有限的场景，保留逐图原值、均值、标准差、共同样本数及排除ID。

线段先按场景聚合，再做场景bootstrap。人工探针少、候选规则有偏；预览仍需目视复核，自动读出不是密集结构真值。

## 7. 联合判断

自动输出每源的证据链，不只给一个最高分：预测增量是否准入；正向成图的本源候选传递是否超过五种条件控制；另一源是否保留；人工缺失边是否有信号；负例是否受控；实际量化变化是否充分。

还要求QAB/F、NAB/F、FMI、VIF、SSIM、MS-SSIM、SCD相对本次E2的共同样本均值不退化。该条是保守探索筛查，不代表这些均值都统计显著改善。固定另一源候选传递容差为0.005，负例最长连续段增量容差为0.02；这些是预定操作阈值，不是理论保证。

只有预测与上述成图检查联合成立，才标为`local_frozen_evidence_requires_training`。否则标为当前固定算子的证据未建立，保留分项原因，不宣布所有RCT方案无效。0.333/0.961/0.931不作为本轮绝对验收线。

## 8. Windows CMD

一次完成头拟合、val64预测及16图冻结成图（**由用户运行**）：

```cmd
cd /d "D:\#imageInfusion\CDDFuse"
run_rct_predictive_transfer.cmd
```

分阶段执行：

```cmd
cd /d "D:\#imageInfusion\CDDFuse"
run_rct_predictive_transfer.cmd fit
run_rct_predictive_transfer.cmd evaluate
```

仅先检查预测增量，独立结果目录：

```cmd
run_rct_predictive_transfer.cmd evaluate --prediction-only --output-dir test_result\rct_predictive_transfer_v1\prediction_only_val64_seed42
```

将成图扩展到全部val64，复用已有头：

```cmd
run_rct_predictive_transfer.cmd evaluate --render-all --output-dir test_result\rct_predictive_transfer_v1\transfer_all_val64_seed42
```

变更拟合配置须同时指定新`--fit-dir`；变更成图配置须使用新`--output-dir`。脚本只复用配置、源码、数据与产物SHA都一致的完整结果；拒绝覆盖不完整或不同协议的目录。

## 9. 结果入口

- 预测头：`models/rct_predictive_transfer_v1/train128_seed42/probe.npz`，不使用pickle。
- 默认结果：`test_result/rct_predictive_transfer_v1/train128_val64_audit16_seed42/`。
- `REPORT.md`：自动生成的中文判读报告。
- `prediction_per_image.csv`、`prediction_comparisons.csv`：预测误差与增量。
- `per_image.csv`、`transfer_comparisons.csv`：实际成图指标、传递与配对结果。
- `per_probe.csv`、`source_probe_qualification.csv`：逐线读出及源图资格。
- `matched_effects.csv`：24条件的共同目标、实际强度、匹配误差和α。
- `metrics/`：逐方法14项指标、均值/标准差及共同样本数。
- `gray/`、`maps/`、`previews/`：灰度成图、条件网格与源图/E2/主要条件九宫格。
- `decision.json`、`summary.json`、`run_metadata.json`、`SUCCESS.json`：分项判断、溯源和完整产物校验。

产生真实结果后脚本自动登记预测头拟合、审计及同组各成图条件，并运行`maintain_experiment_index.py --check --render`。已完成数值产物与索引登记分开处理：若历史注册表校验阻塞，修正外部问题后可重用校验通过的产物登记，不重复推理。

本轮工程验证为合成单元检查和单场景96×96冻结前向；它们不回答真实数据的性能问题。真实结论以用户执行上述CMD后生成的结果为准。
