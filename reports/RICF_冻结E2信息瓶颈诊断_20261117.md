# RICF 前置诊断：E2 Detail 融合瓶颈是否损失可恢复信息

日期：2026-11-17。状态：**仅提交脚本，QXS 真实结果尚未执行**。

## 研究假设

E2 将两源 64 通道 Detail 组合为一个 64 通道融合 Detail。原先推测这可能丢失对融合有用的信息，但**维度压缩本身不构成证据**。此次严格分开：

1. **线性可恢复性**：能否从 E2 原融合 Detail + 相同 Base 上下文线性恢复输入的两源 Detail？
2. **容量基线**：同样是 64 通道的 PCA / 固定随机投影，能恢复多少两源 Detail？是否明显优于 E2 的融合结果？
3. **图像结构弱代理**：源图强/弱 Sobel 梯度区域的特征恢复残差是否不同？**SAR 强梯度不是真值结构，不能将相关性直接当作信息效用**。

若 E2 输出的源信息恢复明显劣于等宽 PCA，说明存在可恢复的信号差距，但这不证明它是融合有效信息，尤其不能直接证明“可逆耦合能改善画质”。现有 Decoder 并不要求还原两路输入 Detail；即使恢复误差很高，也可能是主动舍弃不利于融合的信号。

## 设计与防泄漏

采用同一份冻结的光学 Base E2 epoch_016 权重及原 train1024/val64 manifest，默认仅用前 8 张 train 图拟合**线性岭回归探针**和 PCA 基底，用前 16 张 val 图评估，绝不访问 test1000。网络参数不更新，不进行 RICF 训练，归档 checkpoint 不写入。

每隔 4 像素采样同坐标特征，输入全部先按**训练集统计量**标准化。所有探针都保留同一 64 通道 E2 Base 上下文：

| 条件 | 用于恢复的特征 | 角色 |
|---|---|---|
| base_only | fused Base (64) | 测试 Base 可恢复多少 Detail |
| e2_fused | fused Base (64) + E2 fused Detail (64) | 待诊断的真实 E2 表示 |
| pca64 | fused Base (64) + train-only PCA(D_o,D_s) (64) | 等宽源信息线性压缩上限参考（不是融合模型） |
| random64 | fused Base (64) + 固定随机正交投影(D_o,D_s) (64) | 等宽非优化投影对照 |
| concat128 | fused Base (64) + 原双源 Detail (128) | 未压缩的信息恢复上界参考 |

各条件只使用**相同的 train 源特征目标**训练线性探针，预测目标是 Optical Detail 和 SAR Detail（各64通道）。报告 val 每图的标准化 MSE、R²、与 base_only 比较的改进比例；SAR 使用有效源图位置打分。

由原光学/SAR 亮度图计算 Sobel 幅值，在各图内选择最高/最低20%幅值位置，比较对应特征残差能量。这只是低成本空间相关性读出，**没有分割标注或 SAR 真实结构标签**。

输出归档摘要包括场景 ID、源码/checkpoint SHA256、PCA 累计方差、每条件和每源误差。**不输出虚假的 QAB/F 或 NAB/F**：并无新的融合图像或 RICF 模型。

## 进入 RICF 训练的建议门槛

- 在验证集多数图上，e2_fused 相比 pca64 对**光学或 SAR 的恢复差距稳定存在**，不是单个异常图或仅某一弱方差通道造成。
- 该差距不能被 base_only 单独解释，并且与真实源图可核验的有效结构位置有一定对应；强 Sobel 相关性本身不充分。
- 即便上述成立，还要对齐普通双分支残差融合与参数量相近的可逆耦合，完成真实 QAB/F、NAB/F、FMI、VIF、SCD 检验，才能说有独立收益。

若 pca64 也难以恢复两源，可能是通道预算不足，而非可逆耦合可修复；若 e2_fused 与 pca64 接近，当前实验不支持“E2 信息瓶颈明显落后于等宽线性压缩”。注意**可逆的 128→128 耦合并不能保证最终 128→64 合成无损**。
