# E2 独立消融收益审计

日期：2026-11-19。范围为当前 `lwpd_e2_base_anchor_v1` 相对原版 CDDFuse 的组成变化及其已有对照，另核查 E3/E4 是否具有增量收益。本轮仅读取已有配置、元数据、注册表与逐图 CSV，没有训练、模型推理、批量测试或新增数据集评价。

**严格结论：当前最有力的匹配正结果是“光学 Base 直连＋零初始化跨模态修正”这个完整方案。LWPD-E2 的方向门控＋LL 调制组合有明确的伪影指标收益及小幅 FMI 代价；它不是方向门或 LL 调制各自的独立证据。取消图像旁路已有独立对照和阶段性正结果。跨模态 Base 注意力、多尺度 Detail、固定 Haar 本身以及训练配方各自的独立收益尚未建立。**

这里“明确”限于相应单种子、固定划分和预算的已有结果，不表示跨种子、跨数据集和任意初始化均成立。组件组合可以作为一次模块级消融，但不能将组合差值再分摊给其中每个算子。

**1. 最强匹配正结果：光学 Base 保留方案。**

对照为从头训练的 `lwpd_e2` 与 `lwpd_e2_base_anchor_v1`，均使用 4 轮源重建＋12 轮融合、seed42、同一原损失、完整 train8000/val1000。保存的配置除 variant 与输出目录外一致；验证场景 ID、顺序、清单哈希、offset0、旧 paper/clamp 口径一致。两条评价记录均属于 `QXS-VAL1000-DIRECT-LWPD-v1`。

改变的是 `Bf=C(Bo,Bs)` → `Bf=Bo+C0(Bo,Bs)`，其中 `C0` 的修正分支末端为零初始化。它同时增加光学特征直连并改变修正分支初始化，尚没有“仅直连”“仅零初始化”的拆分实验。

| 指标 | 无光学 Base 保留 | 光学 Base 保留版 | 共同有限场景数 |
|---|---:|---:|---:|
| QAB/F ↑ | 0.723678 | 0.732060 | 1000 |
| NAB/F ↓ | 0.119770 | 0.060073 | 1000 |
| FMI ↑ | 0.674837 | 0.688762 | 1000 |
| VIF ↑ | 0.337749 | 0.393301 | 1000 |
| SSIM ↑ | 0.354190 | 0.527984 | 1000 |
| MS-SSIM ↑ | 0.442355 | 0.567437 | 1000 |

NAB/F 均值下降 49.84%，958/1000 场景改善；SSIM 在 987/1000 场景提高。QAB/F 均值提高 1.16%。这足以支持该方案在本次从头训练协议下修复了大量严重退化场景。

但 VIF 虽均值提高 16.45%，只有 444/1000 场景提高；FMI 均值提高 2.06%，只有 504/1000 场景提高。不能把均值改善写成每图全面改善，也不能将其解释为已经解决光学弱边界缺失。当前冻结 pilot 仍有两源传递不对称。

来源：[无锚点逐图结果](../test_result/e2_scratch_twostage_v1/val1000/seed42/metrics.csv)、[锚点逐图结果](../test_result/e2_scratch_base_anchor_v1/val1000/seed42/metrics.csv)、[无锚点配置](../models/e2_scratch_twostage_v1/seed42/config.json)、[锚点配置](../models/e2_scratch_base_anchor_v1/seed42/config.json)、[具体改动](../e2_base_anchor.py)。

**可采用的结论：光学 Base 直连与零初始化修正的组合，在固定从头训练协议下有效。不能进一步认定零初始化、光学先验或跨模态注意力各自已经有效。**

**2. 有条件的模块级正结果：E1→E2 的高低频调制组合。**

实际 E1、E2 训练产物与 val1000 评价均已存在。二者配置使用相同 R3 初始化 checkpoint 哈希、seed42、2+4+10 共16轮、相同优化设置及损失，验证场景及输出口径一致。旧文档中“尚未执行 E1–E3”不能代表当前事实。

E1 使用固定 Haar，不调制子带；E2 同时增加以下部分：

- 从同源与跨源上下文计算的 LH/HL/HH 方向门控；
- 对 LL 的可学习小幅乘性调制。

因此，这是一组“高低频上下文调制模块”的消融，不是纯方向门控消融。它也没有隔离固定均匀衰减、学习到的空间/方向选择和额外容量。

按原始 CSV 逐图共同有限值计算，以下均 n=1000，旧 paper/clamp 口径：

- NAB/F：0.097365→0.064611，下降 **33.64%**，**990/1000** 场景改善。
- QAB/F：0.730091→0.732369，均值提高 0.31%，605/1000 场景改善。
- VIF：0.399881→0.400923，均值提高 0.26%，576/1000 场景改善。
- SSIM：0.527364→0.528576，957/1000 场景改善。
- MS-SSIM：0.566272→0.567796，844/1000 场景改善。
- FMI：0.717026→0.710386，均值下降 **0.93%**，不能称全指标占优。

这支持保留 E2 调制组合，主要价值是伪影—信息折中改善；NAB/F 下降不等于真实 SAR 散斑减少了同样比例。该结果来自历史 R3 初始化协议，不能未经对照就把幅度外推到当前光学 Base、从头训练的模型。

注册限制：本次在注册表中未找到 E1 val1000 的对应登记，E2 已登记。因此上述作为元数据匹配的历史消融证据报告，不整理为正式注册组定量表；正式论文表需先补齐已有结果登记，无须因此重新训练或评测。

来源：[E1 配置](../models/lwpd_qxs_ablation_v1/e1_seed42/config.json)、[E2 配置](../models/lwpd_qxs_ablation_v1/e2_seed42/config.json)、[E1 指标](../test_result/lwpd_qxs_ablation_v1/val1000/e1_seed42/metrics.csv)、[E2 指标](../test_result/lwpd_qxs_ablation_v1/val1000/e2_seed42/metrics.csv)、[固定与门控模式的代码差异](../lwpd.py)。

**可采用的结论：在固定 Haar 分解上，高低频上下文调制组合获得了有 FMI 代价的正结果。不能单写“方向门控独立贡献降低33.64%伪影”。**

**3. 已有独立对照、但收益依赖训练阶段：取消原图旁路。**

R0 与 R1 使用相同原 Base/INN Detail 融合，差别在于 Decoder 是否在 Sigmoid 前加输入图像，训练和推理都按该策略执行。它是实际存在的单因素策略对照，不能说完全未做消融。

同轮 val1000 的历史结果显示：

- epoch7：R1 的 QAB/F、FMI、VIF 均值略低，NAB/F 恶化 9.49%，SSIM 略高。
- epoch8：R1 的 QAB/F、FMI、VIF、SSIM 均值提高，NAB/F 降低 22.09%。
- epoch9：上述四项均值提高，NAB/F 降低 8.62%；QAB/F、VIF、SSIM 分别有917、912、931张图改善。

这构成晚期训练下的正信号，但不同轮次方向变化，没有形成跨种子的稳健结论，也不是在当前 LWPD/光学 Base 框架中的直接消融。R0/R1 早期验证尚未补齐注册表同组登记，故不列正式排名表。

来源：[历史逐轮汇总](../test_result/direct_fusion_qxs/qxs_direct_seed42_v1/val_extended/summary.csv)、[R0 epoch9 指标](../test_result/direct_fusion_qxs/qxs_direct_seed42_v1/val_extended/r0_epoch_009/metrics.csv)、[R1 epoch9 指标](../test_result/direct_fusion_qxs/qxs_direct_seed42_v1/val_extended/r1_epoch_009/metrics.csv)。

**可采用的结论：直接解码策略有独立的阶段性正结果；尚不能称其是当前 E2 中已确认的稳定增益部件。**

**4. 当前不能列为“独立明确有效”的部分。**

| 部分 | 已有证据的实际范围 | 判断 |
|---|---|---|
| 固定 Haar 替代原 Base/INN 分解 | E1 相对 R3 的比较还包含额外训练和分解路径适配 | 没有隔离 Haar 本身的纯收益 |
| 跨模态 Base 注意力 | R3 同时改变 Base 与 Detail；锚点比较两组都使用该注意力 | 尚无单独替换的稳定正证据 |
| 多尺度 Detail 融合 | R1→R3 同时改变 Base；R2 同时改变两路融合且严重退化 | 尚未证明多尺度本身优于原 INN/单尺度头 |
| 光学 Base 直连单独 | 与零初始化修正同时加入 | 已证实的是组合，尚未拆开两者 |
| 零初始化单独 | 同上 | 不能独立归因 |
| 高频方向门单独、LL 调制单独 | E1→E2 同时启用两部分 | 已证实的是调制组合及其折中 |
| 跨源门相对同源门 | E2 包含两类门，没有匹配训练的逐项移除结果 | 尚未证实跨源条件的必要性 |
| 移除相关性损失、采用4+12训练 | 与架构及训练来源变化共同出现 | 没有独立收益结论 |

关于多尺度头的具体核查见：[Detail 多尺度融合证据复核](Detail多尺度融合相对原版INN_证据复核_20261119.md)。完整 E2 比原版更好，只能支持完整版本，不能让上述每个组件自动获得独立贡献。

**5. E3/E4 不能列为已通过的增量机制。**

已有历史累积消融中，E2→E3 加入 SAR 高频恢复后，FMI 均值提高0.65%，但 NAB/F 恶化16.15%，SSIM、MS-SSIM下降；E3→E4 加入相位对称条件后，NAB/F再恶化29.42%，FMI下降0.81%。这些结果均为同批旧paper val1000的探索性复核，不能因 E4 整体优于某个早期基线，就认定恢复和相位条件各自有净收益。

E3 的对应验证条目也尚未补齐注册表。该状态不否定现存原始结果，但限制正式成表与归档。来源：[E3 指标](../test_result/lwpd_qxs_ablation_v1/val1000/e3_seed42/metrics.csv)、[E4 指标](../test_result/lwpd_qxs_ablation_v1/val1000/e4_seed42/metrics.csv)。

**最终保留意见：当前 E2 中最有实证依据的是光学 Base 保留组合；LWPD-E2 高低频调制组合具有有条件的模块级正证据；直接解码策略具有阶段性证据。其余部件主要是承载结构、尚待拆分的设计或未通过的增量，而不是已经逐项证实的收益来源。**

以上两项强弱不同的正证据来自不同训练背景，不能把收益百分比相加，也不足以替代“两个创新机制”的完整交叉消融。全仓库其他路线（例如 B0 上的 Detail-only SPD）属于另外的模型条件，不在本报告中算作当前 E2 的已证实组成收益。
