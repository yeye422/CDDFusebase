# E2 改进方向深入分析：监督一致性、信息选择与输出约束

日期：2026-11-04。仅依据现有源码、配置、报告和已保存结果分析；没有训练、批量推理或批量重评，没有修改模型和评价实现。

## 1. 核心判断

E2 下一步最值得研究的是：如何在保留 SAR 独有结构的同时，减少不可靠梯度监督，并把这种选择落实到最终图像。现有证据不足以把瓶颈归为模型容量、小波表达能力或训练轮数不足。

优先级应为：评价口径与机制诊断 → 一个保守的监督目标消融 → 依据诊断决定是否改低频或融合路由。不要同时更换小波、添加恢复支路、增加SSIM和方向损失。

E2 的优势是信息、有效边缘和新增伪影之间的相对平衡，不是所有指标领先。此前六方法表的结论仍成立于旧paper协议内；不能将其直接称作标准FMI、Kumar NAB/F下的已认证优势。

## 2. 先澄清目标：不是所有向上指标都应该无限提高

PSNR当前采用双源MSE均值。逐像素恒等式：

`((F-O)^2 + (F-S)^2)/2 = (F-(O+S)/2)^2 + (O-S)^2/4`。

因此，仅追求该PSNR时，最优解就是两源平均。它不要求保留最佳局部细节，不能把追平U2Fusion的PSNR当作主要研究目标。

CC也存在双源相似性的几何限制。对单张图，将O、S、F分别去均值并归一化为单位向量o、s、f，设r=<o,s>，则：

`CC = <f,(o+s)/2> <= sqrt((1+r)/2)`。

上式适用于非零方差；它说明双源差异本身限制可达到的平均相关性。最大CC偏好归一化源方向的折中，不能代替互补结构保留。不要把提高CC等同于提高SAR信息贡献，也不能由低CC单独判断融合失败。

SSIM/MS-SSIM值得改善，但两源局部外观可能冲突，必须与SAR独有信息保留共同判断。AG、SF、SD和EN则不区分有用细节与部分噪声，建议作为描述性指标，而非主要优化目标。

## 3. E2实际控制了什么

由 `direct_fusion.py`、`lwpd.py`、`net.py` 可追溯当前路径：

`O/S → 共享编码器 → 特征Haar分解 → LL调制/三个高频子带门控 → IDWT构造Base和Detail → Base/Detail跨模态融合 → 共享Decoder → sigmoid输出`。

关键限制：

- Haar作用于编码后的64通道特征，不是原SAR强度；不能把原图Gamma统计直接套到特征子带。
- E2高频系数为 `g=0.1+0.9*sigmoid(logits)`，只能对当前子带作正值缩放；不能直接对齐跨模态错位、改变子带符号或修复位置错误。
- LL不是完全冻结，包含幅度为base_scale=0.1的乘性调制；不能将所有结构差异归因于高频门控。
- Detail融合显式接收fused_base，后续卷积、GELU和Decoder也不受固定频带约束。Base/Detail在LWPD输出处有频带构造意义，经过后级网络后并不保证仍为互斥低高频。
- 特征门控下限0.1不等于最终SAR信息保留10%；均值门控0.7也不等于SAR贡献70%。编码器、融合器和Decoder的共同适应可放大、抵消或绕开局部缩放。

由此得到一个重要待证伪假设：当前伪影可能既来自门控前的SAR纹理，也来自融合器/Decoder重新组织特征；继续关小门控未必能稳定限制最终输出高频。这是源码支持的作用可能性，尚不是实测主因。

## 4. 最优先的机制问题：强度与梯度目标可能互相矛盾

当前有效SAR位置的目标是：

`T_I=max(O,S)`；`T_G=max(A_O,A_S)`；`A_X=|Sobel_x(X)|+|Sobel_y(X)|`。

目标函数为：

`L=mean(|F-T_I|)+10*mean(|A_F-T_G|)+0.1*L_R`。

但一般有 `A(max(O,S)) != max(A_O,A_S)`。

一个可直接推导的例子：光学从左侧0过渡到右侧1，SAR恰好从左侧1过渡到右侧0。两源均有真实阶跃，而逐像素最大强度恒为1，内部没有边缘。强度项要求输出平坦，梯度项同时要求在阶跃处保留强边缘，两者无法同时为零。

真实图像中的极性差异、局部亮暗排序切换、轻微错位均可能产生类似冲突。这个反例证明目标不总是一致，不证明它已经解释本数据集的大部分误差。

此外，max强度可偏好SAR亮点，max梯度可偏好散斑形成的强响应。只修改梯度目标，强度通道仍可能传入不可靠亮点；只添加结构项，也未取消这些压力。

原E2最终val日志中，10倍梯度项约占总损失标量的85%。这是目标偏好的线索，不等于它占85%的参数梯度或更新量。应观察各项对同一输出F及共享参数的梯度范数、夹角和冲突位置，而非仅按标量大小调权重。

**改进含义：先判断错误主要是监督对象不可靠、两项目标冲突，还是后级生成过冲，再选择修改项。**

## 5. 现有失败实验分别排除了什么

### 5.1 E2-S：结构监督有价值，但全域等权不保证平衡

匹配B与S属于 `QXS-VAL1000-E2-GENERAL-LOSS-v1`。已有结果中，S的SSIM/MS-SSIM约改善0.30%/0.23%，SCD改善3.14%，但NAB/F恶化18.81%。

能确认：该权重、该双源SSIM定义下存在信息/结构收益与伪影指标的取舍，原筛选未通过。

不能确认：所有SSIM都无效，或恶化已被定位为SAR散斑。原报告没有完成逐像素伪影定位，也缺少B对应的新增结构分项日志。

后续若再做结构项，应研究尺度和监督对象。例如低频结构项可减少直接匹配原SAR高频统计的压力，但低通也可能抹去SAR细线，仍需独立验证。不要默认同时叠加BGC1与新结构项。

### 5.2 E2-G1：共同证据不能承担全部SAR结构的去留决策

G1与匹配B属于上述同一验证比较组。G1的NAB/F从0.065673降到0.026616，QAB/F却从0.732614降到0.324421；对光学输出MAE从0.165135降至0.009998。MI与VIF反而升高。

因此，降低NAB/F并提高MI/VIF，仍可能对应严重光学偏向。G1将低共同置信度区域强制匹配光学，恰好压制光学未响应的SAR独有结构。

后续必须区分三件事：可靠共同边界、SAR独有结构、不确定区域。缺少共同证据只表示不确定，不能直接等同于噪声，更不能成为复制光学的理由。

### 5.3 E2-PRL：新增表示自由度未自动获得正确用途

PRL与原E2属于 `QXS-VAL1000-DIRECT-LWPD-v1`。其MI/VIF改善伴随NAB/F恶化48.47%及SSIM/MS-SSIM下降。单张机制干预中，恢复Haar也未明显消除退化，不能把全部差异归因于最终小波核的即时作用。

支持的判断是：联合训练与目标偏好值得优先审查。它不证明所有可学习小波无效，也不支持当前直接扩大滤波器自由度。

## 6. 推荐的改进路线与条件

### 路线一：有界、局部的SAR超额梯度修正，最适合首个单变量训练候选

仓库已有BGC1提案：

`D=relu(A_S-A_O)`；`T_new=T0-eta*M*(1-C)*D`。

其中C为SAR自身的局部结构张量方向一致性，M为完整有效邻域，eta首版固定0.10。保留原强度项、L1形式和训练预算。

它的优点是保留原双源目标主体，不依赖光学共同响应；有效位置目标满足 `A_O<=T_new<=T0`、`T_new>=0.9*T0`。与G1相比，目标改动更容易定位，且eta=0可回归原路径。

但是，90%仅指目标幅值下界，不能解释为真实SAR信息保留率。角点、点目标、复杂纹理也可能低C；方向性散斑也可能高C。目标幅值有界不代表L1优化梯度变化小：F的当前幅值若位于旧新目标之间，L1导数可直接翻转。更不保证训练输出和NAB/F只发生小变化。

所以BGC1只能列为**优先诊断后决定是否训练的候选**。先检查实际修正是否集中在背景颗粒，而不是SAR独有目标；若误抑制明显，停止该证据路线，不自动扩大eta或堆叠更多掩码。

### 路线二：在梯度主干之外，单独研究低频结构与亮度

触发条件：已有图像显示边缘基本可靠，但大尺度亮度、局部对比度或低频轮廓偏移明显。

此时可考虑在固定低通尺度上分析结构损失，并研究比像素max更一致的低频强度目标。应保留单独的高频/SAR结构保留约束，否则平均化能提高PSNR和部分相似性，却丢失互补信息。

这是与BGC1不同的问题，不建议第一轮合并。不能用“max强度存在反例”直接认定替换为均值最优；均值同样可能削弱弱目标。

### 路线三：若证实特征门控与输出行为脱节，再改融合路由

触发条件：固定checkpoint的局部干预显示，SAR Detail门控变化很大而输出问题不变；或低频/融合器路径仍显著产生目标高频。

可研究以原E2融合结果为保留路径、增加零初始化有界修正，或对最终图像的过冲/方向偏差施加局部约束。不能简单换成光学图加残差：这会重新引入光学偏置，并可能重复G1。

保留路径只保证新配置初始化时接近E2；端到端训练后若原路径也更新，仍不保证保持原行为。严格研究时需说明冻结策略、输出约束和同架构零修正对照。

这比损失消融成本高，且需要直接架构对照，不作为首选。

### 暂缓方向

- 更大可学习小波、多重恢复支路或继续强化高频：没有先解决监督对象。
- 对融合图直接施加Gamma/IS/比率直方图：F不是无斑SAR反射率，当前数据是8位显示读取，物理统计域未确认。
- 直接压缩全部Detail能量或加信息瓶颈：真实SAR弱结构也可能被压缩，现有监督仍可能偏好保留噪声。
- 同时调SSIM、梯度权重、窗口、阈值和训练轮数：难以辨别机制且增加验证集调参风险。

## 7. 训练前最有价值的检查

只需固定少量训练样例和已有验证可视化；不需要默认重训基线或遍历全数据。

| 检查 | 需要观察的量 | 对后续决策的影响 |
|---|---|---|
| 强度—梯度目标一致性 | `A(T_I)-T_G`、强度/梯度项对F的梯度夹角、冲突位置 | 冲突集中于真结构时，优先改目标组织 |
| 新证据是否误判 | 预先标记的平坦区、独有细线、点目标、角点、暗区及无效边缘 | 真结构被大量修正则停止该证据 |
| 输出伪影定位 | 内部/外框分开；幅值过冲与方向误差分开 | 避免把亮度边界效应当作内部散斑 |
| 路径干预 | SAR三个高频、LL调制、融合后Detail的单独干预 | 判断门控、低频或Decoder哪个更值得改 |
| 退化解检查 | F=O、F=S、均值、max强度、原E2、已有G1的分项代价 | 排除新损失继续奖励单模态复制或平均化 |
| 双源分项 | MI(O,F)/MI(S,F)、双源SSIM/VIF、固定SAR独有结构 | 防止总分掩盖一源信息流失 |
| 数值日志 | AMP scale、跳步、真实非有限梯度、FP64诊断范数 | 区分诊断溢出与真实优化异常 |

现有group_gradient_norms在FP32中平方求和，可能自身溢出；NaN/Inf诊断不能直接证明参数发散。数值问题需要检查，但目前不足以推翻G1目标偏置等更直接证据。

额外边界问题：当前原梯度监督只检查中心像素valid，而Sobel需要3×3支持；原SAR的无效零值可能影响邻域梯度。应单独诊断其影响，若修改需另立协议，不能混入BGC1后把收益全部归给新证据。

## 8. 评价口径与最终验收

现有指标审查已确认，旧FMI不是原作者局部归一化FAST-FMI；QAB/F有等幅分支和方向周期差异；NAB/F有方向、参数、权重及补零边界差异；MS-SSIM也有边界及降采样差异。`reference_v2_candidate`存在，但目前本次读取的证据中未见完成MATLAB数值认证的通过标志。

建议两条记录并存：旧paper保留历史工程判断；参考版本先做独立认证，决定采用后统一重评已保存图像，无需仅因指标更改重训模型。所有方法必须同口径，新旧指标不混表，旧阈值不自动迁移。不要依据候选输赢挑评价版本。

模型筛选仍应使用固定val，不用test1000调eta、权重或checkpoint。复用已有匹配B，不将历史E2均值当成新配置的直接分母；B/S/G1和E2/PRL属于不同验证比较组，本报告各自比较，不做跨组定量总排名。

主验收关注：NAB/F有利变化、QAB/F保留、FMI/SCD及SAR独有结构不明显损失、SSIM/MS-SSIM有收益或至少不退化。MI/VIF为辅助支持，不能独立证明成功。具体容忍量应在单次新实验前固定；严格不退化是项目工程目标，不是指标必须共同提高的数学保证。

所有均值、逐图配对区间与视觉检查要一起报告。只有候选值得推进时再考虑多种子，逐图区间不替代训练种子方差。若只能交换某些指标，应如实报告Pareto取舍，不事后调权重宣称综合最优。

本次没有实现新的训练入口，因此不提供不存在的CMD命令。后续若实施诊断或训练脚本，再提供对应Windows CMD命令由用户运行训练及批量评价。
