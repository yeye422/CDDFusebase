# LWPD 与 PAC-Mamba 可视化对比

## 对比设置

可视化使用固定 QXS-SAROPT test1000 中的相同图像，统一展示：

1. Optical；
2. SAR；
3. Wavelet；
4. U2Fusion；
5. Laplacian；
6. B0 + SPD；
7. LWPD E4；
8. PAC-Mamba。

所有方法均展示灰度融合结果，避免光学色度复用方式影响结构观察。每个场景上行为全图，下行为同一位置的 64×64 放大区域。放大区域由 PAC 与 LWPD 局部绝对差最大的窗口客观确定，不为某个方法手工选择最有利位置。

选取的五个场景同时包含明显收益和失败/退化情形：

- 17667：PAC 的 QAB/F、FMI、VIF 明显提高；
- 15605：建筑与强散射目标，PAC 的结构指标也提高；
- 17848：PAC 的 FMI、VIF 下降，用于展示代价；
- 11039：强散斑水体/植被场景；
- 13550：PAC 相对 LWPD 的 SSIM 下降较明显。

## 场景分析

### 17667：稀疏线状目标

PAC-Mamba 对跑道/地表线和小型亮目标的连续性更好，同时弱化了 LWPD 中铺满背景的颗粒感。QAB/F 从 0.5207 提高到 0.5708，VIF 从 0.3728 提高到 0.4117，NAB/F 从 0.1809 降到 0.1632。代价是 SSIM 从 0.4926 降到 0.4792。

### 15605：建筑边缘和 SAR 亮散射

Laplacian 的边缘最强，但存在明显过增强；U2Fusion 更平滑。PAC 在保留建筑轮廓和 SAR 亮目标的同时，较 LWPD 稍微降低背景颗粒。QAB/F、NAB/F、SSIM 和 VIF均改善，说明 PA 条件更新在这一类共同边界场景中符合设计预期。

### 17848：农田纹理退化样例

PAC 降低了颗粒与伪影，NAB/F 从 0.1606 降到 0.1353，QAB/F略升；但局部田块纹理也被重新分配，FMI 从 0.3914 降到 0.1659，VIF 从 0.3888 降到 0.3803。这说明 PA 门控有时会将弱方向纹理视为不可靠交互，属于需要在论文中保留的失败案例。

### 11039：强散斑场景

所有保留 SAR 信息较多的方法都出现明显颗粒，U2Fusion 最平滑但细节传递较少。PAC 与 LWPD 的整体视觉差异很小，但 PAC 的 NAB/F 从 0.1025 降到 0.0655，FMI、SSIM 和 VIF均提高。说明 PAC 能减少部分错误响应，但没有从视觉上彻底消除强散斑。

### 13550：SSIM 下降样例

PAC 的边缘和亮点传播更明显，QAB/F 从 0.6131 提高到 0.6346，NAB/F略降，VIF略升；但大面积浅色区域的灰度和局部纹理发生变化，SSIM 从 0.4623 降到 0.4385。这是 PAC 在信息传递与源图结构相似性之间权衡的典型反例。

## 综合判断

可视化与定量结果一致：

- Wavelet 与 U2Fusion通常更平滑，但互补结构和 SAR 目标传递较弱；
- Laplacian 边缘和对比度最强，也更容易产生过增强；
- B0 + SPD 能降低部分散斑，但细节与信息量弱于深度融合路径；
- LWPD 能保留更多方向细节，但困难场景中仍有颗粒扩散；
- PAC-Mamba 通常在 LWPD 基础上减少背景颗粒、提高共同边界连续性，但部分弱纹理和大面积均匀区域会出现结构相似性下降。

因此，PAC-Mamba 的视觉收益是“选择性减少错误传播并改善有效边界”，而不是全局平滑或彻底去斑。当前可视化足以支持方法叙事，同时也应在论文中展示 17848 或 13550 作为局限案例。
