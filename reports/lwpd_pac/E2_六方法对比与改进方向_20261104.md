## E2 相对 E4 的变化

相对变化按CSV原始均值计算。NAB/F下降有利；其余指标按表头方向解读。

| 指标 | E2相对E4 | 含义 |
|---|---:|---|
| NAB/F | -32.92% | 新增伪影指标明显降低 |
| QAB/F | +0.081% | 边缘传递基本保持，均值略高，不能仅凭微小差异宣称显著提升 |
| PSNR | +1.39% | 与源图的像素一致性改善 |
| CC / SCD | +0.47% / +1.36% | 相关性、差异相关性小幅改善 |
| SSIM / MS-SSIM | +0.10% / +0.47% | 结构指标小幅改善 |
| MI / FMI / VIF | -1.17% / -0.24% / -0.25% | 信息保留略有代价 |
| AG / SF / SD | -0.67% / -0.78% / -1.03% | 梯度、频率和对比度略降 |

E2 相比 E4 保持相近的 QAB/F、FMI 和 VIF，同时 NAB/F 更低。因此，若后续目标重视伪影与信息的平衡，E2是值得保留的起点。E4并未在全部指标上支配E2；本表也不足以证明E2在所有场景或训练种子上更好。

## 需要进一步改进的方向

1. **首先改善结构保持和互补信息的协调。** E2的CC=0.5644、MS-SSIM=0.5718，仍低于U2Fusion的0.6835、0.6251；SSIM=0.5273低于CDDFuse零样本的0.5441，SCD=1.2604也低于其1.6292。后续重点应是低频亮度/对比度稳定、边缘位置与方向保持、SAR独有结构的选择性传递。SSIM或CC提高也可能来自更接近单一源图，必须同步观察MI、FMI、VIF和SCD，不能只优化相似性。
2. **继续压低无依据的高频，保留有效边缘。** E2的NAB/F比E4低32.92%，但仍高于Wavelet的0.0121和U2Fusion的0.0001。候选方向是对局部梯度过冲、方向不一致和不可靠SAR细节施加约束，在可靠共同边缘及SAR独有结构上保留注入。应先以已有验证图检查过冲、散斑、光晕或边缘偏移；仅凭均值不能确定具体伪影类型。
3. **优先审查融合损失，而非继续增加分解或恢复模块。** 当前最大强度与最大梯度目标不直接保证融合图的多尺度结构或低NAB/F。已有E2-S配对val结果使SSIM/MS-SSIM提高约0.30%/0.23%，但NAB/F恶化18.81%；E2-G1虽将NAB/F降至0.026616，却使QAB/F从0.732614降至0.324421。两者均说明约束需要联合设计，不能单独增加SSIM项或压低梯度就认定有效。下一轮应先定位哪些区域发生结构收益与边缘损失，再决定新的目标；复用已有匹配基线。
4. **对新增自由度设置明确收益要求。** 已有E2-PRL验证虽提高MI/VIF，却使NAB/F恶化48.47%，SSIM/MS-SSIM下降。当前证据不支持优先扩大可学习小波或继续增加恢复强度。若保留E3/E4类机制，应在验证集逐模块证明收益，并要求伪影和结构不明显退化。

## 综合指标如何使用

不建议直接把14项指标相加，也不建议以“第一名数量”作为总质量：量纲不同，AG/SF/SD相关，增强噪声也可能抬高这些指标。

建议采用“约束筛选 + 分组报告”：

- 信息与有效边缘：MI、FMI、QAB/F、VIF。
- 伪影：NAB/F。
- 结构与互补性：SSIM、MS-SSIM、CC、SCD。
- 辅助描述：EN、PSNR、AG、SF、SD，结合视觉判断。

先在固定val比较组中预注册：NAB/F不劣于匹配E2，SSIM/MS-SSIM不下降，信息与有效边缘指标的允许退化量事先确定。通过后再比较信息收益与结构收益，最后检查固定场景的边缘连续性、背景颗粒和SAR独有结构。阈值为工程筛选约定，不是统计显著性标准；使用逐图配对差和区间辅助判断，并在值得推进时再做多种子确认。

若论文必须提供单一综合分，应先固定验证集参照范围、正负方向及分组权重，分别归一化后按组汇总，并报告权重敏感性。该分只能作为自定义辅助分，不能替代14项原始指标，也不能在test上调权重选方法。本次不任意指定权重或宣称综合排名第一。

以上test1000用于描述已有结果；新增设计、超参数和checkpoint选择必须回到val，不能反复查看test来调参。本次未提出需要立即执行的新训练或批量测试。
