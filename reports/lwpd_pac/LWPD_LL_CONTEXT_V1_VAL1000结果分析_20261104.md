# LWPD LL-context v1：12轮训练与val1000结果检查

日期：2026-11-04。本次仅检查已有checkpoint、日志、评价结果与保存图像，没有重新训练、推理或批量评价。

## 结论

当前LL-context v1未达到预先提出的结构改进目标，应保留为未通过筛选的候选，不推进当前配置test1000，不默认追加训练或改选其他epoch。

MI、QAB/F、VIF有收益，但CC、SCD、SSIM、MS-SSIM均下降，NAB/F上升26.92%。因此不能称作整体优于E2；该结果尤其不支持“加入低频上下文就会自动改善结构保持”的假设。

结论仅限当前配置、seed42和原paper协议。它不否定所有LL上下文方法，也不能将全部差异因果归于新分支：候选是在原E2上追加12轮联合训练，缺少相同额外训练预算的无新模块对照。

- 两份实际checkpoint哈希均与评价元数据一致。候选最终模型state张量全部有限，1000张逐图14项指标均有限。

## 预设筛选

设计提议要求MS-SSIM至少相对提升0.3%、SSIM不下降，CC/SCD不下降，信息/边缘指标下降不超过0.5%，NAB/F不高于原E2。

- MS-SSIM目标未达到，反而下降0.683%。
- SSIM、CC、SCD均未通过。
- NAB/F未通过。
- MI、QAB/F、VIF提高；FMI均值下降0.450%，仍在提议容忍范围内，但不能抵消上述结构与伪影代价。

因此当前候选明确未通过，不事后以信息项涨幅重定义成功。

## 新分支是否实际工作

不是简单的分支未学习或长期保持零输出：

|---|---:|---:|
| LL修正绝对值均值 | 0.03694 | 0.22338 |
| LL修正绝对值95分位 | 0.11842 | 0.47031 |
| abs(delta)>=0.49比例 | 0% | 1.835% |
| LL直接变化RMS | 0.00431 | 0.02256 |
| 光学delta均值 | -0.00034 | -0.05456 |
| SAR delta均值 | -0.01456 | -0.01035 |
| 当前尺度上下文RMS | 0.72136 | 3.98963 |

修正上限为0.5，末轮95分位接近上限，但饱和比例只有约1.84%，不能描述为全分支饱和。分支已明显参与；上下文特征幅度也持续增长。

LL变化RMS是特征单位，不能直接解释为图像灰度变化或百分比；缺少相对原LL RMS的日志。delta均值为负也不等同于输出变暗，因为原调制logit、特征符号及后级网络共同决定输出。三个尺度上下文范数接近，不代表贡献相同。

## 训练与数值情况

内部val总loss由首轮约0.716723降至末轮0.687281。梯度分项下降、重建项下降，但融合结构评价退化，说明更好拟合原目标不保证解决结构短板。

最低val loss出现在第11轮，第12轮高约0.000008。原协议固定最终第12轮，不因这点差异事后改选第11轮，且没有第11轮的独立14指标证据。

梯度范数日志有非有限项：第1轮decoder/detail_fusion、第4轮detail_fusion、第6/7/9/10轮encoder_early。最终参数和损失有限，不能据这些聚合范数直接认定训练发散。当前范数统计在FP32平方求和，且未记录足够的逐步AMP溢出/跳步信息，无法区分真实非有限梯度与统计溢出。这不是可以忽略的健康性证据，但也不能据此解释全部性能变化。

## 机制判断与限制

较有支持的描述是：本次追加训练与低频调制使信息/边缘指标提高，却没有改善原结构短板，反而形成更强高频/对比度和更高伪影指标的取舍。

可能机制包括：

1. 原损失仍偏好最大强度和最大梯度，新低频自由度被用于更好拟合该目标，而非源图结构保持。
2. 新分支虽然只直接改LL，后续Base/Detail融合及Decoder不受严格频带约束，能把低频变化重新组织为输出细节。
3. 联合训练同时改变编码器、旧LWPD、融合器和Decoder；小幅有界的即时LL调制不限制全训练轨迹。

这些是与源码和结果相容的解释，尚未逐项验证。不能断言主要来自某一尺度、光学delta负偏置或某类SAR散斑。

抽查scene4候选三联图与同checkpoint原E2的另存诊断预览，二者均呈现较强SAR纹理，差异较细微。未完成多ROI、全验证图或盲评，因此不能把26.92%的NAB/F恶化换算成26.92%的视觉噪声增加。

## 后续决策

1. 当前配置停止推进，保留checkpoint与结果；不执行正式test，不自动延长epoch或增加delta上限。
2. 若继续定位，最有信息量的是固定同一候选checkpoint，仅关闭LL-context新分支，对单张预先指定验证图比较正常输出。它能测试新分支的即时作用，不能恢复独立训练E2，也不能分解全部训练因果贡献。本次未执行该干预。
3. 若关闭分支仍无法恢复结构，说明仅撤销即时修正不足以消除其余网络的共同适应；不能反推新分支完全无影响。
4. 继续投入新训练前，应先有机制定位；不要凭当前信息指标涨幅直接叠加PAC，或默认重训基线。
