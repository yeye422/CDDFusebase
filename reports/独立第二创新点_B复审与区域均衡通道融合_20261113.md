# 独立第二创新点：B 的可行性复审与替代模块设计

日期：2026-11-13。状态：候选设计与既有结果复核，未实现新模型、未训练、未运行数据集推理或批量测试。

**本轮建议：暂缓原版 B 的“非局部分组＋低秩分解＋创新残差”完整训练，优先研究 C——区域均衡的通道关系融合，替换现有 Base 跨模态交互算子，完整保留 E2。** 这个排序表示更值得先验证，不表示 C 已证实比 B 涨分更多。B 可以保留为有条件的第二选择，但需要先证明其非局部信息有不可替代的作用。

本轮目标已从“改善 E2 的任意部件”收紧为“保留 E2，构造独立的第二创新点”。A 属于 E2 内部升级，本轮退出首选。原报告的方案优先级不再适用于这个新目标。

## 2. 原版 B 的深度可行性审查

原版 B 在两源内部检索相似 patch，将组矩阵 X 分为重复部分 R 和创新部分 E，再将 X、R、E 输入 Detail 融合头。

### 2.1 工程上能实现，机制上却存在绕过路径

因为 `E=X−R`，所以 `R+E=X`。若原始 X 同时输入融合头，网络可以直接用 X；即使删除 X，只要融合头能自由线性组合 R 和 E，也能重新得到 X。

这不证明冗余表示毫无价值——新表示可能帮助优化。但它意味着“低秩处理保留结构、创新通路保留目标”**不是结构保证**，必须通过对照证明。输出指标小幅增加时，也可能只是多了一层可学习变换。

### 2.2 当前监督没有要求融合头使用重复模式

当前融合阶段仍用 `最大强度 + 10×最大梯度 + 0.1×源重建`。[损失实现](../train_direct_fusion.py)

如果一部分 SAR 高频被组协同处理削弱，而原梯度目标仍奖励它，优化可能让融合头重新利用创新残差把高频补回。这样会得到：训练损失更好、低秩分支看起来有效，但最终伪影不改善。

特别是 B 被放在两源融合器中时，单源重建辅助并不直接训练这套融合器。不能以“有重建损失”推导 B 必然学会有效分组或保留融合信息。这个问题与 LL-context/PAC 的失败经验相符，但不能预先断言 B 必定失败。

### 2.3 低秩与噪声之间缺少可识别性

在 `C'=16、3×3 patch、K=8` 的设置中，X 是 144×8 矩阵，秩天然不超过8。观察到“低秩”本身没有足够辨别力。

- 道路、田块等重复模式可能低秩。
- 相关散斑、重采样纹理或反复出现的强散射也可能低秩。
- 孤立目标、转角和罕见结构可能进入高秩残差。
- 组内高能量响应容易主导奇异值，但高能量不等于融合价值。

原拟定算子 `R=X(XᵀX+τI)⁻¹XᵀX` 在奇异值 σ 上对应 `σ³/(σ²+τ)`，即谱收缩。若 τ 很小，它趋向恒等；如果 τ 较大，则明显压低部分分量。编码器还可以改变特征尺度，使相同 τ 对应不同的实际收缩强度。没有额外约束时，不能将其解释成可校准的噪声估计。

### 2.4 非局部检索本身需要验证

QXS 是256×256显示图块。城市结构存在重复性，不意味着任意图块都能找到足够好的同源邻居。SAR局部均值、角度及建筑散射差异都可能使“外观相似”和“可交换的结构信息”不一致。

若在全分辨率直接构建两两相似度矩阵，单个模态的65536×65536 FP32分数矩阵约16 GiB，尚未计入梯度。降到64×64检索网格后约64 MiB，工程上可行，但细小目标的检索与定位更间接。需要明确检索粒度、邻域排除和内容回填，不能把“轻量KNN”当作零成本。

### 2.5 文献支持可行性，不能直接支持当前涨幅

[Guided Patchwise Nonlocal SAR Despeckling，IEEE TGRS 2019](https://doi.org/10.1109/TGRS.2019.2906412)利用同源非局部内容，并借助光学与SAR判据筛选预测者。这是去斑任务，不能直接推出本融合器的指标收益。[作者机构记录](https://www.iris.unina.it/handle/11588/765003)

[Nonlocal CNN SAR Image Despeckling，Remote Sensing 2020](https://www.mdpi.com/2072-4292/12/6/1006)支持学习非局部权重的价值，同时报告真实SAR信号泄漏及弱纹理被平滑的问题。

[傅玉凯等，《自然资源遥感》2023](https://www.gtzyyg.com/en/article/doi/10.6046/zrzyyg.2021411?viewType=citedby-info)已经将非局部自相似用于光学–SAR融合。因此，仅加自相似、低秩和残差三个名词不能构成充分新颖性。

**综合评价：B 的实现可行性中高，当前监督下的机制可识别性偏低，联合指标收益的证据不足，计算与调试成本偏高。原先“收益上限较大”的说法只代表可能性，不应作为现在优先完整训练的理由。**

## 3. 如果保留 B，怎样缩小到值得检验的版本

建议先取消可学习低秩分解，只验证“同源远距离信息是否比局部上下文更有用”。候选 B-lite 可定义为：

- 保留 E2 全部输出和现有局部 Detail 路径。
- 两源分别建立同源相似组，但只将组统计作为**局部融合算子的条件**；首版不把远处 patch 的像素/特征直接搬到目标位置。
- 原位置的光学、SAR特征承担输出内容，非局部信息只改变这些内容如何交互；不要求光学同意才保留SAR，不预测去斑真值。
- 先用同容量局部条件、真实相似组条件、保持距离分布的随机组条件比较。

这能减少直接搬运远处结构的风险，并让“真实相似组优于随机组”成为必要证据。不过它仍可能被网络忽略，也接近已有上下文条件网络，不能仅凭这个修改就认证新的强贡献。

若真实组不优于随机组/局部组，不增加秩分解、更多检索层或更大K。只有真实相似组先显示稳定收益，才值得继续研究如何利用组内谱信息。

预期收益排序：重复纹理区域的结构一致性比全图大幅提高FMI更可信；NAB/F可能下降，但与有效细节衰减的风险绑定。对当前大量SAR相似度很高的场景，B也可能继续强化SAR纹理。因此它保持备选，不再是本轮首推。

## 4. 更值得先验证的 C：区域均衡的通道关系融合

工作简称 RBCF，Regional-Balanced Channel Fusion。名称仅为本地候选标识，不代表已发表方法或新颖性认证。

### 4.1 独立于 E2 的具体缺口

当前 `CrossModalBaseFusion._interaction` 将空间维展平，归一化 Q/K 后计算每个注意力头的通道关系：

`A = softmax(Qnorm K_normᵀ / temperature)`。

64通道、8个头时，每头得到8×8矩阵；**同一幅图内所有位置使用同一矩阵**。图像中不同区域会共同决定它。[实现](../direct_fusion.py)

这不是说原网络没有空间信息：Q/K含深度卷积、V随位置变化，前后还有非线性层。准确的限制是“跨模态通道交互矩阵在空间上共享”，不是“整网对所有位置给出相同输出”。

对互不重叠的区域w，可将原全图余弦关系写成：

`Rg[i,j] = Σw a[i,w] b[j,w] Rw[i,j]`

其中 `a[i,w]=||q_i,w||/||q_i||`，`b[j,w]=||k_j,w||/||k_j||`。这个等式表明不同区域对关系估计的贡献与投影后的特征能量相关。注意这里是**Q/K特征能量**，不能直接等同于原SAR亮度或散斑能量。

研究假设是：当不同区域具有不同跨模态关系时，全图共享矩阵可能把某些区域的关系施加到其他区域。局部关系不足以被一个全局矩阵表示时，区域统计应更有价值。这个缺口由代码确认，其对当前错误的贡献尚未实测。

### 4.2 第一版只替换 Base 交互算子

```text
Optical / SAR
      ↓
原 Encoder + 原 E2/LWPD（完整保留）
      ↓
Bo, Do, Bs, Ds
      ├── Bo, Bs → 区域均衡通道关系融合 → Bf
      └── Do, Ds, Bf → 原 Detail 融合器 → Df
                                   ↓
                              原 Decoder
```

保留光学 Base 锚点 `Bf=Bo+correction`，保留现有Q/K/V投影、双向交互、拼接压缩和输出变换。仅替换注意力关系的估计及应用方式。首版不同时动 Detail 融合器、不叠加 B、不改 E2 小波/门控、不换 Decoder。

因此第一创新点负责“方向/频率表示”，第二创新点负责“空间非均匀条件下的跨模态通道组合”。二者在结构上可拆开；效果是否独立仍需消融。

### 4.3 将关系描述与内容值分开

在窗口w内，每头每通道的Q/K沿空间维去均值并归一化：

`qtilde_i,w = (q_i,w−mean(q_i,w)) / max(||q_i,w−mean(q_i,w)||, eps)`

K同理，令 `Rw = Qtilde_w Ktilde_wᵀ`。这里是局部归一化跨通道关系，没有噪声分布假设，也没有特征值分解。

**只对估计关系的Q/K做此处理，V保留原投影值。** 原始局部亮度与幅值信息仍可经V及原两源值通路进入融合，不能对V同步做强制均衡后再声称幅值信息保留。

在非退化窗口、忽略eps的条件下，对某个Q/K通道作正仿射变化 `q'=a q+b, a>0`，其归一化关系保持不变。这只是**注意力描述层的性质**；原图变换经过编码器和投影后不一定满足该形式，不能宣称整个融合模型具有严格辐射不变性。反号变化也不属于这里的正仿射不变性。

### 4.4 区域均衡先验与局部关系共同决定矩阵

用不重叠窗口统计区域关系，按有效面积形成均衡先验：

`Rbal = Σw area_valid(w) Rw / Σw area_valid(w)`。

这样每单位有效面积的贡献不再直接按原Q/K能量放大。它也不保证区域等权一定最优：大面积平坦区可能稀释有效关系，因此必须与普通全局关系、仅局部关系比较。退化通道对需用明确的数值有效性处理；不得把数值有效性包装成“地物可靠性”。

在用于融合的重叠窗口中：

`Aw = softmax(((1−lambda) Rw + lambda Rbal) / temperature)`。

首版建议固定 `lambda=0.5`，沿用原温度参数；这是可审查的工程起点，不是最优值，不先做参数网格搜索。局部统计退化时退回均衡先验；整个输入缺乏有效统计时使用明确的数值回退路径。真实无效SAR像素不用于局部关系估计。

局部关系可以适配地物差异，先验避免完全割裂不同窗口的统计。**这个混合系数调节关系估计的尺度，不是光学/SAR二选一权重。**

### 4.5 内容留在原位置，窗口用固定权重连续合成

对光学接收SAR信息的方向：

`Y_os(p) = Σ_{w包含p} omega_w(p) Aw_os Vs(p)`，其中 `Σw omega_w(p)=1`。

反方向同理。ω是固定、非负且归一化的重叠合成权重，不训练语义路由。它可以减少硬窗口拼接，但不能证明最后输出没有接缝或过冲。

这一算子在当前位置混合通道，**不把远处位置q的V搬到p**。原Q/K/V的3×3投影仍会读取局部邻域，不能据此称整个模块是逐像素独立。

建议以32×32窗口、16像素步长起步。对256×256、64通道、8头，225个完整窗口每方向仅需约11.5万个注意力系数；但窗口内容和反向传播仍有开销，不能由系数少就声称运行免费。避免显式展开成全分辨率的所有通道矩阵，优先分块或流式合成；实际显存和时延需实现后测量。

### 4.6 与失败方向的差别

| 已有方向 | C 的区别 |
|---|---|
| LL-context | 不在LWPD内缩放LL；改变的是分解之后的跨模态非对角通道关系 |
| R1/方向收缩 | 不新增对SAR特征的逐点标量增益或三个方向的衰减 |
| CSR/structure-joint | 不将像素分类为共同/独有/冲突，不构造几何置信路由 |
| OCAF/Optical Rescue | 不从光学输出恒等映射出发做SAR注入，不新增光学回退图像 |
| PDCF/C1/P2-A | 不学习冻结基线外的小幅校正Adapter，不需要跨模态预测器 |
| PAC-Mamba | 不另开自由长程残差支路；替换现有交互的统计方式 |
| 极性/ASPR/RCCR | 不生成目标梯度场，也不在输出端求解或投影 |

不过，C仍然受到原融合损失影响，Base改变也会通过Detail和Decoder影响高频。没有最终NAB/F不增的理论保证，更不能把“保留原Detail代码”写成“最终细节绝不变化”。

## 5. 文献查重后，C 的论文空间有多大

不能将“区域自适应”或“双向通道注意力”单独列为原创。需要明确以下已有边界：

| 来源 | 已有内容 | 对C的意义 |
|---|---|---|
| [DT-F Transformer，Information Fusion 106，2024，102274](https://doi.org/10.1016/j.inffus.2024.102274) | 双向/转置注意力用于偏振图像融合 | 交叉通道注意力本身已成熟；该任务收益不能移植到SAR |
| [MDCA-Net，Geo-spatial Information Science](https://www.tandfonline.com/doi/full/10.1080/10095020.2025.2589611) | 直接光学–SAR融合，包含动态细节与上下文聚合 | 泛化的“动态上下文增强”不足以区分C |
| [RegionFuse，CVPR 2026，原论文摘要](https://openaccess.thecvf.com/content/CVPR2026/html/Xia_RegionFuse_Region-Adaptive_Pixel_Distribution_Learning_for_Infrared_and_Visible_Image_CVPR_2026_paper.html) | 针对区域分布差异，使用区域注意力专家与区域特征压缩 | 与C的问题动机接近，投稿前必须逐式比较，不能只写首次区域融合 |
| [Restormer，CVPR 2022](https://openaccess.thecvf.com/content/CVPR2022/papers/Zamir_Restormer_Efficient_Transformer_for_High-Resolution_Image_Restoration_CVPR_2022_paper.pdf) | 空间增强的通道转置注意力 | 是当前交互形式的技术来源，需要正确引用 |

其中期刊页面主要核对了出版社摘要/方法片段，不能声称已完成所有全文和代码的穷尽性查重。

C可能形成的具体贡献是：**面向光学–SAR空间非均匀性，构造去幅值偏置的区域关系估计、保留幅值的原位内容交互，并用均衡先验稳定局部估计。** 这是待证明的组合机制，不是自动成立的强创新。

要形成论文，必须展示三件事：

1. 当前全局通道关系在某些异质区域确实不适用，且这种不适用与输出缺陷有关。
2. 普通局部注意力不足以解释全部收益；关系归一化与区域均衡确有必要。
3. 改善光学结构保留时，没有仅仅把模型从SAR偏向推向光学偏向。

如果最终只是“窗口注意力涨一点”，应将C定位为有效工程模块，不夸大其理论贡献。

## 6. 指标预期：改变投入顺序，不虚构预测百分点

| 项目 | 原版B | B-lite | C |
|---|---|---|---|
| 与E2结构独立 | 是 | 是 | 是 |
| 当前短板匹配度 | 不确定，可能继续强化SAR纹理 | 中等，需先证明检索价值 | 相对更直接，针对跨模态关系的区域适用性 |
| 首要收益假设 | 重复纹理、背景伪影 | 局部信息组织 | 光学结构保留、MS-SSIM、SCD |
| 明显风险 | 可绕过、过度收缩、误检索 | 条件被忽略、泛化新颖性不足 | 局部统计不稳、关系均衡失真、原目标仍偏向SAR |
| 实现/归因成本 | 高 | 中高 | 中等，可复用原投影和输出层 |
| 本轮优先级 | 暂缓 | 备选 | 先做机制诊断，合格后首个候选 |

C对QAB/F和FMI的直接提升预期应保守，因为当前基线这两项已有较高值，而且更像SAR也能提高部分指标。更合理的价值是：**在保持信息与有效边缘的前提下，改善融合的结构平衡。** 如果只接受所有指标同时大幅提高，目前没有足够证据为B或C作这种承诺。

建议事先固定的继续投入门槛，而非预测值：

- SSIM或MS-SSIM至少一项绝对增加0.005，另一项不明显下降；
- 同时SCD相对增加至少3%，或VIF相对增加至少2%；
- QAB/F绝对下降不超过0.001，FMI/VIF相对下降不超过1%，NAB/F不恶化；
- 额外报告SSIM_O和SSIM_S的配对变化，但不以二者强行相等为优化目标；
- 如果均值收益集中于少数场景，必须给出场景类型与负例，不能只报平均涨幅。

这些门槛是“值得投入完整消融”的目标，不是统计显著性的替代。当前MS-SSIM含较多非有限值，必须使用共同有限样本并报告数量和失败比例。

## 7. 最小验证路径与停止规则

### 7.1 先做已有权重上的机制诊断

诊断不训练；使用预先固定的少量val场景，不根据结果不断挑图。训练或批量运行的脚本只能在实现后提供Windows CMD命令，由用户执行。

**C的关键诊断：**

- 缓存基线进入Base融合器的特征，再比较各区域Q/K关系与全局关系；同时量化特征能量分布。仅发现矩阵不同不够，还要验证它是否影响当前输出。
- 固定目标区域的输入特征与V，只改变远端区域用于关系估计的统计，观察目标区域Base响应变化。这样隔离Base交互，避免把Encoder/Decoder的全局作用混为一谈。
- 用同权重的原全局关系、普通局部关系、均衡局部关系做有限干预；干预结果只用于检查作用方向，不是训练候选的最终效果。
- 分别看输出对两源的相似性与源独有结构。现有近SAR场景可作开发分层，但不能称为噪声标签或独立测试集。

**停止条件：** 若区域关系差异小、Base交互对输出不敏感，或干预普遍只改变对比度而不改善目标结构，停止C，不继续加窗口尺度、专家或损失项。若局部有改善但明显引入接缝，先解决数值与合成问题，不直接投入完整训练。

### 7.2 第一个训练候选

只有机制值得继续时，训练E2+C一个候选，沿用4轮重建+12轮融合、原损失和现有优化预算，整套模型从头初始化。基线checkpoint与已有同协议评价结果复用，不默认重训E2。

候选可以保持Base修正末层零初始化，因此融合起点仍为光学Base。它不意味着最终模型等于已训练E2，也不保证最终源比例。

保留一个能调用原交互的工程模式，检查同权重回退时严格复现原算子；该模式不是独立训练对照。阶段一仍走原E2源重建，新融合交互只在融合阶段启用。

### 7.3 通过后才补论文消融

必要消融为：原全局交互、普通局部交互、归一化局部交互、完整区域均衡交互。普通局部对照尤其重要，否则不能排除收益只是扩大了空间适应性。

要宣称两个创新点可分别贡献，理想矩阵是“有/无E2 × 有/无C”，且训练协议匹配。已有R3与当前光学Base E2存在额外结构/训练差异时，不应直接当作严格四格消融；先核查可复用情况，再说明缺失控制的成本，由用户决定是否补做。仅有E2与E2+C时，可以主张在E2基础上的新增贡献，不能声称已经证明完全独立。

所有新模型/指标输出使用唯一目录；采用新评价协议与独立比较组，真实结果产生后再更新注册表。最终配置在val固定后才进入正式test，不根据test选择窗口、温度或归一化方式。

## 8. 当前交付与判断

本轮新增的是研究审查文档；没有启动训练、批量测试，没有修改生产模型或伪造实验条目。新增的608/668计数来自已有CSV的只读汇总，不是新数据集评价。

**如果现在决定下一步实现哪个，建议实现C的机制诊断与最小原型；不建议直接训练原版B。** 若C的机制诊断不成立，再转B-lite验证检索信息，而不是在两个未证实模块上同时堆叠。

此前给B较高的潜在收益排序，需要被本轮更严格的监督分析和现有源相似性证据修正。当前最有价值的第二模块，应当能解释“不同区域的两源信息怎样合理进入输出”，而不仅是让网络看到更多SAR上下文。
