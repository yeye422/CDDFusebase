# MaRS-Base 冻结光学结构先验诊断

日期：2026-11-18。状态：实现完成；尚未运行 QXS 真实数据或官方 MaRS 权重。仅对冻结特征拟合简单 Ridge 线性读出器，不训练 E2、MaRS 或 Adapter；不访问 test。

## 1. 文献与权重

- Yang et al., MaRS: A Multi-Modality Very-High-Resolution Remote Sensing Foundation Model with Cross-Granularity Meta-Modality Learning, AAAI 2026，DOI 10.1609/aaai.v40i14.38153
- 源码：https://github.com/WanderRainy/MaRS
- 官方权重：https://zenodo.org/records/17800805
- 首轮使用文件：mars_base_rgb_encoder_only.pth
- 官方示例：timm==1.0.15，swinv2_base_window8_256，features_only，in_chans=3，img_size=512。
- 官方 mars_dataset.py 中 RGB mean=[87.01,91.52,83.51]，std=[62.66,54.58,53.11]，按照训练时原始0-255 TIFF量级做标准化。

限制：释放的 encoder-only 权重不是 MaRS 完整 MMA 融合网络，不能把这一诊断称为已使用 MMA 跨模态融合。模型仅供学术研究；检查上游版权条件。

## 2. 实验要回答的问题

MaRS 的冻结特征能否比 E2 源 Optical Detail 更容易线性恢复源图梯度，尤其是既有人工审计认为 Optical 连续、但 E2 融合图缺失的线段？优势是否来自预训练，而非同架构随机特征或错位特征？

首轮不采用 QAB/F、FMI、VIF 等融合质量指标，不修改最终融合图。高读出表现是 Adapter 的必要前提之一，不是实际融合收益的证明。

## 3. 固定数据和对照

- train：复用既有 STG 归档锁定的 pilot manifest，均匀取 train32；只有 train 图片的源 Optical Y Sobel 作为线性自监督目标；每张/尺度固定采样512个像素。Ridge alpha=0.01，特征标准化统计来自 train，绝不利用 val 选 λ。
- val：test_result/stg_no_train_v1/val8 中已有的 sample.json、source_labels.csv、e2_visibility.csv，固定8个已人工审计场景。含 E2 缺失连续光学线、保留线和 disconnected 负例。用这一批固定人工审计场景，不能声称外部独立性。
- E2：采用 STG 样本归档保存的 OpticalBaseAnchoredE2 checkpoint，严格哈希匹配。严禁把不同 E2 版本和另一训练 pilot 的指标混用。
- MaRS：先用 E2 一致的光学 Y 复制为三通道再标准化，保证与 E2 拥有相同输入信息；可选 include-rgb 用原始 GF2 RGB，但 RGB 带来额外颜色信息，必须与 gray 对照分开解释。
- 将 MaRS 官方512输入（QXS 256插值上采样）阶段0/1特征和 E2 源特征投影到原图等效的128/64网格，分别建独立 ridge，不能事后只报最有利阶段。
- 方案 e2_detail、e2_shared、mars_gray、mars_random（同架构随机权重）、mars_shifted（预训练特征空间错位）。可追加 mars_rgb、mars_rgb_random。

## 4. 输出读出

源目标：灰度 Optical Y 高斯平滑1.25后Sobel梯度幅值，统一映射至[0,1]。在 train 上拟合逐像素线性 ridge，val 上输出各场景、尺度的 MSE、MAE、高梯度前20%区域MAE、R2。

线段：使用既有人工标签和坐标，沿线内侧70%取33点，沿法向±4像素取固定走廊最大响应，记录响应均值、超过固定0.2阈值的连续比例、第25百分位。分别汇总 E2-missing、E2-present、disconnected。若缺失线的响应提高，但 disconnected 同时提高，不视为成功。

所有读出是源图结构代理，不能等同真实 SAR 散斑标签、独有目标真实性、融合图结构改善或 QAB/F 提升。随机对照需要在相同训练数、同样 ridge、同样输入规格下比较。

## 5. 判断门槛

1. 同尺度同图比较，MaRS-gray 必须在梯度 MSE/高梯度 MAE 上优于 E2 Detail 与 random MaRS，并覆盖多数图而非离群点。
2. 既有 Optical 连续但 E2 缺失的线段必须出现更高、且不过度增加 disconnected 误连的读出优势；缺失线数量少，应保守解释。
3. 预训练特征 spatial-shift 控制不应达到同样效果；如果原始RGB好而复制Y不好，结论是额外 RGB 信息或域适配，不是公平同输入下 MaRS 优势。
4. 以上若不满足，停止 Adapter；若通过，才做同训练预算的 E2+MaRS Adapter 与 random-feature Adapter 的融合质量对照。

## 8. 2026-11-18 权重加载修复

第一次本地 smoke 日志在 E2 两个读出器完成后、加载 MaRS 时失败。错误为 `Unexpected key(s) in state_dict: layers_2.*, layers_3.*`。原因是官方 `mars_base_rgb_encoder_only.pth` 含完整四个 SwinV2 阶段，而最小诊断用 `timm.create_model(..., features_only=True, out_indices=(0,1))` 只创建前两个阶段。原脚本通过 `checkpoint_path` 请求 timm 的严格全量加载，因此其余阶段键被视为多余，属于**脚本与权重抽取范围不匹配**，不是 checkpoint 失效。

现在将加载拆为两步：
1. 创建相同的两阶段 `FeatureListNet`，避免为本次 128/64 像素验证计算剩余阶段；
2. 读取官方权重，仅忽略键前缀 `layers_2.` 和 `layers_3.`，对实际使用的全部键检查存在性与形状一致，使用 `strict=True` 加载。若还出现其它多余键、阶段0/1缺失或形状不符则中止，不执行弱化版加载。

同时提供 CPU 合成测试，验证标准全量权重可装入两阶段网络、缺失键/不匹配/其他未知键会失败。该测试不需要下载大型官方权重；**真实 MaRS 权重的前向仍需用户本机验证**。

修复后运行：

    cd /d "D:\#imageInfusion\CDDFuse"
    git pull --ff-only origin main
    .venv\Scripts\python.exe -m unittest -v test_mars_frozen_prior
    .venv\Scripts\python.exe diagnose_mars_frozen_prior.py --train-scenes 8 --save-images 1 --output-dir test_result\mars_frozen_prior_probe_v1\smoke_train8_val8_gray

脚本应打印 `MaRS encoder loaded: retained ... tensors; ignored ... from unused stages 2/3`。失败时目录不会写入最终验证产物（仅使用临时目录）；若旧输出目录已存在，则另外指定新的 `--output-dir`。
