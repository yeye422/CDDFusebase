# 第二机制建议：初融图引导的源别局部修正模块

2026-11-19。面向 QXS 光学–SAR 灰度融合，第一机制沿用 LWPD-E2。第二创新点按完整深度学习模块评价。主实验比较已有匹配 E2 与 E2 加完整修正模块。单种子 val64 小试已完成，结果见第 7 节。

## 1. 从已有结果得到的设计要求

在固定七图上，14 条标注连续边中只有 3 条被源图选线部分覆盖，其中两条在 E2 中已可见。4880-B 被覆盖 7/22 个点，自动图元和源图法向剖面均只使 1/22 个点达到预期光学极性的阈值；10095-B 完全漏选。每种编辑的窗口 MAE 都匹配。这说明在给定改动预算时，只按源边强度排列，会把一部分预算花在已经可见的边上。此次验证限于当前直线检测规则、固定场景与 8 位归档输出。[逐线结果](../test_result/e2_blind_lines_v1/remaining7_hough/probes.csv)

冻结 E2 的 val16 中，光学候选边的传递系数从单源重建的 0.961 降到融合的 0.333，SAR 对应值为 0.954 和 0.931。单源重建包含 Base 和 Detail；这些数值支持检查最终图像中的源别传递，不足以把全部衰减归给 Detail 或 Decoder。当前 SAR 候选由源响应定义，真实独有目标尚待核验。[源别传递诊断](../test_result/e2_fcsr_decoder_diagnosis_v1/val16_seed42/summary.json)

## 3. 推荐的网络接口

主干保留光学 Base 直连的 E2，利用原 Decoder 得到未量化初融图 F₀。在 Decoder 末端并接一个保持空间分辨率的卷积模块。E2 已有分别读取两源 Detail 与融合 Base 的接口。第一版只执行一次完整 Decoder，增加两个浅层候选头、一个共享评分头和逐像素合成。[现有骨干接口](../direct_fusion.py) · [Base 接口](../e2_base_anchor.py)

1. **生成两个可检验的修正候选。** 两个轻量卷积头分别读取原位光学或 SAR Detail 及局部上下文，以 1×1 投影、3×3 卷积和单通道输出产生有界的亮度残差。形成候选 Fₒ、Fₛ，并保留 F₀ 作为第三张候选。首版用有限幅值残差叠加到 F₀ 的图像 logit，统一经 sigmoid 回到灰度范围；残差末层零初始化。最终合成前都使用浮点数，强度预算以合成后的灰度 MAE 核验。每个候选只需单通道图，便于直接检查它实际改变了什么。
2. **共享卷积头在每个位置评估三种结果。** 对每个候选，读取两张源图、F₀、候选图及候选相对 F₀ 的变化，通过相同权重的小型卷积网络输出稠密得分图。可加入局部归一化的一阶有符号差分作为输入，学习哪些中心与侧翼观察支持该改动。第一版无需手工 Hough 候选或全图位移场。保留原结果也实际参加评分，网络可以对强度本已充分或两源对应含糊的区域选择小改动。
3. **一次空间加权合成。** 令 p₀、pₒ、pₛ 为对三个得分做 softmax 的结果，最终图为 F = p₀F₀ + pₒFₒ + pₛFₛ。输出受三个候选的局部范围约束，便于比较门控与实际成图效果。p 是网络的混合权重；它不是边界真实性概率。凸组合可能削弱相反极性的候选，对这类场景优先检查原位可辨认性。若两候选本身均无法恢复某条边，评分器也没有能力从两者中选出成功的修正。

相对 FusionBooster，候选贡献在于直接评估“对当前图执行一次特定来源的局部修正会怎样”，并用可观察的候选图与保留选项验证。相对 CSR，核心差别是打分时可读取各个修正已经产生的图像变化，并且可以用已知扰动为动作排序提供监督。卷积、残差、门控和 softmax 都是现有算子。论文将两路候选头、评分头和合成作为一个模块报告，其整体增量由与 E2 的配对结果给出。

## 4. 没有融合真值时怎样学习

- **利用现有源重建阶段启动训练。** 在训练划分的单源重建任务中，参考源图是已知的。对初步读出局部衰减方向细节，或保持原状，形成同一来源、同一位置而初融状态不同的成对样本。对三个已渲染候选，在相同局部窗内比较相对参考的有符号剖面误差与邻域误差，为评分头提供相对排序；候选差距很小时跳过排序。先让候选头通过重建误差学到非零修正，再加入排序，避免零初始化时三个候选完全相同。参考图仅参与损失，训练和推理的评分器只读可获得的源图与候选图。
- **显式控制取巧路径。** 保留已清楚、无扰动的训练位置；同一源图配多种初融状态。对同一源重建的恢复可能退化为总是复制该源，故应在真实双源开发场景检查学到的排序是否有效。合成任务不负责裁决真实 SAR 散射和光学反极性歧义。
- **融合阶段复用原融合目标。** 初版对 F₀ 保留原目标，对最终输出施加同口径目标，以约束初融质量；有监督的排序辅助项限于可构造参考的训练样本。已有困难场景可帮助解释原目标下的实际成图变化。新模型遵循项目规则，从头训练全网；沿用原数据和预算、复用已有基线。若采用候选排序辅助项，在方法与训练设置中一并披露，结果归于含此训练设计的完整方案。

## 5. 主实验与论文主线

**主实验只需两组：匹配的 E2、E2 加完整局部修正模块。** 复用同数据划分、预算和评测协议的已有 E2 结果。新增模型沿用 E2 的初始化规则与训练预算；将模块专用的训练设计写入配置。按现行协议报告 14 项指标的逐图配对结果及共同有限样本数，用事先关心的指标解释具体收益及伴随的取舍。

**论文叙事从两源表示延伸到最终成图。** 第一机制用 LWPD 分解和调制两源细节，得到初步融合图。冻结 E2 的诊断表明，部分在源图中可辨的光学结构经过融合后响应减弱。第二机制据此在输出端读取初融图和两源 Detail，学习在保留初融、光学修正、SAR 修正之间逐位置组合。实验结论落在完整模型相对 E2 改善了什么。若配对结果显示边缘传递改善，可用固定场景的光学、SAR、E2 和新模型局部图解释；若主要收益是降低伪影或改善信息保留，就按实际收益表述。

错位反馈、简单源剖面和同容量细化网络可用于日后分析内部原因。第二创新点的判断依据是完整模块相对 E2 的明确收益。

## 6. 首轮配对小试

实验入口为 [run_e2_local_correction.cmd](../run_e2_local_correction.cmd)。固定 seed42、train1024/val64，候选整网从头初始化，4 轮源重建后做 12 轮融合，使用最终第 16 轮检查点。对照为既有光学 Base E2 小试的同一批 64 张输出。启动前校对基线检查点、指标、划分和场景顺序。

首版候选头与共享评分头宽度均为 16，源别 logit 残差上限为 1，SAR 无效位置屏蔽 SAR 候选。重建阶段在交替的 16 像素区域保留初始读出或以 5×5 均值模糊衰减细节；局部候选误差差距超过 1/255 时提供排序标签。辅助重建与排序系数分别定为 0.25、0.05。融合阶段融合损失按最终图 0.75、初融图 0.25 加权，沿用 E2 的源重建项。这些系数是首轮固定设置，结果归于完整模型及其训练设计。

在 Windows CMD 中启动新模型训练及随后自动执行的配对验证：

```cmd
cd /d "D:\#imageInfusion\CDDFuse"
run_e2_local_correction.cmd train-val
```

中断且已有完整 epoch 检查点时使用 `run_e2_local_correction.cmd resume-val`。训练完成后也可单独用 `run_e2_local_correction.cmd val` 运行或核查验证。结果目录为 `test_result/e2_local_correction_pilot_v1/val64/seed42/`。其中 `paired_comparison.csv` 给出 E2 与候选的均值、配对差、共同有限样本数及场景 bootstrap 区间。候选灰度、RGB 和三联预览可按场景检查；训练及验证按阶段登记。

## 7. 首轮结果

固定 seed42、训练 1024 对、最终第 16 轮，已完成同组 val64 配对验证。FMI 从 0.630553 升至 0.652085，36/64 图上升，均值差的场景 bootstrap 95% 区间为 [0.001059, 0.040366]。MS-SSIM 在两法共同有限的 54 图上从 0.586953 升至 0.588481。与此同时，QAB/F 从 0.789001 降至 0.784367，49/64 图下降；NAB/F 从 0.031860 升至 0.036882，59/64 图变差；VIF 从 0.335292 降至 0.331631，50/64 图下降。后三项配对差的区间均未跨零。原始 MI 也下降，55/64 图变差。AG 和 SF 上升只说明灰度变化增强，不能区分目标边缘和颗粒。[全项配对表](../test_result/e2_local_correction_pilot_v1/val64/seed42/paired_comparison.csv)

在三个场景的归档灰度 PNG 上，沿此前固定的四条缺失边复核，最长连续达标段占比在 E2 和候选上分别同为 15.8%（546-A）、18.2%（546-B）、0%（4880-B）、9.1%（10095-B）。四条线的中心覆盖率与峰值偏移也分别相同。546-B 沿用无符号判读，其余三条以源图光学对比的符号判读。数值反映这些探针的读数，不能推断两模型输出像素完全相同或整个数据集均无局部收益。[既有标注](../test_result/e2_contour_evidence_v1/holdout_labels/e2_visibility.csv) · [候选灰度图](../test_result/e2_local_correction_pilot_v1/val64/seed42/candidate/gray)

可报告的正结果是 FMI 与 MS-SSIM 在此次开发集上提高。对于“相对 E2 改善弱边传递并控制伪影”的主张，本轮同时出现边缘指标下降、伪影指标变差和四条既定缺失边连续性持平，尚无明确综合收益。

|---|---:|---:|

## 9. V2 实验：直接监督两路候选

V2 沿用 V1 的两个候选头、共享评分头和一次完整解码的推理路径。变化在训练端：分别对光学候选和 SAR 候选施加本源结构监督，在融合阶段继续施加较小权重的同类监督。真实双源融合图仍使用原融合损失。主比较是已有 E2 对完整 V2。

- **扰动和目标。** 在单源重建读出上按 16×16 棋盘格交替保留或局部模糊，模糊采用 5×5 有效像素归一化均值。在衰减区域比较候选与源图的水平、垂直有符号对比：对相距 4 像素的两个 3×3 邻域比较均值之差，两侧邻域均须有效且落在衰减区。完整区域惩罚候选偏离未扰动读出的绝对亮度差。源图和候选采用相同方向，整片加一个常数不能改善对比项。
- **阶段和参数。** 直接候选损失按两源等权，采用“有符号对比误差＋完整区域保持误差”。4 轮重建阶段权重为 0.25，保留 V1 的混合重建和排序辅助项；12 轮融合阶段权重为 0.10，复用已有单源重建读出，并在该辅助路径分离骨干梯度。两项系数按首轮实现固定。历史中的光学/SAR 对比与保持误差分别记录为 `optical_contrast`、`sar_contrast`、`optical_keep`、`sar_keep`。
- **固定探针。** 第 4、8、12、16 轮在保存检查点时，以评估模式读取 4880-B、其平移负例和 10095-B 的初融、光学候选、SAR 候选和最终图。记录达标点数、最长连续点数、覆盖率、峰值偏移及有符号亮度差。负例用无符号响应检查两个极性的伪边，第 4 轮为融合训练前读出。人工探针只参与记录，不进入梯度或检查点选择。
- **主评测。** 复用同 seed42、train1024/val64 的 E2 检查点和归档指标，仅新增 V2 整网从头训练。最终第 16 轮按项目现行协议输出 14 项配对指标、逐图结果和灰度/RGB/三联图。附带 `other_val/` 描述性子集，事前排除两套既有人工八图面板及 smoke 场景 211，作为同一 val64 的补充观察。

## 更换第二机制：从图像复原、超分辨率、增强与 SAR 去斑迁移的候选（2026-11-22）

推理骨干以完整训练的光学 Base E2 为参照，保留 LWPD 和原三尺度 Detail 融合器。替代式与残差式局部交换在完整训练上分别将 NAB/F 均值提高约 35.7% 和 38.3%。这提示应研究如何形成清晰且有源支持的输出边缘，但现有全图统计还没有区分平坦区纹理、边界旁的双线、过冲和真实 SAR 独有结构，也没有将伪影唯一定位到 Decoder。

### A. 软区域约束的融合解码（优先候选）

Jampani 等的 SSN 给出了可微超像素分配。Gauen 与 Chan 的 SNA 用区域归属概率调制邻域注意力，在图像去噪任务中比较了硬分组和软分组。Su 等的 PAC 则提供了用引导特征调制空间卷积核的直接近邻。它们分别提供区域表示、邻居选择和动态卷积的依据，原论文没有验证本项目的光学–SAR 融合收益。[SSN，ECCV 2018](https://arxiv.org/abs/1807.10174) · [SNA，NeurIPS 2024](https://proceedings.neurips.cc/paper_files/paper/2024/hash/d41f8403e9bb5141bc2c81fad7658185-Abstract-Conference.html) · [PAC，CVPR 2019](https://arxiv.org/abs/1904.05373)

首版仅改 Decoder 最后一个 Restormer block 的 FFN 空间卷积。现有 FFN 有 1×1 投影、3×3 深度卷积、门控乘法与输出投影，改动可落在实际存在的空间算子上。由光学、SAR 的浅层特征分别预测像素对邻近区域中心的软归属。每个源内部计算两个邻近像素的同区域分数，跨源只合并这两个标量，因而不依赖两个源的超像素编号一致。SAR 无效位置可只用光学判断。原位和邻域参与计算的内容都来自**融合后的隐藏特征**。[Decoder 实现](../net.py#L240)

一种具体参数化是，令原卷积权重为 k，邻居为 q，中心为 p，以软归属得到邻居系数 g。用“原卷积 + Σ k(q−p)(g(p,q)−1)(x(q)−x(p))”替换单层空间卷积。g=1 时恢复原算子；内区常量特征不产生额外响应。该式允许原卷积权重为负，不能据此保证无过冲或 NAB/F 下降。两源区域边界若有错位，简单取同区域概率的乘积可能过度截断传播；首版宜保留可学习的连续混合以及原位特征。该机制的潜在贡献是两源的结构判断怎样约束融合图解码。软超像素与引导卷积本身均已有先例。

### B. 双边网格引导的 Base 融合（备选）

HDRNet 用低分辨率 CNN 预测双边空间中的局部仿射系数，再由高分辨率引导图切片，将变换应用于原位像素。DGF 提供端到端的引导上采样层。LGABL 已把双边学习用于多曝光融合，是直接的融合近邻。同一场景的多曝光与光学–SAR 的物理关系不同，不能直接搬用多曝光监督或把局部曝光变换当作跨模态成像模型。[HDRNet，SIGGRAPH 2017](https://arxiv.org/abs/1707.02880) · [DGF，CVPR 2018](https://arxiv.org/abs/1803.05619) · [LGABL，IEEE TETCI](https://doi.org/10.1109/TETCI.2023.3327397)

迁移时，低分辨率双源 Base 上下文预测少量通道组的系数网格，高分辨率引导坐标从原位特征生成，切片后调制光学 Base 直连上的跨源修正。保留原 E2 Detail 融合。低分辨率承担的是系数预测，原位细节仍走原有路径。主要风险是引导图把 SAR 颗粒当边界，或改善仅来自全局亮度增益。首轮可与现有 E2 比较，解释时另查将输出做一次全局亮度/对比度拟合后，局部差异是否仍有结构意义。

### C. 源内自监督 SAR Detail 估计（有条件的备选）

Speckle2Void 用盲点网络进行自监督 SAR 去斑；Speckle2Self 以互补掩码预测被遮挡像素，并用降采样处理其噪声假设。MERLIN 则以单视复数 SAR 的实虚部构造自监督观测。当前 QXS 只有显示域 PNG，复数分量、独立多时相和实际辐射标定均不能假定。可研究的是以 SAR 源内遮蔽预测作为训练辅助任务，在推理时给 E2 提供结构描述；“预测残差大”可能是散斑，也可能是孤立目标，不宜据此硬删除 Detail。此路线需要有可核验的 SAR 独有目标与背景样例，优先级低于 A、B。[Speckle2Void](https://arxiv.org/abs/2007.02075) · [Speckle2Self，Remote Sensing 2025](https://www.mdpi.com/2072-4292/17/23/3840) · [MERLIN](https://arxiv.org/abs/2110.13148)

### 选择与验证

同任务方面，WEMFusion 已覆盖小波方向增强与差异门控 Mamba，CSP-MCIN 已使用跨模态 Transformer 解码、门控和相关性/语义先验。上述三条为可迁移设计，检索不能证明首创。[WEMFusion](https://www.mdpi.com/2072-4292/18/4/612) · [CSP-MCIN](https://www.mdpi.com/2072-4292/18/7/975)

以完整 E2 自身的失败样例为选择依据，再看局部交换相对 E2 新增的伪影作参照。若重复出现沿边混叠、邻近平行假边，优先 A；若结构位置正确而区域明暗或来源占比失衡，优先 B；若主要为 SAR 背景颗粒，且能核实真实孤立目标，才提升 C 的优先级。主实验仍是 E2 与 E2＋一个新模块的同预算配对，不加载局部交换或 V3，也不设额外指标阈值。小试只作筛查，检查点验证应关注伪影变化何时出现；论文结论以完整训练的实测收益及代价为准。本节未实现或训练任何新模块。

### 方案 B 的最小版本与判定

保留 E2 编码器、LWPD、光学 Base 及现有 Decoder。在 Detail 聚合处用轻量投影为每个源生成共享与特有两组全分辨率特征，总宽度匹配 E2。训练时只对共享组的局部池化描述施加跨源对齐；私有组保留来源，连同本源共享组参与源重建。推理时用共享组产生共同上下文，对两源原位私有内容分别做有符号变换，再聚合成原接口的融合 Detail。这样三路承担不同的成图操作，避免把通道切开后立即线性拼回的等价重参数化。源重建可以走 Base 旁路，必须通过真实融合输出检查私有组是否被使用。共享损失不能把全体 patch 当作已确认的像素级几何对应，也不宜把 batch=2、梯度累积 4 误作每步都有 8 张图的对比负样本池。

先复用归档诊断：真实配对的线性 CCA 虽强于空间滚动，但第一典型相关与跨场景配对接近。现有证据不支持把高相关直接当作共享地物。只有发现融合输出中可定位的源别缺失，B 的结构设计才有明确改进对象。[子空间及梯度审计](历史实验结果总结_20261118.md) · [残差式交换 val64](../test_result/e2_residual_exchange_routing_v1/val64/per_scene.csv) · [跨尺度条件对照](../test_result/e2_cross_scale_pilot_v1_relation/val64/seed42/paired_comparison.csv)

若立项，先单开 B，采用既有 train1024/val64、seed42、4＋12 轮流程，与匹配 E2 比较。用现行 14 项与三指标逐图联合改善数判断收益，并检查光学弱边、平行负例及经核实的 SAR 独有内容；没有已核实的点目标时明记证据缺口。必要时从同一检查点关闭某一组观察影响，不要求先重训整套六格消融。共同有限场景按指标确定，非劣主张若要正式采用需预定义可解释容差；区间跨零不能证明等效。val200 如需使用，应预先固定 ID，避免与已看过的 val64 混称独立验证。已有局部交换从 693/936 联合改善降至完整训练的 58/1000，故小试只决定是否扩大；最终以同预算完整 E2 的 val1000 为准。本次为设计审查，没有运行训练或批量测试。

### B 最小小试入口与工程验证（2026-11-22）

实验变体 `lwpd_e2_shared_private_patch_v1`。每源 Detail 的 32 通道有符号投影分为 16 个共享通道与 16 个特有通道。两路共享表示经 3×3 卷积生成 32 通道共同上下文，分别调制两源原位特有表示的增益（初始为 1）。合计 64 通道送入原 E2 三条尺度分支，保持 176 通道聚合输入、光学 Base 和 Decoder。两路独立的 1×1 源重建读出均读取本源共享＋特有通道。模型总参数从 1,001,832 变为 1,016,360，其中新增的 4,224 个参数只用于源重建。[模型实现](../e2_shared_private.py)

共享训练目标取 16×16 patch 内通道幅值的有效像素均值，以图内均值去中心并归一化。将同一粗 patch 作为弱正对，在单张图的其他有效 patch 中进行双向对比；温度 0.2，对齐项权重 0.05。SAR 无效像素从双源描述中同步排除，仅有一个可用 patch 时跳过该图对齐。重建阶段开启源投影与重建读出；融合阶段使用同样的共享约束、双源重建和 E2 原融合损失。该设置不要求各像素具有精确同名点，仍可能受 patch 级错配及重复地物假负例影响。特有通道不会自动获得地物语义。

已通过四项单元测试、同一场景 4880 的 63×61 裁块 GPU 混合精度前后向检查，以及基线/划分预检。训练与批量验证尚未由代理运行。在 Windows CMD 执行：

```cmd
cd /d "D:\#imageInfusion\CDDFuse"
"D:\anaconda\envs\lightglue_env\python.exe" -u run_e2_shared_private.py train-val
```

固定 train1024/val64、seed42，全网从头 4＋12 轮，只复用 E2 的对照结果。运行中断且已保存完整 epoch 时使用 `resume-val`，已有最终检查点可用 `val` 单独复核。输出位于 `test_result/e2_shared_private_patch_pilot_v1/val64/seed42`：`paired_comparison.csv`、`paired_counts.csv`、`joint.json` 分别给出配对差、逐项改善计数和 QAB/F、NAB/F、VIF 同图联合改善数；`fixed_probes.csv` 对比 E2 与 B 的困难边、平行负例及既有 SAR 源响应，另记录场景 4880 同权重下分别关闭两路特有组的影响。SAR 源响应尚无独有地物真值。[小试入口](../run_e2_shared_private.py)
