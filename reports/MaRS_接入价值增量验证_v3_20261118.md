# MaRS 接入价值增量验证（v3）

日期：2026-11-18。状态：脚本和合成回归测试已实现，**尚未运行真实数据的完整v3验证**。已有v1结果因实现错误作废；v2修正了实现，但独立梯度读出不足以回答接入价值，当前默认流程升级为v3。所有原结果保留，不覆盖、不混表。

## 1. 本轮决策范围

检验：冻结MaRS前两个阶段，在现有E2可用表示之外，是否提供稳定、空间对齐且优于随机分支的光学结构读出增量；人工线段上是否比低成本光学结构输入更有用。

最高结论是“值得进入小规模受控Adapter对照”。本轮不训练E2、MaRS或Adapter，不修改融合图，不访问test，不计算或宣称融合质量指标提升。冻结编码器上的PCA、Ridge仅用train拟合。

MaRS使用官方RGB encoder-only权重，架构为 `swinv2_base_window8_256`，`timm==1.0.15`。输入为光学Y复制三通道，再从256双三次插值到512，采用官方原始0–255量级RGB mean/std。仅计算阶段0/1；不是完整MMA网络，没有额外成像细节。

- 官方实现：[WanderRainy/MaRS](https://github.com/WanderRainy/MaRS)
- 权重：[Zenodo 17800805](https://zenodo.org/records/17800805)
- 默认文件：`models/external/mars_base_rgb_encoder_only.pth`，脚本不自动下载。

## 2. 固定数据与复用

继续使用STG归档的E2 checkpoint `models/e2_scratch_original_loss_pilot_v1/seed42/epoch_016.pth`，启动时校验SHA-256。复用锁定的pilot manifest，验证train/val/test无重叠。

- train：均匀选32图，每图每网格采样512个像素。所有方法使用同一组像素。PCA标准化、投影及Ridge系数全部仅由这些训练像素拟合；Ridge alpha固定0.01。
- val：默认锁定pilot的全部64图。其中固定人工审计8图与其余56图分别统计，56图是主要像素增量检查集。两类不得混成一个主结论；56图仍来自既有pilot val，不称为外部独立验证。
- 人工线段：沿用8图标注，排除uncertain，现有missing 3条、present 10条、disconnected 16条。它们只提供小样本结构筛查。
- `--val-scenes`可缩小流程检查集，但始终包含人工8图；若未人工审计的共同有效场景不足16、train不足32图或随机初始化不足3个，判断固定为证据不足。

旧输出没有完整的训练投影/读出及v3对照，不能复用其数值。新增流程只重新拟合冻结特征读出；不重训已有融合基线或编码器。

## 3. 对照与容量

各方法分别在128/64两个网格读出同一源目标：光学Y经sigma=1.25高斯平滑后的Sobel梯度幅值。不能事后只保留最好网格。

E2 Detail先经Haar DWT取门控后的三个带符号方向系数。绝对值和三方向能量均在128原生系数网格计算，再池化到64，避免抵消，也避免先抵消再取幅值。

| 方法 | 输入表示 | 默认读出通道 | 用途 |
|---|---|---:|---|
| `e2_signed` | shared64＋signed Detail192 | 256 | 检查幅值表示造成的差异 |
| `e2_rich` | 上述256＋abs Detail192＋energy64 | 512 | 主基线 |
| `e2_plus_mars` | rich＋冻结预训练MaRS | 544 | 检查增量价值 |
| `e2_plus_shifted` | rich＋循环错位MaRS | 544 | 空间对应控制 |
| `e2_plus_random_42/43/44` | rich＋三个随机SwinV2 | 各544 | 预训练和新增容量控制 |
| `e2_plus_source` | rich＋低成本光学结构 | 544 | 检查昂贵先验是否有额外结构价值 |

所有增量分支均通过训练集拟合的标准化PCA，默认输出32维；`--augmentation-dim`范围1–32，各分支相同。错位MaRS与对齐MaRS共用同一训练PCA，训练和验证都错位。各分支有效秩和PCA方差保留率会保存，等输出通道不保证有效秩相同。

PCA后，所有新增分支统一用训练集E2 rich做无标签线性残差化：去除E2已能线性解释的部分，再与原E2拼接拟合Ridge。残差化不使用梯度目标或val数据，E2协方差采用相对特征值阈值1e-8的伪逆。这样避免把重复已有特征、降低Ridge收缩造成的数值改善误认为新信息。验证时折叠PCA、残差化和读出系数，避免每像素重复大型矩阵乘法；合成测试核对折叠与显式计算等价。

低成本结构为32个固定特征：0/1/2/4尺度的光学灰度、带符号及绝对值梯度、梯度幅值，原图Haar方向/绝对值/能量及局部标准差。没有直接放入sigma=1.25的精确监督目标。但其像素目标仍较有利，因此**不要求MaRS在像素MSE上击败该控制**；人工线段比较参与筛查。

E2 Detail本身受SAR条件门控；灰度MaRS不含SAR输入。该设计控制光学信息源，不声称双方全部输入条件相同。

## 4. 统计与线段检查

像素输出：逐图MSE、MAE、高梯度前20%区域MAE、R²。每项指标先取**所有方法共同有限值的场景交集**，所有比较使用同一交集并记录场景ID。以场景为单位配对bootstrap 2000次，报告均值、中位数、改善场景数和95%区间；不把采样像素当独立样本。

线段沿内侧70%取33点，法向±4像素固定走廊。旧逐点最大响应、覆盖率保留作诊断；新增主指标使用动态规划路径：相邻采样点法向偏移最多1像素，变化惩罚固定0.02，不允许每点跳到不相邻的边缘。阈值固定0.2。

- `path_mean`：路径响应均值；
- `path_coverage`：路径上超过阈值的比例；
- `longest_run_fraction`：最长连续超过阈值段的占比；
- `max_gap_fraction`：最大低于阈值缺口的占比。

missing/present/disconnected分别报告，同场景多条线先汇总再做场景bootstrap。对于disconnected，响应和连续段下降才是改善。路径指标仍是人工走廊内代理，不能等同真实拓扑恢复。

## 5. 预先固定的筛查规则

规则保存在 `mars_probe_evidence.py::DECISION_RULES`，并写入每次元数据；不根据val选参数。

两个尺度均须满足：

1. 未人工审计场景上，相对`e2_rich`的MSE平均相对改善至少5%，高梯度MAE至少3%；两项均要求中位改善为正、95%改善区间下界大于0、至少60%场景改善。
2. MSE分别优于三个随机初始化和错位MaRS：平均和中位改善为正、95%改善区间下界大于0、至少60%场景改善。
3. 人工missing相对`e2_rich`和`e2_plus_source`的最长连续段平均增加至少0.05，至少2/3共同场景改善，最大缺口不增加；至少3条missing参与。
4. 至少12条disconnected参与。相对上述两个结构对照，最长连续段和路径覆盖率的误响应增加均不得超过0.02，且95%配对改善区间下界不得低于−0.02。

判断输出：

| 状态 | 含义 |
|---|---|
| `candidate_for_small_adapter_ablation` | 两尺度均通过，可进行小规模受控Adapter对照；没有证明融合收益 |
| `inconclusive_structure_or_stage` | 部分尺度通过，或结构安全性不足，当前不足以推进 |
| `not_supported_for_current_probe_route` | 两尺度均未通过当前增量读出门槛，当前前两阶段/PCA/读出路线不受支持 |
| `insufficient_data` | 样本或随机初始化不足，仅作流程检查 |
| `exploratory_rgb_requires_gray_confirmation` | RGB探索通过，但额外颜色信息使其不能代替灰度主结论 |

线性读出失败不能否定所有非线性Adapter或MaRS深层路线；固定3条missing也不能给出普遍性证明。置信区间用于探索筛查，不作为外部验证或正式多重假设检验结论。

## 7. 输出与追溯

- `接入价值筛查.md`：中文判断、两尺度增量表和人工线段证据；
- `decision.json`：结论、全部固定规则和逐尺度逐条件布尔结果；
- `summary.json`：像素、线段及幅值表示检查；
- `pixel_probe.csv`、`line_probe.csv`：全部逐图、逐线段原始值；
- `pixel_comparisons.csv`、`line_comparisons.csv`、`representation_checks.csv`：共同有限样本、场景bootstrap和增量差异；
- `readout_and_projection.npz`：训练集PCA、无标签残差化与所有Ridge完整参数，以及折叠后的验证系数；
- `run_metadata.json`：E2/MaRS/manifest/标注/脚本与证据模块哈希、输入模式、场景、随机种子、实际读出维度、投影有效秩和方差、归档哈希、各冻结编码器参数量、各类特征提取调用数与同步计时；
- `previews/`：有限数量的结构读出图，不是融合结果图。

每场景每个冻结编码器只提取一次，训练仅保留固定采样行，不缓存整套多GB特征图；不重训融合基线。多个截断冻结编码器常驻设备，因此仍有额外内存及推理成本。运行成功后自动登记独立比较组，执行实验索引校验和渲染。

本轮没有新增真实研究结果，不预先登记虚构实验。v1的两条`invalid`记录保留；v3结果产生后由脚本自动登记。
