# MaRS机制审查与接入研究

日期：2026-11-18。范围：论文、固定版本官方代码、本地权重结构和既有v3结果的交叉审查。执行了权重静态检查、极小合成算术检查，以及1276单场景完整RGB编码器前向；没有训练、优化器更新、批量推理或新的融合评价。未改动v3验证协议与历史结果。

**研究判断：应将研究重点从浅层梯度增强，转向深层空间关系是否能帮助双源信息选择。工程上先验证现有RGB深层编码器；机制上更完整的方向是双模态关系条件；部署阶段再考虑关系蒸馏。三者目前均未得到融合收益验证。**

**2. MaRS训练的实际链路**

论文将MaRS定位为跨模态解释骨干，结合层次对比、遮挡重建和光学教师约束。其结构服务于可迁移表示；它没有直接定义本项目需要的单张光学–SAR像素融合图，也没有提供散斑真值或连续线段真值。[论文](https://ojs.aaai.org/index.php/AAAI/article/view/38153/42115)。

对当前公开代码的调用链，可写为：

```text
配对RGB/SAR + 同一空间mask
    → 两个完整SwinV2编码器
    → 末级空间特征
    → MMA：模态内处理、联合token处理，共两轮
    → 两路增强特征
    → 各自重建 + 跨模态对比 + RGB教师约束
```

源码中CGCL接收的是MMA后的特征，梯度再经MMA传回完整编码器。实际入口`model_factory.py`选择`contrast_type='cross'`；不能仅依据`build_mars`函数的默认`clip`参数解释训练路线。[模型实现](https://github.com/WanderRainy/MaRS/blob/7ce79aea78c228db9b292e0cb5751fd42cc69c4e/models/MaRS.py#L135)、[实际入口](https://github.com/WanderRainy/MaRS/blob/7ce79aea78c228db9b292e0cb5751fd42cc69c4e/models/model_factory.py)。

CGCL的设计意图是联合约束局部对应、整图一致性、局部到另一模态全局上下文的关系。公开损失给三项设置0.5/0.3/0.2权重，并分别使用0.1/0.05/0.07温度。这适合研究区域语义在局部成像差异下的稳定性；不能从这些目标推出精确位移场、逐像素可靠性或拓扑连通性。[损失源码](https://github.com/WanderRainy/MaRS/blob/7ce79aea78c228db9b292e0cb5751fd42cc69c4e/models/clips.py#L30)。

MMA模态内步骤分别处理RGB/SAR token，且两者共用同一attention模块参数；联合步骤让同一图像对的两组token相互作用。不同batch样本没有在MMA中混合。最终仍输出两个增强流。MIM用各模态自身作为重建目标；教师由冻结的同架构`timm pretrained=True`模型提供。[实现](https://github.com/WanderRainy/MaRS/blob/7ce79aea78c228db9b292e0cb5751fd42cc69c4e/models/MaRS.py#L11)。

对本项目的设计推断是：MaRS最值得进一步检验的能力在于“区域之间、模态之间如何关联”。若仍只拿每个像素的线性头恢复Sobel幅值，检验的问题更接近边缘可读性，难以覆盖上述关系能力。这个推断不预设深层特征一定有效。

**3. 本地权重保留了什么**

官方转换脚本只提取两个编码器，删除末端norm和分类头；MMA、重建解码器、教师、mask token和对比参数不在encoder-only导出范围内。本地421个张量严格加载到完整四阶段`features_only`模型成功，且确实不存在MMA键。[转换脚本](https://github.com/WanderRainy/MaRS/blob/7ce79aea78c228db9b292e0cb5751fd42cc69c4e/utils/convert_mars_checkpoints_to_swin.py)。

编码器单独用于下游是合理的迁移方式：训练期的影响仍可能保存在其权重中。MMA没有随权重导出，并不意味着预训练知识全部消失；但本项目不能把新建的随机attention称为“已加载原MMA”。另一个限制是，对比目标作用于MMA之后，不能直接保证两个独立编码器的原始通道坐标可用余弦相似度逐像素比较。

完整RGB骨干的本地静态结果如下。网格以512输入计，原图为256时由两倍插值得到：

| 阶段（零起点） | block数 | 通道 | 特征网格 | 原图等效步长 | 阶段参数量 |
|---|---:|---:|---:|---:|---:|
| 0 | 2 | 128 | 128×128 | 2像素 | 403,464 |
| 1 | 2 | 256 | 64×64 | 4像素 | 1,721,872 |
| 2 | 18 | 512 | 32×32 | 8像素 | 57,434,400 |
| 3 | 2 | 1024 | 16×16 | 16像素 | 27,325,504 |

patch embedding另有6,528参数。完整骨干86,891,768参数；v3前两阶段共2,131,864参数，占2.45%，使用4/24个block。**参数比例不是能力比例**，浅层也接受预训练梯度；但v3没有检查包含大部分深层计算的阶段2/3。1276的灰度单样本四阶段前向全部有限，形状与上表一致，深层权重可直接使用；这不是性能结论。

论文Figure 7的特征热图明确来自骨干最终block。原论文的这项边界激活证据不能直接移用到本项目的前两个阶段，也不能反过来保证最后阶段在QXS上有效。[论文图7](https://ojs.aaai.org/index.php/AAAI/article/view/38153/42115)。

深层网格适合提供较粗的上下文。上采样不会恢复新观测细节，所以不宜让16×16语义响应直接承担256×256细线的像素定位。也不能仅因低分辨率而放弃深层；其价值应在关系或条件作用中检验。

**4. v3应如何重新解读**

v3在未人工审计56图上，MaRS增量分支的MSE比E2 rich低15.53%/23.60%，改善图数均为53/56。这说明当前灰度输入、浅层特征、PCA32及线性读出路线存在稳定补充。

缺失线最长连续响应占比：128网格从17.17%到19.19%，64网格从17.17%到16.16%；低成本结构对照分别为37.37%/33.33%。当前路线没有通过结构准入。结论继续有效；它的适用范围不能扩展到未经检查的深层、双模态和关系接入。

还有一项对照解释限制：本地`timm==1.0.15`随机SwinV2所有block的残差后归一化缩放与偏置默认全零。残差分支初始不起作用，前两阶段主要留下patch embedding和patch merging。灰度复制输入下，v3随机特征的有效秩为17/68，与这种退化形式相符；预训练分支则为128/256。

因此，三随机初始化仍是合法的“未训练模型”对照，但不能单独归因出MaRS特有的跨模态机制优势。新增研究应包括普通ImageNet预训练SwinV2；也可补充预先固定非零残差缩放的随机网络，单独检查随机初始化的影响。后者属于新的控制，不能悄悄替换v3结果。相关本地实现见 `.venv/Lib/site-packages/timm/models/swin_transformer_v2.py::_init_respostnorm`。

低秩现象还有结构上的解释：复制灰度的4×4输入patch仅提供16个独立像素变量。残差分支为恒等、patch投影为仿射且归一化偏置初始为0时，其通道向量落在至多约17维的张成空间；一次2×2合并对应约68维。这与v3的17/68相符，是当前初始化和输入形式下的推断，不适用于所有随机骨干或原生RGB输入。

v3对阶段0/1的PCA32保留方差分别约88.0%/64.7%。方差保留不等于结构信息保留；也不能仅根据读出失败，就确认有用的深层、低方差信号不存在。

**5. 公开代码审查中的复现风险**

以下发现针对上述固定提交的公开代码。没有官方训练日志或完整checkpoint证明本地发布权重使用了完全相同的代码；**不能据此宣布发布权重无效**。其直接影响是：不要把当前仓库原样重训视为已忠实复现论文，也不要照搬损失代码构造本项目新模块。

| 项目 | 本轮核对结果 | 对接入研究的影响 |
|---|---|---|
| mask类型 | dataset返回long，编码器使用位运算`~mask`；0/1会变为−1/−2 | 字面代码不等价于预期的可见/遮挡替换 |
| 默认输入尺寸 | dataset默认256，构造编码器指定512；训练入口直接用dataset默认值 | 本地相同timm配置的patch embedding拒绝256输入 |
| 首token处理 | 对比函数切掉第一个token，输入来自Swin空间网格 | 没有可核验的CLS token依据，会删除首个空间位置 |
| 层次标签 | 将全局特征重复N次形成BN列，标签仍为图像索引b | 正类所属图像变为floor(b/N)，与预期b不一致 |
| 教师余弦维度 | 输入为B×N×C，cos维度设为1 | 当前计算沿空间token维，不能按逐token通道余弦解释 |

层次标签的极小算术检查：B=2、N=3，当前标签映射的目标图像全为0，预期后三个应为1。mask整数取反和输入尺寸错误也已做独立算术/接口检查，没有运行上游训练。[模型源码](https://github.com/WanderRainy/MaRS/blob/7ce79aea78c228db9b292e0cb5751fd42cc69c4e/models/MaRS.py#L76)、[损失](https://github.com/WanderRainy/MaRS/blob/7ce79aea78c228db9b292e0cb5751fd42cc69c4e/models/clips.py#L47)、[数据](https://github.com/WanderRainy/MaRS/blob/7ce79aea78c228db9b292e0cb5751fd42cc69c4e/mars_dataset.py#L37)、[入口](https://github.com/WanderRainy/MaRS/blob/7ce79aea78c228db9b292e0cb5751fd42cc69c4e/main_pretrain.py)。

**6. 域差异与公平问题**

作者项目页描述MaRS训练数据来自Umbra/Capella，约0.35m、X波段。QXS原论文描述的是1m、GF-3 C波段SAR和Google Earth光学，光学来自Maxar/INEGI。因此本地工具中沿用的“GF2”命名不能证明光学来源就是GF-2。[MaRS项目页](https://rsidea.whu.edu.cn/mars.htm)、[QXS原论文](https://arxiv.org/pdf/2103.08259)。

接入推断有三个实际边界：

- 把256插值为512只改变采样网格，不使QXS变成原生0.35m影像。需分别考虑地物尺度、波段、极化及显示域差异。
- MaRS原生RGB与当前复制Y不同。可另开RGB探索，但必须配普通RGB预训练骨干及RGB低成本控制，不把颜色增益记为MaRS预训练增益。
- SAR源码分别使用Umbra/Capella原始量级统计。QXS显示域PNG不能因同为SAR就套用其中任一统计，更不能任意扩展到16位量级。双SAR分支要先核对训练集预处理与特征稳定性。

此外，QXS patch来自少量大场景且存在相邻相关。当前56图只与人工8图分离，不是新区域或新传感器的外部验证。

**7. 机制相符的接入假设**

本项目E2 Base交互将张量组织为B×head×channel×HW，计算通道之间的注意力；MaRS的MMA把输入组织为B×token×channel，显式计算空间token之间的注意力。E2有全局统计作用，但与MMA跨位置token交互的形式不同。E2 Detail聚合则依赖两源投影和多个膨胀卷积分支。[本地Base/Detail实现](D:/%23imageInfusion/CDDFuse/direct_fusion.py)。

据此，新增模块最值得检验的是：**MaRS深层的区域关系，能否帮助选择E2已有的双源内容。** 应保留E2原生特征作为细节的value来源，让MaRS承担关系、query/key或条件角色；关系相似性不能直接命名为真值可靠性。

候选A——现有RGB权重能支持的最小路线：

```text
光学Y → 完整冻结MaRS RGB → 阶段2(32×32) + 阶段3(16×16)
                            → 低维上下文/区域关系条件
Optical/SAR原生Detail → 各自32通道投影
                            → 结合双源及Base上下文的小幅调制
                            → 原多尺度分支 → 原Decoder
```

这修正了此前只强调阶段0/1调制的侧重点。阶段0/1可以保留为细定位控制，但不能代替深层机制检查。深层条件应在原生网格提取后投影，由E2全分辨率特征补充定位。Base及Decoder的结构先沿用，避免同时改变多个位置而无法归因。

候选A可继续使用有界独立调制，两个源的增减不强制互补。条件同时看光学、SAR和Base；不能由RGB MaRS单独判定SAR是真实目标还是散斑。乘性调制无法补回已消失的信息，适用的是现有内容在融合中被弱化的情形。v3未证明这一路线有效。

候选B——更贴近跨模态机制的关系路由：

```text
RGB/SAR各自冻结MaRS深层特征
    → 各自关系 + 经校准的跨模态软关系
    → 为E2两源特征分配局部/区域路由条件
    → E2保留的共同内容和模态独有内容共同参与成图
```

不能直接把原始RGB/SAR特征余弦当共同置信度。可先检验各模态内部的空间关系一致性，再为跨模态投影和有限邻域对应建立证据；不要假定严格逐像素同位置。MaRS关注共同表示，E2仍需保留SAR独有目标，不能将两源不一致的部分全部抹去。

当前本地没有MaRS SAR权重，也没有原MMA权重。若新建小attention，它是借鉴MMA的新融合模块，需要自身对照；不是原预训练MMA的恢复。其优先级应晚于A的深层可用性验证和SAR域检查。

候选C——有效后才进行的关系蒸馏：

把MaRS深层的区域关系作为训练期教师，教小型E2条件网络预测可用上下文；推理只保留学生。关系目标可基于同模态归一化token之间的邻域相似矩阵，避免强制不同通道基底逐点相等。教师RGB关系优先监督光学条件支路，不能直接要求最终融合图匹配光学外观。

关系蒸馏也可能学到同质区域的错误相连，所以仍需disconnected硬负例。只有昂贵教师先证明融合收益，压缩教师才有明确收益来源。当前就直接增加感知损失或教师损失，没有这层依据。

**8. 最小后续研究顺序**

| 顺序 | 要回答的问题 | 主要控制与停止条件 |
|---|---|---|
| 已完成静态审查 | 深层权重是否存在、能否前向、是否包含MMA | 四阶段可用；MMA未导出；这不是质量验证 |
| 下一项 | 深层是否提供超过浅层和普通预训练骨干的区域关系 | 同信息输入、ImageNet SwinV2、随机初始化影响、廉价结构/区域关系；新协议新目录 |
| 条件成立后 | 深层条件是否改善真实融合而非只改善读出 | 同接口E2自身条件、廉价条件、随机条件、MaRS条件；关注SAR保留与负例 |
| 收益成立后 | 能否移除昂贵教师并保留收益 | 关系学生与在线教师直接比较，使用相同数据和评价口径 |

下一项的主读出应覆盖局部扰动下的关系稳定性、固定线段与不连通负例；若取得配套SAR权重，再检查成对检索或允许小错位的局部对应。Sobel恢复可保留为辅助，不能继续作为语义关系的全部代理。语义相似不等同几何连接，3条missing不足以支持普遍性结论；不得把现有val8人工标签用于训练或挑阈值。

只新增尚未测过的深层/控制/接口检查；复用现有checkpoint、可比基线及v3事实，不默认重训E2基线。若以后进行新增模块的完整训练，融合网络按仓库规则从头初始化，MaRS使用明确指定的官方冻结权重。正式融合验证沿用`reference_v2_candidate_with_paper_fmi`，不同输入、路径及评价目标使用独立比较组。

本轮没有实施上述批量研究或训练，也没有提供尚不存在的训练入口命令。下一步首先需要实现深层关系验证协议，而不是把本报告假设直接当作模型收益。
