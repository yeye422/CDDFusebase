### 1.2 失败方向排除表

| 路线 | 已有版本/证据 | 本轮不再推荐的同类方案 |

| 增加通用表达能力 | PAC-Mamba、LL-context、E4 恢复 | 再堆 Mamba、全局注意力、LL 上下文或增强恢复强度 |
| 可学习频率基与强频带重构 | PRL、MFFA Phase 2 | 把 Haar 换成另一套可学习小波；重新做光学高频锚定的小残差频率解码器 |
| 光学主导与局部可信度注入 | OCAF v1/v2、Optical Rescue | 光学恒等输出上加入 SAR 门控或幅值修正 |
| 共同/独有/冲突结构分流 | CSR v1/v2、structure-joint、极性解耦 | 重新命名共同边界路由、几何置信度、极性选择或梯度域重建 |
| 抑制/去斑的适用区域选择 | SPD 线掩码、line gate、方向子带收缩 | 换置信图、方向权重或收缩阈值；单独换一个去斑网络 |
| 输出约束与近端修正 | RCCR、源区间、严格过冲、ASPR、G1 | 再增加梯度上限、光学回退、投影或抑制惩罚 |
| 冻结骨干的小幅残差适配 | PDCF、P1/P2-A | 改为另一种可预测/不可预测分解后仍学习同类有界 Adapter |

表中是“此次选题不再沿用”，不是证明整个技术类别在所有条件下无效。例如 Detail-only SPD 本身有保留价值，失败的是进一步掩码/路由能否取得足够增益；PDCF 的负倍率曾有条件改善，但 Raw Evidence 对照同样改善，难以支持预测性分解的独立贡献。不能将这些情况统一写成“所有版本都完全无效”。

### 1.3 可以从失败中得到什么

1. **新增自由度不等于新增有效信息。** LL-context 的单图开关和训练损失显示，模块可以更好拟合既有目标，同时恶化结构和伪影。PAC 从头训练版本也没有解决这一点。
2. **压低高频不等于提高融合质量。** 极性/G1/OCAF 等说明 NAB/F 可以在有效边缘与信息大幅丢失时降低。
3. **特征域限制不能直接推出输出域限制。** LL 修改后仍经过非线性融合和 Decoder；子带增益有界也不保证最终图像梯度有界。
4. **尚未被现有失败排除的研究问题，应有不同的可检验机制。** 本轮选择的 A 改变采样结构，B 改变内容聚合所利用的证据。二者都不靠再给旧 Gate 换名称。

## 3. 方案 A：采样相位完整的 LWPD（优先推荐）

这里的“相位”指 **2×2 下采样网格的四种起始位置**，与已失败 E4 中的图像相位对称性证据不同，也与极性翻转不同。

### 3.1 问题与代码依据

当前 [HaarDWT2D](../lwpd.py) 在 `forward` 中用 `stride=2`。后续 LWPD 用各子带生成空间变化的门控，再进行 IDWT。固定 Haar 的完美重建只能保证未经任意非线性修改的分析—合成对可重建，并不能保证“门控之后”对一个像素的共同平移保持一致。

用一维阶跃可以理解这个问题：在一个采样起点下，阶跃恰好落在两个 Haar 块之间，某些高频系数为零；移动一个像素后，阶跃进入块内，出现非零高频。同一套衰减规则便会不同地改变这个边界，即使两张输入始终完全对齐。

**研究假设 A：部分不稳定细节来自输入结构与下采样网格的偶然关系；减少这种关系，可能改善边缘稳定性与伪影，而无需重新判定哪些 SAR 边界“可信”。**

目前只有代码和理论依据，尚未测得该效应对当前模型误差占多大比例。更不能声称现有全部失败由 Haar 引起。若它在真实验证图上很弱，A 就不值得完整训练。

### 3.2 替换什么，怎样实现

替换 `LearnableWaveletPriorDecomposition` 的单一起点分析—门控—合成流程。保持编码器、光学 Base 锚定、Base/Detail 融合器和 Decoder 接口，返回原来的四个 `N×64×H×W` 特征。

定义原 LWPD 成对算子为 `Tθ`，它输出两源 Base/Detail。对四个起点 `P={(0,0),(0,1),(1,0),(1,1)}` 使用共享参数：

```text
Zδ = shift_backδ( Tθ(shiftδ(Xopt), shiftδ(Xsar)) )
Tpc(Xopt, Xsar) = (1/4) × sumδ Zδ
```

- 两源同步平移，绝不只移动 SAR，不引入配准和对应搜索。
- 四个分支共享 Haar 和全部门控参数；不是四套独立网络。
- 在特征分解位置进行处理，编码器和最终 Decoder 各执行一次；不是四次完整网络推理取平均。
- 首版使用固定等权合成，不新增可靠性/相位选择 Gate。再给四个相位加任意位置相关权重会破坏要研究的性质。
- 工程实现可用四起点重排或等价的固定无下采样框架；不能仅把 `stride=2` 改成 1 而保留旧 IDWT。必须重新核对分析—合成归一化。
- 单源重建阶段也使用同一候选分解，从随机初始化完成训练，避免重建和融合分别看到不同特征坐标。

在偶数尺寸、周期边界及原算子对两个像素平移等变的条件下，四起点共享平均能构造一像素平移等变的模块。实际 padding、奇数尺寸及其它网络组件需要分别测试；不能直接宣称整网在任意边界或亚像素平移下严格等变。首版应固定扩边与裁剪规则，报告有效内部区域和全图两种诊断。

### 3.3 为什么不重复 PRL、E4、方向收缩

PRL 学习的是分析滤波器；A 固定滤波器，改变采样覆盖。E4 用图像相位对称性决定恢复；A 不计算相位对称图。方向收缩改变不同方向的保留幅度；A 不新增方向衰减规则。MFFA 重建整个频率分解和输出架构；A 保留当前 E2 融合与 Decoder，仅替换采样处理。

普通 SWT/cycle spinning 本身早已存在，因此论文不能只写“用 SWT 替换 Haar”。有价值的贡献需要是：**定位光学–SAR 特征门控的采样不一致，构造共享参数且保持既有接口的采样一致模块，并证明收益来自这个机制而非多次平均带来的平滑。**

### 3.4 指标收益路径与风险

优先期待 NAB/F、MS-SSIM 和细边连续性的改善；FMI、VIF、QAB/F 主要承担保真约束。它不是最有理由大幅提高 MI 的方案，也不自动解决低频辐射差异或大范围跨模态错位。

最大的风险是四相位合成变成平滑：NAB/F 下降，但 FMI/VIF/QAB/F 跟着下降。第二个风险是原门控对采样位置已经很稳，增加计算无实质收益。分解/门控部分的计算和激活规模可能接近原来的四倍，整网增加多少需实际计时，不能直接写成整网四倍或无开销。

**建议继续投入门槛**：相对新建同协议比较组中的既有光学 Base 基线，NAB/F 至少下降 15%，或 MS-SSIM 至少增加 0.005；同时另一项不退化，QAB/F 下降不超过 0.001，FMI/VIF 各下降不超过 1%。另外必须通过固定 SAR 独有细节检查。门槛用于决策，不是显著性标准或收益承诺。

### 3.5 最小验证与论文故事

先用固定少量开发场景诊断两源共同移动 1 像素后，逆移输出的差异。分别记录编码器、LWPD 和完整输出的差异，避免把全网边界效应全归于小波。再用现有 checkpoint 做四起点特征合成的干预，作为筛查；它不是从头训练候选的性能结果。

必要对照：既有 E2、A、与 A 计算预算相近的单起点控制，以及固定的普通输出平均/轻度平滑控制。后两类仅在 A 值得推进时安排，不能为了完整表格默认重训既有基线。四起点与两起点的消融检验采样覆盖，不做大规模滤波器搜索。

如果增加机制训练项，只允许作为后续独立消融：对完整融合输出施加两源同步平移的一致性约束。它不规定“更像光学”或“更弱梯度”，但一致性本身仍可能通过平滑达到，必须同时看信息保留。不要在首版同时加入它而无法分清架构和损失贡献。

论文主线可为：**从采样网格依赖到采样一致的光学–SAR 小波特征融合**。关键图包括四相位差异图、边界剖面、平移误差与伪影的关系、信息—伪影 Pareto 图。若只有平移测试改善、自然输入指标没改善，最多支撑稳健性论文主张，不满足本次高指标收益目标。

## 4. 方案 B：保留创新细节的模态内非局部协同融合（进取选项）

“创新细节”在此只表示不能由同源相似 patch 的重复模式解释的残差，不是已知噪声，也不是与另一模态的预测差。它可能包含孤立目标、罕见结构和噪声，必须保留可用通路。

### 4.1 问题与位置

当前 [MultiScaleDetailFusion](../direct_fusion.py) 将两源投影后送入膨胀率 1/2/3 的局部分支，再拼接 Base 上下文。编码器虽有全局通道交互，但这里没有显式的同源远距离 patch 检索与组协同处理。

田块、道路片段和建筑群往往在同一图内存在重复结构。仅依靠当前位置的方向幅值或跨源共同边缘，容易混淆弱结构和噪声；而模态内重复模式提供另一种证据：**一条 SAR 结构即使在光学中不明显，仍可能由 SAR 自身的其它相似位置支持。** 非局部去斑文献支持这种证据有价值，并不保证它在当前融合任务上一定有效。

建议替换整个 Detail 融合器的局部聚合部分。保留 LWPD、光学 Base 路径和当前 Decoder，先不叠加 A、SPD、结构路由或额外去斑损失。

### 4.2 可实现的首版

1. **每源单独建组**：从同源 Base 与归一化 patch 描述提取低维检索键，在较大空间范围选 K 个相似位置。两源各建自己的组，不要求光学和 SAR 的 patch 灰度或位置关系相同。
2. **使用 Detail 作为组内容**：取对应位置的 Detail patch，经共享轻投影后组成矩阵 `Xm(p)∈R^(C'k²×K)`。首版可以固定 `C'=16、k=3、K=8`，并以较粗网格检索和重叠回填控制开销；这些是起点，不是经验证的最优值。
3. **分出重复模式与剩余内容**：用小矩阵软谱滤波得到 `Rm`，保留 `Em=Xm−Rm`。可以采用 `Rm = Xm (XmᵀXm+τI)^−1 (XmᵀXm)`，τ 为有正下界的标量或少量组级参数。在奇异值方向上相当于连续谱缩放；不要把高秩残差直接判成噪声并删除。
4. **回填并联合融合**：对两源分别得到重复模式图 `Ro,Rs` 和创新图 `Eo,Es`，连同原始两源 Detail 与 Base 投影一起生成完整 `Df`。

```text
Optical Detail ─→ Optical 同源 patch 组 ─→ Ro, Eo ─┐
SAR Detail     ─→ SAR 同源 patch 组     ─→ Rs, Es ─┤
原始两源 Detail + Base 上下文 ────────────────────┤
                                                 ↓
                                    轻量联合合成 → Df
```

谱处理在 FP32 完成，线性求解优于显式求逆；τ 下界避免病态矩阵。分组首先包含中心 patch，缺少相似邻居时不强制聚合无关 patch；无效 SAR 不进入候选组。首版检索可以使用固定/停止梯度的键，连续谱处理和融合头可学习，避免早期模型通过改变相似度任意操纵组结构。

检索可用 Base 辅助，但 Base 不是地物真值；重复散斑和重采样相关性也可能进入组内。必须保留距离/位置诊断，而不能只展示一张“可信度热图”。

### 4.3 为什么不重复失败路线

- 与 SPD 不同：不先预测一张干净 SAR，也不引入外域 noisy/reference 教师。协同表示直接参与完整的两源 Detail 合成。
- 与 PDCF 不同：没有跨模态预测器，不以光学能否预测 SAR 来定义 SAR 的信息价值，也不在冻结基线上只加一个小幅 Adapter。
- 与 CSR/structure-joint 不同：没有共同、光学独有、SAR独有的空间类别判定；相似组在每个模态内形成，不用跨模态置信度否决 SAR。
- 与方向收缩不同：处理对象是多个 patch 的相关结构，而不是当前位置的三个方向标量。原始 Detail 与创新残差均保留。
- 与普通非局部注意力不同：重复模式和创新残差被显式同时保留，必须用去掉创新通路、替换为普通注意力的对照验证是否必要。

诚实的查重边界：早期项目文档提过“非局部/低秩作为可选教师 cue”，也曾提出固定邻域的关系聚合。此次代码和实验检索未找到上述**同源远距离分组、组谱处理、创新保留的完整 Detail 替换器**及其验证记录。它不能宣传成项目此前从未想到自相似；新意需要落在具体运算和用途，而非关键词。

### 4.4 预期收益与失败风险

相对 A，B 更有机会触及 SCD、VIF 与 FMI，尤其是 SAR 自身有重复支持但跨源一致性较低的区域。重复结构协同也可能降低背景无规律高频。但这是机制推断，尚无数据证明当前误差主要出现在这些区域。

主要风险：

- 罕见建筑、点目标或孤立道路没有相似组；若创新通路失活，会重演过度抑制。
- 同源噪声可能相关或重复，组低秩不等于无噪声；不能对 8-bit、重采样后的 QXS 图像直接宣称满足独立 Gamma 散斑模型。
- 原始强度/梯度目标仍可能让融合头忽略协同信息，或把其用于锐化；若只是增加特征，可能重演 LL-context 的失败。
- 相似 patch 检索引入时间、显存和区域拼接问题；需要报告时延和稀疏场景行为。

**建议继续投入门槛**：在同协议配对比较中，VIF 相对提高至少 3% 或 SCD 至少 5%；同时 FMI/QAB/F 不下降超过 1%/0.001，NAB/F 不恶化、SSIM/MS-SSIM 不下降。只有 QAB/F 或 AG/SF 上升、其它信息不变且 NAB/F 上升，应停止，而不是加大检索范围或残差增益。

### 4.5 最小消融与论文故事

优先验证“相似分组是否有用”，再验证“谱处理是否有用”，最后验证“保留创新是否有用”。至少需要以下明确反证：

- 固定组数量和距离分布，打乱相似组成员。如果随机组与相似组相同，收益不能归于重复结构。
- 用同容量的大窗口局部卷积或普通非局部注意力替换组谱处理，检验是否只是更多上下文。
- 删除创新通路与保留创新通路比较，关注孤立目标，不只看全局均值。
- 局部光学证据弱、SAR 自身重复性强的区域，与重复性弱的区域分别报告；区域划分在看候选输出前固定。

完整方法从头训练；同一训练模型上的分组打乱/通路开关属于机制诊断，不能当作独立训练消融的替代品。只有首个候选满足继续门槛后，再由用户运行必要的训练消融，不提前铺开多组训练。

论文主线可为：**利用模态内重复结构，而不牺牲模态特有创新细节的光学–SAR 协同融合**。关键证据应展示：同源相似组确实选择到重复结构；去掉创新后孤立结构受损；新模块在信息保持与伪影之间改善了取舍。不能只画网络图并以“低秩=结构、残差=噪声”作为论证。

## 5. 两个方案怎样选

| 维度 | A：采样相位完整 LWPD | B：非局部协同 Detail 融合 |
|---|---|---|
| 改动位置 | 分解—门控—合成 | Detail 融合器 |
| 研究问题 | 一个像素的共同平移不应改变细节决策 | 不依赖跨模态共同可见性，利用同源重复内容 |
| 优先收益 | NAB/F、MS-SSIM、边界稳定 | VIF、SCD、FMI及结构/伪影折中 |
| 风险收益判断 | 优先，机制集中且筛查便宜 | 上限可能更高，证据与实现风险更大 |
| 最主要失败方式 | 多相位平均带来平滑；采样敏感本来就弱 | 分组吸收噪声；孤立结构流失；融合头忽略新证据 |
| 论文难点 | 证明超过传统 SWT/平均和计算预算效应 | 证明超过普通非局部注意力与已有自相似融合 |
| 最小起步 | 无训练机制诊断，再决定是否从头训练 | 同源相似组审查，再做单个候选替换器 |

**如果只选一个，建议 A；如果希望主攻“有效互补信息增加”，接受更高实现和实验成本，可以选 B。** 当前没有证据支持先把两者叠起来。组合后提高也无法说明哪个模块有效，失败则更难定位。

## 6. 统一验证约定与投入顺序

1. **基线复用**：使用已存在的光学 Base 从头训练 checkpoint `models/e2_scratch_base_anchor_v1/seed42/epoch_016.pth`。复用可追溯的源图、融合图与逐图指标，不默认重训 E2。A/B 的完整模型仍按项目规则从随机初始化训练，不加载已训练 E2 当初始化。
2. **比较口径**：只用新协议 `reference_v2_candidate_with_paper_fmi`。为候选和复用基线建立新的独立比较组，核实场景、split、checkpoint、输出策略及元数据；不能仅把旧表重命名为新协议结果。
3. **非有限值**：每项指标使用参与方法共同有限的样本，报告 N。当前 MS-SSIM 经常只剩七百余共同样本，不能隐去这部分缺失，也不能跨组比较其基线均值。若无效率变高，应同时报告失败比例和源图特征，避免幸存样本使均值看起来更好。
4. **配对分析**：报告逐图差、均值、尾部与置信区间。既有逐图 bootstrap 仅反映场景抽样差异；相邻裁块还可能相关，不能等同于跨训练种子的稳定收益。若能追溯原大场景，确认阶段优先按大场景聚类统计。
5. **不让 test 参与选择**：固定开发诊断样本与验证规则，正式 test 只在配置固定后运行。现有 val 已反复被使用，不能把重新切出的 val 子集称作从未使用的独立确认集。最终可推广结论还需要外部场景或新保留数据。
6. **收益判定**：14项原始指标完整报告，但不以“第一名数量”选模型。AG/SF/SD 只作描述；主判据为信息、有效边缘、结构和伪影的联合改善。
7. **外部竞争力**：模块消融之外，论文还应与可复现的直接光学–SAR 方法比较，如 VSFF/SOSTF，以及项目已有融合基线。文献表中的现成数值不能搬入本地实测表；有无公开权重、训练数据和复现许可需分别核实。
8. **预算顺序**：先证伪机制，再只训练一个候选；通过门槛后补有区分力的消融，最后多种子或外部确认。训练预算按现有 4轮重建+12轮融合、数据和优化设置起步，不通过延长训练暗中改变比较条件。

本次任务是方案选择，尚未创建 A/B 训练入口，所以没有可以真实执行的候选训练命令，也不提供虚构脚本命令。选定并实现后，应交付 Windows CMD 命令和唯一输出目录，由用户运行训练与批量评价。新增真实实验结果时再更新注册表并运行维护校验；本研究文档不伪造实验条目。
