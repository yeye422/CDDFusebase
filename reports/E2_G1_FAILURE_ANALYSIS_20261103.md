# E2-G1 失败原因分析

日期：2026-11-03。本报告仅审查已有代码、日志与验证结果，不新增训练、批量推理或评价结果。

## 结论

本次失败表现为融合输出明显向光学退化，主要原因是梯度目标的光学偏置。首版实现将“低置信区域不强制匹配 SAR”变成“在低置信区域强制匹配光学梯度”，共同结构之外缺乏 SAR 独有细节的正向保留路径。不能据本轮否定 PA 法向约束，也不能认定只是训练轮数不足。

QAB/F在968/1000张图上下降；已有Bootstrap差值区间为[-0.424709,-0.391630]。输出对光学MAE从0.165135降至0.009998，对有效SAR像素MAE从0.109521增至0.262670。二者不是完全相同的有效区域定义，但各自跨模型的变化支持明显光学偏向。scene4预览也与该表现一致；只看过单张预览，不声称完成全验证集视觉审查。

## 根因一：低置信区域的光学梯度监督压制 SAR 独有细节

代码最终形式：

`LG = mean((1-M)*Huber(|GxF|+|GyF|, |GxO|+|GyO|) + M*Ldirection)`。

M同时要求光学与SAR具备PA响应且方向一致。真实SAR独有结构在光学缺乏响应时，恰好可能落入M接近0的位置。该位置新增SAR边缘会偏离光学梯度目标并受到惩罚。共同结构证据适合确定强共同监督的位置，不能独立决定所有非共同区域应向光学靠拢。

这是首版实现中的设计偏差，不是已证明的网络容量问题。

## 根因二：复制光学是梯度项的低代价候选解

当F=O时，光学fallback及光学切向损失均为0，唯一剩余误差为共同区域的法向增量。法向目标被限制在 `[|On|, |On|+0.25]`。

Smooth L1的beta为0.1，因此误差最大0.25时损失为0.25-0.05=0.20。由此可得：

`LG(F=O) <= 0.20 * mean(M)`，外乘10后仍有 `10*LG(F=O) <= 2*mean(M)`。

这是直接由代码得到的界，不需要假设模型训练失败。并非证明总损失全局最优一定等于光学：强度项仍为max(O,S)，会推动一定SAR强度保留。但梯度目标提供了廉价的光学近似解，并惩罚非共同区域的SAR起伏；模型可通过更平滑的亮度偏移降低部分强度误差，不必保留原SAR细节。

## 根因三：掩码数值可能被多重乘法显著缩小

置信度先按 `(C-0.3)/0.7` 截断，再将两模态置信度与方向一致性相乘。举例：两模态PA均值都为0.5且方向完全一致时，平滑前M仅约0.0816；方向相差30度时进一步降为约0.0408。这是公式示例，不是本数据集的实测覆盖率。

使用全图均值聚合，SAR方向项的实际作用会随mean(M)下降。3×3平滑可以降低尖峰并扩散局部权重，但不能保证得到高置信掩码。原训练日志没有记录mean(M)、有效权重面积或分项梯度，因而目前无法量化该机制的实际贡献。

## 根因四：共同区域仍以光学为基准

方向使用光学PA法向，切向目标固定为光学，SAR仅能提高法向幅值且增量不超过0.25。该设计不是模态对称的方向约束。

当前Sobel没有除以8。对于理想轴向阶跃，边缘响应约为4倍灰度阶跃，0.25响应增量相当于约0.0625灰度阶跃增量（约16/255）。这只是理想阶跃尺度解释，不等于一般图像的统一对比度限制。

绝对值投影也允许方向分量符号歧义；跨模态极性差异使其有一定合理性，但不能替代完整结构约束。这属于次要设计限制，现有证据不能把本轮失败主因归结为它。

## 根因五：一次替换同时改变了多项因素

本次不仅增加PA法向投影，还改变了源目标（双源最大梯度变光学fallback）、区域策略、切向权重、幅值截断、L1到Smooth L1、边界padding。即使外部梯度权重仍是10，也不代表实际监督强度保持不变。

B最终val_gradient=0.063601，G1为0.001054；定义不同，不能据约60倍数值差断言优化梯度也缩小60倍。G1最终验证总损失约0.069388，其中强度项0.058641、加权梯度项0.010544、加权重建约0.000204。低总损失表明符合当前目标，并非融合任务成功。

## 为什么MI/VIF改善仍不通过

仓库paper MI按两源互信息求和，VIF按两源结果平均，不要求两源信息均衡保留。接近光学可能提高光学对应项，从而提高总体分数；当前没有保存两源分项，不能声称已经量化该贡献。它们不能单独证明新增SAR信息被保留。

NAB/F降低也可能伴随大量SAR高频信息被移除，结合QAB/F、FMI、SCD和输出MAE，应视为细节保留与伪影控制失衡，不能描述为成功去斑。

## 排查优先级

1. 已确定：存在光学fallback、SAR独有结构无正向梯度监督、法向增量截断与光学切向目标。
2. 强推断：这些目标共同驱动光学近似解，符合大多数验证图的退化表现。
3. 待量化：掩码实际权重面积、跨尺度方向稳定性、各项对融合输出的梯度强度、两源MI/VIF贡献。
4. 数值异常是次要待查项：首轮多个梯度范数NaN，第13/15轮Detail梯度范数Inf；AMP开启，日志未记录跳步次数，不能直接判定原因。B亦存在类似非有限诊断记录。无证据表明这是G1光学偏置的首要解释。

## 后续建议

保留G1失败消融，不覆盖已有输出，不自动延长训练或推进test1000。

优先做小样本损失诊断：比较F=O、F=S、已有B输出、已有G1输出在同一损失下的分项代价，记录掩码权重及输出梯度。小样本可以定位退化解是否被奖励，不能替代全验证集结论。

下一版首先修正非共同区域的监督策略，避免把缺少共同证据等同于应当复制光学。可保留原融合梯度主干并以较弱PA方向项作辅助，作为最小干预的诊断消融；原最大梯度仍可能传播散斑，因此这不是最终去斑方案。另一个独立问题是SAR独有结构应如何用跨尺度/扰动稳定性或幅值可靠性保留，应单独设计，不应再由共同掩码一刀切排除。

先固定一个主改动，再依次检验掩码、截断和Huber；不建议同时调阈值、权重、训练预算及网络。不得承诺仅增加SAR权重就能解决问题。
